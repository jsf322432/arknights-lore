# 明日方舟剧情知识库（Arknights Lore）

> 一个**逐篇精读明日方舟（Arknights）全部剧情文本**并沉淀为结构化知识库的开源项目：章节摘要、人物档案、势力档案、剧情时间线与世界观基线，全部为中文，可自由检索与二次整理。

## 项目特点

- **全文覆盖**：主线 0~17 章 + 30+ 活动 + 肉鸽傀影与猩红孤钻 + **obt/memory 干员密录全部 387 段**，逐篇精读（`章节摘要/` 101 篇）。
- **结构化沉淀**：755 个人物档案、33 个势力档案、剧情时间线（`时间线.md`）、世界观基线（`世界观基线.md`，105 节）、推荐阅读顺序（`阅读顺序.md`）。
- **自带工具**：`tools/` 提供剧情文本下载脚本（ASTR 数据源）与全文查询脚本，方便扩展与检索。
- **数据来源**：剧情原文来自 [ASTR（ArknightsStoryJson）](https://github.com/050644zf/ArknightsStoryJson) 项目（R2 镜像），本仓库存放精读产物；原文文本不入库（见下文"获取剧情原文"）。

## 快速开始

```bash
git clone https://github.com/<你的用户名>/arknights-lore.git
cd arknights-lore
# 可选：下载剧情原文（约 180MB，按需）
node tools/fetch-story.mjs zh_CN <活动路径...>   # 用法见 tools/fetch-story.mjs
# 可选：全文查询
node tools/search.mjs <关键词>                   # 在摘要/档案/原文中检索
```

**不想拉原文也能用**：`章节摘要/`、`人物档案/`、`势力档案/`、`时间线.md`、`世界观基线.md`、`阅读顺序.md` 已包含全部精读结论，无需原文即可阅读。

## 目录结构

```
arknights-lore/
├── README.md            # 本文件：项目说明与精读进度索引
├── 阅读顺序.md           # 主线 + 重要活动推荐阅读顺序（含时间线位置）
├── 世界观基线.md         # 泰拉世界基础设定与精读校验记录（105 节）
├── 时间线.md             # 剧情时间线（随精读持续更新）
├── 章节摘要/             # 每章/每活动/每密录批次的精读摘要（101 篇）
├── 人物档案/             # 人物档案（755 个）
├── 势力档案/             # 势力档案（33 个）
├── tools/               # 剧情下载脚本（fetch-story / fetch-memory）与查询脚本（search）
└── raw/                 # 【不入库】剧情原文（ASTR 下载产物，Git 忽略）
```

## 获取剧情原文（raw）

剧情原文不随仓库分发（约 180MB）。需要时：

1. 安装 [Node.js 18+](https://nodejs.org/)；
2. 运行 `node tools/fetch-story.mjs zh_CN <path...>`（path 形如 `activities/act33side/level_act33side_st01`，完整清单见 `raw/zh_CN_storyinfo.json`）；
3. 原文 JSON 亦可直接从 [ASTR 镜像](https://r2.m31ns.top/) 或 [ArknightsStoryJson](https://github.com/050644zf/ArknightsStoryJson) 获取。

> 全量原文打包（zip）可关注本仓库 **Releases** 附件。
