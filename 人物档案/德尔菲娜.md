# 德尔菲娜（Delphine / "菲娜"）

- 身份：安布罗修修道院萨科塔少女；福尔图娜的挚友、莱蒙德的青梅；**死于走火误伤**
- 首次登场：活动《空想花庭》（act26side）
- 关键信息：
  - 立场：痛恨拉特兰（"我宁愿不去这样的拉特兰"）——"他们区分我们，他们承认我们是同胞，却同时贬低我们真正的同胞"；"我其实没有那么在乎是否有自己的铳，也不在乎斯特凡诺爷爷总说的什么信仰"
  - 目睹真相：发现居民（卡洛琳等）以糠皮木屑充饥（"我们这日子，到底已经过到什么样的地步了？"）；指责福尔图娜"替拉特兰人当说客"/还有心情做格子饼
  - 《空想花庭》：与福尔图娜争吵中抢夺守护铳（"把你的守护铳给我……我们不需要对着这种东西祈祷"）——**铳械走火被误杀**（"我只想……大家能，一直在一起……"）；其死直接导致福尔图娜堕天
  - 与福尔图娜（共感）："光环告诉我你是真诚的，你的痛苦不比我少""我多希望我真的能明白，但是小福，我开始搞不懂了！"
- 经典台词："我在乎你，我在乎莱蒙德，我在乎斯特凡诺爷爷和杰拉尔德叔叔……我只有这一个家，只有这么点家人。""我只想……大家能，一直在一起……"
- 信息来源：活动《空想花庭》（全文）
