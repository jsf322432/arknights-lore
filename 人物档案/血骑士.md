# 血骑士·狄开俄波利斯（Dikaiopolis / "卡西米尔的血色高脚杯"）

- 身份：卡西米尔特锦赛卫冕冠军（大骑士）；**米诺斯人（丰蹄）**；**感染者英雄**；赤盏骑士团团长
- 首次登场：活动《长夜临光》（act13side）
- 关键信息：
  - 出身：米诺斯（"围绕在蔚蓝湖畔的白色建筑……摆着一盆茉莉花"）；感染矿石病后在地下竞技场打黑赛求生，被商业联合会（发言人恰尔内）包装为"炽斧骑士"→"血骑士"
  - **缔造感染者骑士制度**：夺冠后向骑士协会提出感染者参赛提案（"感染者也是受害者，感染者骑士也是骑士"）；组建**赤盏骑士团**收留感染者（"来我这里，我们可以正常地生活"）；"让很多感染者免遭厄运"
  - 理念："他们把我奉为感染者的英雄……但我的初衷，仅仅是活着""我们，感染者，只是为了生存而战""他们只是不幸患上了同一种疾病而已"（非血缘的"同胞"）
  - 战斗：鲜血法术（"血归吾身，教污秽奉还"）；击败逐魇骑士（"你的可汗在哪！让他上前来！""虚张声势的恐惧，对任何一个努力活在当下的人来说，都毫无意义"）；决赛败于耀骑士（矿石病恶化——"摆弄鲜血的法术，令英雄的身体早已干枯殆尽"）
  - 决赛后：**与耀骑士共赴冠军墙**（"授勋之地，是骑士的归属"）；隐退乡间种橄榄（"先回家。换身衣服，总不能一直穿着盔甲"）；"你有真正保护过哪怕一个人吗？"（对耀骑士的诘问）——"一个伟大的失败者"（评耀骑士）
- 经典台词："我的初衷，仅仅是活着。""一个感染者为感染者而战，一个普通人为感染者而战，究竟谁更高尚？""会有人明白这个道理的。"
- 信息来源：活动《长夜临光》（全文）；活动《未尽篇章》（act11mini st04）
