# 萌萌香 / 紫野遥（Momonga / Yukino Haruka）

- 阵营：金石集团演艺事务所（偶像/艺人）→独立（演艺事务所）｜种族：阿戈尔｜身份：偶像歌手/演员（"怪谈艺人"）；后川城出身
- 首次登场：活动《墟》（act44side）
- 关键信息：
  - **身世（重磅）**：真名**紫野遥**（"爸爸和妈妈希望我能到遥远的地方去，远离后川城……去自由地生活"）；后川城（南部边境/金城家地盘——化工厂废液污染水循环——"没味道却能杀人的脏水"）——父母死于污染（父亲早逝/母亲病逝——"我五六岁的时候（父亲）就不在了""她身体一直不好……手脚发麻"）；事务所压制身世（"羽"=北方印象——"紫野"易暴露后川城出身）；"羽生萌萌香这个名字不是我自己选的，但事到如今……那我和死了又有什么区别"。
  - **怪谈艺人**：以"怪谈"人设走红（探访凶宅/鬼屋节目）；"我其实很怕怪谈的……艺人就应该靠自己的努力给大家带去快乐"；《恶鬼的诞生》（"无名之鬼"=星熊怪谈的电影主角）。
  - **《墟》**：演唱会被"青鬼"（星熊）惊扰；被三船逼迫参加凶宅探访节目（捡到**佐野口断刀**——三船要回收刀镡）；电视异象（更纱放录像提醒——澪与三船密谋"让萌萌香得矿石病/消失"）；跳窗逃跑；与星熊同行（骑摩托逃跑/"反推把，然后压车"）；叶助（捡来的树苗——被忍者剪断——怒打忍者"凶手！那是我的叶助！"）；**直播告发金兵卫**（"根本就没有什么怪谈""金石电视台和演艺事务所欺骗了大家""我在此指控三船光平……是幕后真凶"）；"从今往后，羽生萌萌香不再是怪谈缠身的艺人。从今往后，羽生萌萌香与金石会下属的演艺事务所，脱离一切关系！"；"演艺的路我还会走下去……有人会把你们的故事唱出来，演出来"。
  - **结局**：手持小烟花赠星熊（"你至少看到了这个"）；考虑去罗德岛（"也许，在一个没人认识羽生萌萌香的地方，紫野遥也能短暂地拥有她自己的时光"）；与吉星/森内/更纱结缘。
- 经典台词："能为人恐惧而恐惧，其实是一种……幸福。""就算是我，被逼到墙角……也是会咬人的。""羽生萌萌香这个名字不是我自己选的……那我和死了又有什么区别？""也许我们繁荣的生活……就建立在这些谎言之上。"
- 信息来源：活动《墟》（全文）
- 后续：独立艺人（自办演艺事务所）；考虑赴罗德岛
