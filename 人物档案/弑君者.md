# 弑君者（Crownslayer / 柳德米拉 Lyudmila）

- 阵营：整合运动（头目之一）｜真实身份：**柳德米拉**，切城石棺研究所研究员**伊利亚**之女
- 首次登场：序章（蒙面）；第六章揭示身世（6-10）
- 关键信息：
  - 负责核心能源区；擅浓雾与精英部队
  - **身世（第六章）**：父亲伊利亚是凯尔希的学生/朋友、石棺封锁行动发起者之一；研究所遭乌萨斯清洗灭口；柳德米拉认定凯尔希与谢尔盖背叛，亲手杀死谢尔盖（米莎/碎骨之父）复仇
  - 被凯尔希（+红/Mon3tr）制服后放走；凯尔希点醒她"你的领袖并不是什么心性正常的人"，预言她终会离开整合运动（"她会在集体复仇心理中清醒"）
  - 曾为救米莎/碎骨自责："如果之前是我去救米莎，也许他们都不会死"
  - **第十六章（回归）**：成为罗德岛干员（"干员弑君者"）；经"托卡车互助会"接应博士/科谢尼娅一行，开卡车穿越涅瓦湖冰面救援矿工（"赶路的时候没时间闲聊……但现在，先上车"）
  - **第十七章（泽尔格勒）**：以旧整合运动识别码潜入；劝**瑭雅**"收集证据"而非孤身炸墙（"你能做的，其实一直都只有一件事——去收集其他的证据"）；**刺杀阿纳托利**（割喉——源石自行修复，"那看上去甚至不像是人类身体应有的组成部分"）；与整合运动/图林合流，掩护民众撤离
  - 与**塔露拉**和解（"我曾经怨恨过你，就像怨恨无能为力的自己……渐渐，我又有了更多要去做的事"；"我不会再相信无瑕的领袖那一套了"）；"你必须去做到你曾经没能做到的事"
  - **《叙拉古人》（st04 幕间）**：回到叙拉古寻找**老师**（"当年，弑君者怀着一腔怒火离开了这里，为了证明自己已经足够强大，能够向笼罩她的那片阴云复仇"）；却发现老师已被**红**（猎狼人）杀死——"真狼死了，真狼没有反抗"（红语）；老师遗言"吞下死难者的苦"；"她的努力是否有给阴沉的天空打开一丝缺口，她自己都拿不准。或许，其实什么都没改变，或许，她只是成了更大灾难的帮凶"
  - **《新沃尔西尼狂欢节》（重磅续篇）**：回叙拉古后先与老师重逢无望——老师（瘸腿"真狼"/獠牙）已被红杀死（"真狼死了，真狼没有反抗"）；追杀红失败、晕倒荒野，被**索默尔**救回卡车互助会（"第一次给互助会跑长途，就遇上这种事……咱们俩都挺倒霉的"）；经伊雷妮担保+司机们签字通过背景审查，成为新沃尔西尼合法市民/工会正式司机（"伊雷妮这段时间为这件事没少往市政厅和法院跑，最后她亲自为你做了风险担保"）；发现索默尔为威尼斯家族运"轮胎"（实为军火）并跟车（"我已经上了车，今晚这一趟我会陪你走完"）；车祸后追红而离开索默尔（自责："我怎么能就那么走掉呢……如果我没有被那个狼崽子吸引，说不定……"）；找到藏车发现军火→**放火烧毁巨狼花车**（"火可以点燃愤怒，点燃理想，火也可以掩埋一切……唉，真倒霉啊"）；狂欢节夜参与"卡车围法院"，劝阻伊雷妮越线（"在乌萨斯的时候，我认识一个有类似想法的人。她最后迷失了自我""伊雷妮，我会确保你不会越过最后那条线"）；结局——带红回罗德岛找凯尔希（红信仰崩塌："外婆骗了红"），救下子月（"我查看了她的伤口，你最后那一刀避开了要害，她没死，我救下了她"），警告伊雷妮（"我会盯着你，伊雷妮，我是悬在你头顶的剑。如果你变成那样，不管我身处何处，我都会出现……杀了你。我希望永远不会有那一天"）
- 经典台词："逃跑……又能逃到哪里？""叛徒……找到你了，叛徒！""赶路的时候没时间闲聊……但现在，先上车。""吞下死难者的苦。"（老师遗言）"倒霉蛋们不期而会。""我是悬在你头顶的剑。"
