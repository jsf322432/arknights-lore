# 别格勒（Begler / 女皇密探）

- 身份：**莱塔尼亚女皇密探**（夕照区以咖啡店主"别格勒店长"为掩护）；白垩爷爷的共事者；格特鲁德案的终结者
- 首次登场：活动《尘影余音》（act18side）（《崔林特尔梅之金》st01 中接应黑键的旧书商/密探）
- 关键信息：
  - 潜伏：在夕照区生活十几年（"你和夕照区的人朝夕相处，你对夕照区的感情不比任何人少"——爷爷语）；经营咖啡店（给芙蓉名片："想喝了可以打给我"）
  - 作风：现实/讲证据（"证据，乌提卡伯爵，凡事都要讲究证据"）；幽默刻薄（与黑键斗嘴："我开始觉得和你相处很让人痛快了"）
  - 《尘影余音》：追踪散布谣言的拉赫曼（与黑键在下水道发现尘世之音实验室）；逮捕格特鲁德（"涉嫌开展被陛下明令禁止的尘世之音研究"）；审问格特鲁德（得知她弑兄/引残党上层的真相）
  - **杀死格特鲁德**（匕首刺背——"友情、牺牲、奉献……他们可能确实有些幼稚，但至少有人会为他们掬一把同情泪。而你，斯特罗洛伯爵？你亲手毁掉了自己和车尔尼之间萌生的友情……你想让别人为你奉献，可你给了别人什么？"）；"我会替你写一份翔实的报告的……晚安，祝你做个不用诅咒别人的梦"
  - 与爷爷（白垩的爷爷）：共事（"看在我们俩共事过的分上"——曾将白垩引入维谢海姆局中）；对白垩的处置知情（"夕照区什么样，我就什么样"）
- 经典台词："这片大地上不尽如人意的事情多着呢，小姐。""我看到的，是堂堂乌提卡伯爵竟然在深夜带人强闯音乐厅。除此之外，我什么都没看到。""夕照区什么样，我就什么样。"
- 信息来源：活动《尘影余音》（全文）；《崔林特尔梅之金》（st01 接应黑键）
