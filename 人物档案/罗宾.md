# 罗宾（Robin）

- 阵营：前私人安保公司职员 → 罗德岛干员｜种族：鲁珀（推测）
- 首次登场：活动《孤岛风云》（act15d0，2021）
- 形象：身手不错、性格温和（入狱帮囚犯包扎）；因父亲医药费被迫铤而走险（"为了你的病，我会努力的"）
- 关键信息：
  - **身世**：父亲曾是**黑云贸易有限公司**总经理（海德兄弟最得力手下之一）；公司被西蒙家族垂死反扑拖垮；父亲一蹶不振、酗酒、肝病住院等医药费；母亲劝她离开父亲
  - **《孤岛风云》**：被"慷慨的J"（=杰斯顿）雇佣潜入曼斯菲尔德刺杀安东尼；入狱一个月后借"打扫 C 区"接近安东尼，被卷入另一拨杀手袭击昏迷；安东尼在医务室识破她并招揽（"你可以继续尝试刺杀我，或者就此收手"）；杰斯顿揭穿身世后选择当卧底（"我加入"）
  - **最终抉择（重磅）**：越狱日设伏主控室失败；被安东尼制服不杀；停尸间对峙中**选择安东尼**——"爸爸变成今天那样虽然确实是西蒙家一夜之间覆灭导致的，但是在那之后他的一蹶不振是他自己的责任""如果因为我这么做导致了来不及医治爸爸的病，那我会自杀，去地下向他道歉"；"这就是我的选择"
  - **杜玛线**：劝杜玛离开监狱（"像你这样善良的人才是最不应该生活在这样的监狱里的"）
  - 结局：随队越狱成功（罗德岛干员）；安东尼承诺设法帮其父医药费
- 经典台词："我好累啊，母亲要我做出选择，父亲要我做出选择，生活要我做出选择，杰斯顿要我做出选择，你也要我做出选择。我不想做选择……"
- 信息来源：活动《孤岛风云》全文 18 段
