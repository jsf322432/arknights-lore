# 努艾达（Nuwanda / 玻利瓦尔羽蛇修女）

- 身份：玻利瓦尔修道院修女（**羽蛇**——承载远古知识）；"拉特兰"信仰的想象者；带领孩子们穿越灾异的守护者
- 首次登场：活动《众生行迹》（act42side）
- 关键信息：
  - 身世：自幼在玻利瓦尔流浪（父母往她脑子里塞了大量知识——"它们指向黑流树海、海洋背面、黄沙深处……一个又一个族群，一桩又一桩秘辛"）；13 岁遇见弥留的修女（"生命的最后，她那么那么疼痛，却又那么那么宁静"——赞美诗让她的知识有了色彩："拉特兰"）
  - 与奥罗拉：同行的十年（"我们在一起十年了，奥罗拉。对羽蛇来说，这是很长很长的一段时光""我或许确实没有那么相信拉特兰，可我总该相信你"）
  - 《众生行迹》：带孩子们离开玻利瓦尔前往拉特兰（"我们只是需要一个领路人……一个像你一样的人"）；照顾萨科塔孤儿们（讲故事/唱赞美诗）；灾异中安抚孩子（"所有人都由祂来爱"）
  - 信仰观："哪怕乐园真的洁白无瑕，对我来说，它也比不过我第一次听见的那首赞美诗。""我确实没有那么相信拉特兰……可我总该相信你。"
- 经典台词："所有人都由祂来爱♪""我们只是需要一个领路人，一个知晓前方路途、能判明方向的人。一个像你一样的人。""至少，他们还有这首歌。"
- 信息来源：活动《众生行迹》（全文）
