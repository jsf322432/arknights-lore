# 莱托中校（Lieutenant Leto）

- 种族：黎博利｜身份：**伦蒂尼姆城防军指挥官**（指挥塔）；**高卢遗民**
- 首次登场：第十一章「淬火尘霾」
- 关键信息：
  - 城防军士兵对其绝对信任（"这些年里，是您带着我们走过了那么多险境""只要是您做的决定，我们都不会质疑"）
  - **与特雷西斯谈判**（4 年前）：以高卢遗民全力支持军事委员会为代价，换取"让那几座原本属于高卢的城市回到高卢"——复国交易
  - "最后一代亲眼见过高卢的高卢人正在死去……我们唯一能做的，就是尽可能抓住这些余烬"（独白：高卢帝国卫队老兵、切普区疗养院）
  - 与**变形者集群**暗中合作；血魔大君烧公爵府时奉命"旁观"（"莱托，他说得对。我还没尝过他珍藏的酒"）
  - 为救被血魔"赐福"成血傀儡的下坠士兵而暴露；被阿米娅拉住（莱托独白："他们叫你魔王，而我看见的……只是一个温柔的孩子啊"）
  - **第十二章**：配合萨卡兹发布诺伯特区"技术原因"脱城的声明（开斯特公爵赞其为"有意思的人"）；与变形者（假茉莉）共事（"去找老红眼病吧，他正开了瓶好酒等着你"）
  - 与戈尔丁摊牌：自救军情报"从一个懦弱的老师那里得来"——戈尔丁是泄露源头；其自我剖白："我不过是想……在接踵而至的毁灭中，活下来。可悲又懦弱，渺小又单薄。""起码……今天还没发生（流血）。"
  - **第十三章**：城防军被军事委员会解除武装；与克洛维希娅诀别（"我该如何拯救自己吗？"——拒绝合作）；被血魔大君召见时，以自身受污染之血"**赐予**"血魔大君——**牺牲自己污染其纯净血脉**（"我'赐予'你我的血，臭蛭虫！你再也没法夸耀你纯净的血液了！因为卑鄙的勒内·莱托污染了它！"）；死前探望昏聩的高卢老兵（"林贡斯青年近卫军……莱托下士"），哀悼戈尔丁
- 经典台词："等最后一代亲历者死去，我们对高卢的回忆就会和那个帝国一样随风而散……我们唯一能做的，就是尽可能抓住这些余烬。""我没有为自己选择任何使命……我不过是想，在接踵而至的毁灭中，活下来。""我'赐予'你我的血，臭蛭虫！……因为卑鄙的勒内·莱托污染了它！"
- 信息来源：第十一章（11-09/11-12/11-13）、第十二章（12-02/12-03）、第十三章（13-16）
