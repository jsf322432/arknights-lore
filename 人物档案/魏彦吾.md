# 魏彦吾（Wei Yenwu）

- 阵营：龙门（实际统治者，"魏长官"）｜身份：龙门最高决策者
- 首次登场：第二章「异卵同生」（2-2 谈判）
- 形象：慢条斯理、老谋深算、喜怒不形于色
- 关键信息：
  - 与凯尔希/罗德岛谈判：看重"实力"；提出两条合作条件（①解威胁+共享情报 ②善后协助，暂保密）
  - "我的要求不会超出罗德岛的能力范畴"；"罗德岛没有选择"
  - 拍板合作："恭喜各位，龙门信任你们。陈警官将全权负责和你们的对接事宜"
  - 对感染者态度：实用主义（"感染者自由行动会引起市民恐慌"，要求罗德岛服从近卫局）
  - **第五章**：幕后总策划——龙门"失守"实为**诱敌围歼之计**（提前转移物资、封堵路线、引整合运动入埋伏点）；赠陈**赤霄**（"斩龙之剑"，"该向谁出剑，就由你自己选择"）
  - **第六章**：**黑蓑**（秘密武装）的实际默许者（由林雨霞指挥）；回忆与结义兄弟的约定（托付女儿**塔露拉**——"你总不能连自己的妹妹也照顾不好吧"）；与陈的过去（"老公爵掳走她"的牺牲者）
  - **第七章**：陈与塔露拉的**舅舅**（陈/文月均以"舅舅"指代）；妻子**文月**；塔露拉之父**爱德华·雅特利亚斯**（结义兄弟，20 年前死于龙门——遗物线索）；被文月以罗德岛委托逼其让步；黑蓑听命于他
  - 与陈的过去：陈噩梦"现在，魏彦吾，你又要牺牲谁、牺牲什么？"（暗示他曾在塔露拉事件中做过牺牲）
- 经典台词："我所看重的就只有一点——实力。""我们该进入下个阶段了。""望龙门长治久安。""由你去让它能。"
- 信息来源：第二章 2-2；第五章 5-9、5-10；第六章 6-1、6-5、6-8；第七章 7-1~7-4；活动《多索雷斯假日》（提及）

## 活动《多索雷斯假日》补全（提及）

- **与坎黛拉**：十年前亲访后只靠信使往来（"她就是腻了，那座城市，不是什么好地方"——鼠王语）；"你见过坎黛拉，这个女人，陈晖洁和林雨霞，她们还太年轻，应付不来的"（对文月——最终"罢了，都依你"）
- **结局对话（与文月）**：看林雨霞的报告——"她们两个确实做得很不错。但我想，她们自己不会很高兴……坎黛拉这个女人的善意，我恐怕她们还不知道该怎么去承受。对这个女人来说，没有大是大非，只有结果"；文月："你说，小陈还会回来吗？"——"她会的。"

## 活动《春分》补全（身世重磅）

- **=四十年前离开百灶的皇子（当今真龙/炎武的兄长）**（"四十年前……离开百灶，整整四十年了""看来胞弟是准备把许多件旧事，一并了了"）；**四十年前真相**：老真龙晚年生矿石病/政举失偏——魏彦吾（皇子）带**赤霄剑**入宫劝谏（太师支持——"有太师相助，兄长最终还是走进了那座禁城，带着赤霄剑。六军辟易，无人敢挡"）——老真龙驾崩之夜/魏彦吾下落不明（成龙门总督——文月："没有人会记得一个为民请命的大臣，只会有人记得一个弑君弑亲的皇子！"）；"爱德华，妹妹，先师……胞弟"（他亏欠的人）
- **《春分》**：收到真龙请柬（禁军送信/赴百珍宴——文月拦阻："这次换我来保护你"）；嘱托文月（"陈家老宅的书房里，藏着一个柜子……依着上面的交代，可保龙门安稳"）；**赴百灶**（影卫随行——"在这里死去的，皆是我们的兄弟"——四十年前随其出京的禁军）；被**陈**拦路（"好久不见……魏彦吾……舅舅""母亲的事……姐姐的事……不能说与你的过往无关"——陈想亲眼看看往事如何收场）

## 活动《相见欢》补全（重大进展）

- **=炎武（真龙炎礼的兄长）**：太傅密会（"后手"=备位真龙——"国不可无君……兄退弟进"）；**失踪**（屏退影卫后前往禁城——陈追寻）
- **与陈的剑斗**：魏彦吾想**自我牺牲**（以"不反"为代价消灭岁兽——"这是炎国可以接受的最小代价"）；陈以"天喟"化解其"天瞠"（"你终究还是后悔了""死不能让你弥补一切""别像小塔那么做"）；陈的"天喟"之名（魏彦吾起名）
- **救炎礼（兄弟和解，重磅）**：从坍塌的"不反"密室中救出真龙（"炎武？……别说话，跟我走"）；"唯独是你……不曾于大炎有愧。炎礼……你可以放下了。你应当放下了"（炎武对炎礼——兄弟和解）；回忆（炎景公主——胞妹——"她是那样坚决地央求我回到百灶……她相信所有事都能够有个解释，'手足之间不应当有误会'""她只是说她会留在我身边，直到有一天，我愿意回到百灶，与你说清"——**炎景公主促成兄弟和解的关键**）
- **与太傅**："太傅所言，不可尽从……事情根本不该走到他所言的那一步。我另有打算"
