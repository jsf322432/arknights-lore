# 白金·欣特莱雅（Platinum / 欣特莱雅）

- 身份：无胄盟"**白金大位**"（弓箭手）；后叛逃、随罗德岛离开卡西米尔（干员"白金"）
- 首次登场：活动《长夜临光》（act13side）
- 关键信息：
  - 无胄盟白金大位（"能带领队伍/统筹全局"型）；敏锐视力（父母："她敏锐的视力一定会为家族带来荣耀"——"现在，她荣耀吗？"）
  - 厌战情绪（"每个月提个十七八次请假申请""又是对孩子出手，又是要和耀骑士扳手腕……真不想工作"）；放走瑟奇亚克的儿子（"没必要听他的话，去对一个孩子动手"）
  - 任务：绑架玛莉娅逼耀骑士认输（被红松骑士团/托兰所救）；刺杀博士未遂（被博士以"商业联合会临时成员"身份化解——"他们真正害怕的，是在同一张桌子上，盯着他们的饿兽……他们害怕的，是自己人"）；发现**耀骑士的体检报告——她不是感染者**
  - **《玛莉娅·临光》（前史补全）**：最年轻的白金大位（师父=前任白金，因爱上目标被同僚射杀——"那个爱上目标而试图背叛我们的可怜人"）；拦截老骑士弗格瓦尔德/科瓦尔（"你们都是出色的卡西米尔人，就不能乖乖离开吗？"）；执行恰尔内流放（恰尔内请求灭口瑟奇亚克之子）；奉命监视耀骑士（玄铁警告"不要对耀骑士身边的萨卡兹出手"——赦罪师/罗德岛背景）
  - **叛逃**：无胄盟（罗伊/莫妮克/玄铁）计划摆脱联合会，欣特莱雅作为"替罪者"被追杀（"我还能被利用多久？"）——"得……逃走……"；逃至零号地块，被罗德岛（砾/芙蓉/Touch）救下，随舰离开卡西米尔（"苦日子要开始了……我还是第一次登上这样的陆行舰"）
  - 师父（上一任白金）因爱上目标叛逃、被玄铁钉死在烂尾楼墙上（罗伊叙述）
- 经典台词："卡西米尔就像一座塔，从底层仰望那盘旋向上的楼梯的顶端，永远，望不见尽头。""我们还会回来吗？……不知道，没想过。但至少现在，只想要离开的吧。"

## 活动《红松林·索娜线》补全（身世/继任白金）

- **身世（重磅）**：玫瑰报业集团骑士海选亚军（冠军=金发库兰塔——"太过符合卡西米尔人对于库兰塔的想象"——内定冠军）；独立骑士生涯（**放水/花边绯闻/随意变动赛事安排**——"骑士到底是什么？商品吗？商品至少能买定离手后尘埃落定。那我呢？"）。
- **被无胄盟招揽（重磅）**：电话（"你的箭能够洞穿大骑士领的夜幕"）——花店递箭（**军用规格三棱箭**，无厂商无编号）——测试=射杀羞辱她的无礼库兰塔——成为无胄盟一员；**白金大位的学徒**（师父教她管理/领导/调配/指挥）。
- **继任白金（重磅）**：**前任白金因爱上目标叛逃、为保护目标而死**（青金："'白金'已经死了，死在他叛逃的路上"）；青金把"白金"徽章塞给她（"你不说，我就算你默许了。新工作要好好干哦，小白金"）——成为**新任白金大位**。
- **白金的工作（重磅）**：商业联合会董事的"电话"（"你永远不知道属于商业联合会的电话会何时响起……而白金，没有拒绝的权力"）；任务=让辉煌盾工业董事长"不列席董事会议"（扭断脖颈——**商业联合会内部清洗——董事=傀儡**）；"这双手经由商业联合会，延伸到整个卡西米尔"——**卡西米尔高塔意象（商业联合会=幕后之手）**；st01 对感染者任务的反感（"感染者会哭吗？""我不是很喜欢这个任务"）。
- 信息来源（补）：活动《红松林·索娜线》（act9mini st07）
