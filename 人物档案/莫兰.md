# 莫兰（Moran）

- 阵营：塔拉流民（感染者）｜种族：（塔拉人）｜身份：失明的感染者女性（夜盲）；"卡迈河谷的吟游诗人"
- 首次登场：活动《照我以火》（act22side）
- 关键信息：
  - **身世**：感染者（矿场/工厂感染——"将塔拉人撵去危险的地方工作的工厂老板，自己也是塔拉人"）；被感染者街区驱逐（"整个感染者街区的人一起被驱赶出了小镇……更健壮有力的那些，抢走了大家身上所有的物资"）；多年前饥荒中眼睛受损（夜盲——"她的眼睛在几年前那次饥荒里就坏了，夜里看不见路"）；歌谣"笼罩溪谷的雾霭啊……将她远行的身影遮蔽"（"卡迈河谷的吟游诗人"——曾被追捕者记得）。
  - **《照我以火》**：跟随流民队伍（维恩照顾）；决定加入苇草（"他们都说我活不久了……可我不想这样""我想，抓住我生活里难得的选择机会"）；战斗中保护同伴（火把烧伤士兵/断剑刺击——"塞尔蒙，留下我就好"）；塞尔蒙牺牲时引路（"分不清自己摸到的是黏稠的血还是潮湿的泥"）。
  - **成长**：从"逆来顺受"到觉醒（"以前我一直想，生活就是这样子……只要肚子饿了，闭上眼睛就咽下去了"→"我不想再听这种话了"）；结局与苇草同行（"苇草，你也在想，塔拉人到底是什么？"——身份之问）。
- 经典台词："笼罩溪谷的雾霭啊……将她远行的身影遮蔽……"（歌谣）"我不想再听这种话了。""我想，抓住我生活里难得的选择机会。"
- 信息来源：活动《照我以火》（全文）
- 后续：随苇草（塔拉人觉醒之路——"我们还没有帮到其他塔拉人，就死在同样想救塔拉人的深池手里，多遗憾"）
