# 阿尔图罗（Arturia / 通缉犯·大提琴手）

- 身份：**拉特兰通缉犯**/大提琴演奏家；费德里科的远亲（幼年曾寄住她家）；莱塔尼亚线关键人物
- 首次登场：活动《空想花庭》（act26side，正式登场；《吾导先路》中由费德里科线索引出）；《崔林特尔梅之金》（act29side，核心角色）
- 关键信息：
  - 源石技艺=**演奏/映照情感**："我不过是依照我的意愿自由演奏……我的音乐只是一面镜子"——以琴声浮现、放大他人的情绪与记忆，**引导而非操控**（克莱芒："她又怎么可能真的干扰我们的意志，替我们做出这些选择呢？"）；费德里科称其"源石技艺又一次引导了他人的死亡"
  - 幼年（费德里科视角）：能听见"被关在大人们身体里面的声音"（"那么多声音在哭，那么多声音在笑……一齐涌过来"）；曾惧怕大提琴（"它是我的眼睛、耳朵和喉舌，是我的心脏。只是说来惭愧，我曾经，对它感到惧怕"）；母亲葬礼上的演奏（"我让所有人释放了藏在心中的情感。那是我第一次发现，人们会那么轻易地在我的旋律中沉沦"——"可我并不欣喜。与之相反，我感到失望"）
  - 《空想花庭》：潜伏安布罗修修道院给孩子们讲故事；为主教斯特凡诺、花匠克莱芒演奏（见证绝望者的抉择）；被莱塔尼亚选帝侯使者接走——"演奏从未停止，只是你听不见"
  - 《崔林特尔梅之金》：为画家希曼/格哈德等"巫王之死"见证者演奏（送葬）；从见证者（希曼/洛里斯/布兰特/格哈德/珂拉）的情感深处**拼凑出"巫王的遗言"**；越狱登塔演奏，开启荒域
  - **荒域觐见巫王**：求证"一种理想的未来"——"所有人都应拥有强大的心灵，所有人都应能'共感'"（超越拉特兰律法/金律乐章的普遍情感联结）；巫王点破其"唯一真实"——"你将自己变成了容器……你无比接近，混沌"（"你恰恰是离答案最远的人"）
  - 荒域中失去乐声（"我丢失了我的乐声"）→**第一次演奏自己**："我感受着自己，费德里科。此时此刻，唯有我心怀希望，我才能还给人们希望；唯有我爱，我才能还给人们爱。我愿以这微末的自尊，联结所有的，悲与喜。"——以情感联结被虚无侵蚀的众人（费德里科协助）
  - 结局：随费德里科回拉特兰（教宗之命/双边协议——"当有需要的时候……阿尔图罗·吉亚洛会回到莱塔尼亚"）；"赫尔昏佐伦从未征服过死亡，但他将自己一生的情感镌刻于虚空之上""我们的始源也是终点，我们的能力即是桎梏"
  - 与费德里科："终有一天，杀死阿尔图罗·吉亚洛的一定是费德里科·吉亚洛。可你觉得……白日能杀死黑夜，秩序能杀死混沌，理性能杀死感情吗？""最理性的你，届时也最适合作为我的行刑人"；"从过去到现在，我都没有主动选择过离开拉特兰。我只是并不认同律法所代表的秩序。至于共感……它的局限，正是我对未来所有想象的起点。"
  - 《众生行迹》（拉特兰）：在兰登修道院（监狱职能）服刑后越狱（纸蜻蜓音乐术式）——调查"失踪的孕妇"（怀孕的木攀兽母亲，被牧首接入育婴圣堂）；与费德里科合作调查梦境异样；被教宗嘱托（"你这样的异类，到那时或许是一剂良药，或许是一剂毒药"）
  - 迷宫前转身："但不是每个人都对拉特兰的'真相'和'意义'那么有执念的……此刻，拉特兰有几百万值得倾听的心声"（去引开敌人/倾听众生）；"再见，我亲爱的弟弟"
  - **PCS 被毁（萨科塔失去共感）后**：以琴声联结失去共感的同胞——"让不再能共感的这万千同胞们，可以无所保留地，纯粹而坦诚地，'交流'……这只是我，存在于此的意义"；"拉特兰啊，洁白的圣城即将沉入黑夜……阿尔图罗决定向夕阳奏乐。尽情地。"
  - 白垩的老师（《尘影余音》伏笔）：曾教流浪大提琴手白垩（"头发很长的萨科塔大姐姐，穿的衣服很素净"——白垩记忆）；《尘影余音》中在远处聆听《光影》首演（"我曾经的学生……我在教你如何用提琴说话时，就听到了你命运的主题……向你们致敬，我熟悉或不熟悉的人们。聆听，这就是我向你们献上敬意的唯一途径"）；《崔林特尔梅之金》："除了你之外，我还教过一个学生……他发出了呐喊……并不比那位与他同姓的大音乐家逊色多少"（白垩/巫王血脉）
- 经典台词："我的音乐只是一面镜子。""费德里科，你学会哀怜了吗？""我们必须变得强大，而无从消弭的脆弱，也应有容身之处。""光亮恒常，黑暗才是暂时的。""而我们的情感呢……悲哀与喜悦都只存在于生命的某一刻，但我们无时无刻不在感受着一切的发生。所以它们从来不曾真正消失。……就像晚霞，从未离开这片天空。"
- 信息来源：活动《空想花庭》（全文）；活动《崔林特尔梅之金》（全文）；活动《吾导先路》（线索）
