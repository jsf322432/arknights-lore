# 莱欧斯（Laios）

- **身份**：《迷宫饭》主角/穿越者——**剑士/魔物狂人**；法琳（Falin）的哥哥；迷宫冒险者小队队长
- **穿越（活动《泰拉饭》act36side）**：与玛露西尔/森西/齐尔查克误入泰拉（"我们可能是误打误撞来到了迷宫不为人知的新区域"）；目的：找到回家的路——**救回被炎龙吃掉的妹妹法琳**（"我们的目的是赶紧去救法琳"）
- **性格**：魔物狂热（见到任何未知生物都想"研究/尝尝"——"说不定还能试试它们的味道？！"）；不按常理出牌（用"咯——"的姿势证明自己身份/用杏子驯化墨魉）；天然呆（得罪人而不自知）
- **经历（act36side）**：
  - 大鲍勃源石虫农场：学源石虫料理（"好好吃！"）；获《鲍勃的美食指南》
  - 萨米：吃下**被邪魔污染的角兽肉→坍缩**（"脸上覆盖虚空"、失去自我念叨"回家"向北走）——被齐尔查克/刻俄柏追回
  - 婆山镇（夕的画卷）：与墨魉交朋友（阿咬/小躁/偷闲——"嘎嘎语"交流；发现墨魉会死而复生）；**点破画中境**（"墨魉们甚至没有被我们找到一个'窝'……就好像这里的一切都是'假的'一样"）；被夕扔出画卷
  - 盐风城：随教士去海嗣溶洞（"跟着他所谓的'指引'，总能发现点什么吧"）
  - 罗德岛：对干员们做"生物研究"（"你会下蛋吗？""猫人和狗人生下来的孩子是猫还是狗？"——干员们集体后退）；被 Mon3tr 吓到；参加森西的大餐
- **经典台词**："好想研究一下。""你会下蛋吗？""这简直是天堂……"（看到各种种族干员）
