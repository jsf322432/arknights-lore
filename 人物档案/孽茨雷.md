# 孽茨雷（Niezhrale / 食腐者之王）

- 身份：**食腐者王庭之主**；萨卡兹最古老的战争领袖之一，人称"战争之神"；爱国者（博卓卡斯替）的师父
- 首次登场：第十三章（食腐者军团）；第十四章正式登场
- 关键信息：
  - 以"死亡"巫术支配战场（"灵幛"/枯枝王座；数千座战争祭坛汲取死亡）；"最强大的食腐者，也是最恐怖的战争祭坛"
  - 与威灵顿公爵对决（"加斯特里尔"号 vs 枯木王座）：互有胜负（"你向我证明了，战争的前进。两百年前，还没有维多利亚人能坚持到这一步"）
  - 与 Logos 决战：被斩右臂（"特雷西斯的剑术……"）、被"腐朽归于腐朽"之咒压制；称 Logos（哀珐尼尔）"作为战士，你合格了"
  - **爱国者（博卓卡斯替）是其最欣赏的学徒**（"他是那样天赋卓绝……可惜他离开了卡兹戴尔，又死在一场异国的阴谋中"）
  - 特蕾西娅死后：宣称"她兑现了她的承诺……'阿喃那'已绽放，命运已握于我们手中"；继续战争（"维多利亚的哀悼，我亲自替她来取"）
  - 史观："战争如巨石，而萨卡兹注定站在深渊中。石头永远会一次次落下。"
- 经典台词："我们要令维多利亚人知道，战争的主宰——定将主宰战争。""战争如巨石，而萨卡兹注定站在深渊中。石头永远会一次次落下。""卡兹戴尔的下一位英雄……在哪里？"
- 信息来源：第十三章、第十四章（14-01/14-06/14-07/14-09/14-10/14-18/14-20）
