# 祖拜尔（Zubayr / 祖巴伊达姆-亚努尔-阿尤苏）

- 阵营：沙阿（路加萨尔古斯）｜种族：（萨尔贡人）｜身份：万王之王之子/御前护卫军官；沙阿宝库的守护者（长生军）
- 首次登场：活动《太阳甩在身后》（act35side，"无名将领"古尸）
- 关键信息：
  - **身世（重磅）**：路加萨尔古斯之子（沙阿之子）；御前护卫军官（"兴盛之时，我是万王之王路加萨尔古斯身边的御前护卫军官"）；姐姐=史官（持白色莲花/编撰萨尔贡史籍——"我打算编撰一部史籍，记录下那些被遗漏的前代事迹"；"我腹中的孩子也会继续……终有一日，它会告诉后来人"——佩佩=姐姐的后裔/相似者）。
  - **宝库守护**：父亲失踪后（"父亲不知所踪"——在焚风热土挑战"无形之敌"），路加萨尔古斯把宝库地址交给祖拜尔（"他让我等待梦魇的后裔，将其中的一切尽数给予他们"——与哈兰杜汗的誓约）；自愿接受长生军改造（"一位来自阿尔萨兰的宝石匠人告诉我，他可以通过篆刻特殊回路的宝石保留我的意识……制作长生军的工匠们也愿意为我打造另一副躯壳"——"我不想永远躺在床铺上"）；五颗宝石分散记忆（"分割我记忆的人将有关宝库位置的信息打乱"——被王酋军剖胸取宝石后落入博物馆）。
  - **《太阳甩在身后》**：被佩佩唤醒（模仿动作→恢复语言→恢复意识）；释放宝石构装体（复原沙阿时代的米纳特哈玛仪——城市将被黄沙淹没的危机——"我必须那么做，这是我的职责"）；与拉恕尔相认（"你们自由了"——原谅告密工匠的后裔）；请求（"如果那位梦魇当真是哈兰杜汗的后裔，我将应沙阿之诺，为她打开宝库"）；带佩佩进入宝库（米纳特哈玛仪地下——"父亲离去后，我将他的衣冠冢修建在他的宝库最深处，这间宝库亦是他的陵寝"）；**安息**（"祖拜尔已经安息并离开"——展示完宝库后）。
  - **能力**：沙土源石技艺（叉铃——"黄沙倒流"/瓦解墙壁/复原建筑）；宝石间引力感知；"躯/名/格"理论（暗阑时代——源石回路宝石保存"格"）。
  - **性格**：温和/怀念（"我想看一眼太阳升起的样子""我问候你，哈拉赫特"）；对佩佩（"你不能再将我当作文物来看待，我的行为与想法受我自己控制"——自主意志）；"我已经苏醒……至少此刻，我并不想那么快回忆起自己的过往"。
- 经典台词："你问的是贝亚德帕夏……""我问候你，哈拉赫特。""你们自由了。""我不想要一只会飞的羽兽……"（无）→ "我遇到了一个孩子，我觉得她能帮我。"
- 信息来源：活动《太阳甩在身后》（全文）
- 后续：已安息（宝库真相交给佩佩/沙阿后人）
