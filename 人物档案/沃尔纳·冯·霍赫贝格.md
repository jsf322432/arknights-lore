# 沃尔纳·冯·霍赫贝格（Werner von Hochberg / 施彤领选帝侯）

- 身份：施彤领选帝侯；薇薇安娜之父；露辛达·德罗斯特的爱人；珂拉/布兰特/阿尔图罗的故友；1100 年遇刺身亡
- 首次登场：活动《崔林特尔梅之金》（act29side，回忆/遗案）
- 关键信息：
  - 与露辛达：在金盏花小巷（卡尔·施密特街）诗会上相识相爱（"一个平民出身的年轻姑娘鼓起勇气，念了一首自己写的小诗"）；**"十分钟的错过"**——巫王死后被召回施彤领继承选帝侯，若多等十分钟就能见到前来相会的露辛达（"这十分钟……成了沃尔纳一生的遗憾"）；露辛达后来仍赴施彤领（沃尔纳已另娶，别无选择），13 年前病逝
  - 诗人梦：梦想成为诗人（"他没能留下什么句子，但这依然是一个诗人书写自我的方式"）；每周在固定夜晚去高塔探望薇薇安娜（教她乐器）；病重时托珂拉/布兰特保护女儿（"他担心自己走后，你会沦为权力斗争中的牺牲品"）
  - 与金律乐章副本：施彤领保管的金律乐章副本"是沃尔纳对双子的承诺"（"无论是转移乐章，还是丢失乐章，施彤领都难辞其咎"）；深知残党觊觎——**以死保全所爱之人与霍赫贝格家族**（"他早已病入膏肓，等待着死亡来领他与露辛达团聚。不过多活几天而已，不值得牵连施彤领……还有你"）
  - 遇刺：1100 年被贴身侍从刺杀（精神类源石技艺影响——残党"首席"（珂拉）案）；对外宣称病故；珂拉："他离开得太决绝，放弃得太轻易，又太无可奈何。"
  - 与阿尔图罗：朋友（"除了大贵族的身份之外，他也是个敏感浪漫的艺术家，我们常就音乐展开交流"）；数月前派使者请阿尔图罗"在琴声中再见见心爱的人"（露辛达与薇薇安娜）
  - 与弗莱蒙特：风暴城的小子（"说什么会用自己的命来践行诺言"——弗莱蒙特语）
- 经典台词："他应该动用了自己在施彤领和崔林特尔梅的所有人脉……割舍自己所拥有的一切，并不容易。"（薇薇安娜）"他永远看不到金盏花再一次盛放。"
- 信息来源：活动《崔林特尔梅之金》（全文）
