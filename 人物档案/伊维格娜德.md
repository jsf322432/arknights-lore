# 伊维格娜德（Ivgenad / 白塔女皇·"永恒恩典"）

- 身份：莱塔尼亚**双子女皇**之一（白塔/"永恒恩典"）；本名**莉泽洛特**；诞生于术式的双子（弗莱蒙特提供塑造术式）
- 首次登场：活动《崔林特尔梅之金》（act29side）
- 关键信息：
  - 双子真相："我和希尔德加德身体里有他的术式。我们俩是被制造出来的，对付他的兵器"；23 年前与赫琳玛特攻入巫王塔亲手杀死赫尔昏佐伦（"杀至王座面前的只有那一对双子"）
  - 性格：温和仁爱（"莉泽洛特从不赞同我的做法。她总在我的耳边说，太过激进的手段会使得人类逆反"）；把崔林特尔梅的街道/喷泉设计成乐器（"水花并不是随着旋律而跃动，是流动的水本身奏响了这首曲子"）
  - 《崔林特尔梅之金》：任命薇薇安娜为女皇之声（沃尔纳遗愿）；放任珂拉的计划（"一个看似弱小的人……说不定能做到赫尔昏佐伦都做不到的事……重新定义莱塔尼亚"）；与赫琳玛特合奏迎战巫王（盾）
  - 结局：始源之角崩塌时"撑起了盾，护住了双塔和双塔下的万民……除了她（赫琳玛特）"；赫琳玛特留荒域后成为**唯一发声的女皇**——"我要令我们所见的这片晚霞恒久不变""永恒恩典"（"崔林特尔梅之金"）；与教宗谈判（拒绝引渡阿尔图罗/接受"灾难"警示）
  - 与赫琳玛特：彼此心意相通（"我们决定了自己的命运"）；赫琳玛特擦肩而过的最后一句话是"祝你能如愿拥有这片晚霞"
- 经典台词："变化……变化未必都是坏的。要不然，我们甚至都不会出生。""我永远是你的盾，于你，于莱塔尼亚。""希尔德加德，等我们再一次杀死赫尔昏佐伦，你想做什么？"
- 信息来源：活动《崔林特尔梅之金》（全文）
