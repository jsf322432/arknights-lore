# 鼠王（林舸瑞 / 林）

- 身份：龙门贫民区的实际掌控者（"鼠王"）｜**林雨霞之父**｜魏彦吾老友（"灰色的林"）
- 首次登场（提及）：第六章；正式现身：第七章末/第八章；活动《喧闹法则》（完整前史）
- 关键信息：
  - 经营贫民区数十年（"贫民区是他父亲的心血"——林雨霞继任黑蓑指挥）；沙尘/流沙源石技艺（"这么多年了，胆敢直接近身对我舞刀弄枪的人可不多"）
  - 与魏彦吾是故交（"二少爷"——魏彦吾家族排行）；与魏彦吾的协议（"你将龙门夺回我们手中的时候，我答应过你，我会待在魏彦吾的阴影之中"）；"龙门有龙门的律宪，我有我的规矩"
  - 《喧闹法则》（安魂夜）：布下棋局清扫叙拉古黑手党（"敲碎岩石固然困难，但掬起一捧沙，轻而易举""我并不需要你的忠诚，自始至终"）；"假死"大帝（苦肉计）；"活着的人们热热闹闹的，亡魂才能没有遗憾地离去"
  - 与董阿伯（老友/魏彦吾救命恩人）的告别（"鼠王还活着，轮不到你们送死"）；女儿之约（"我会坚持到龙门足以失去鼠王的那一天。那是我的女儿真正长大的那一天"）
  - 第八章：以命拦阻魏彦吾亲赴核心城（"拦到我死——或者拦到核心城被停下""如果要我看着你像二少爷一样自己送死，不如叫我先死"）
  - 感慨塔露拉："塔露拉，塔露拉……难道说这真是命数？"
- 经典台词："我们的时代已经过去了，魏彦吾！""晖洁……小心啊，晖洁……千万别把命送了！""龙门并不能代表我。""活着的人们热热闹闹的，亡魂才能没有遗憾地离去。""再大的风也吹不动百年的树。""没见过另一条路，就不能算自己的选择。"
- 信息来源：第六章~第八章；活动《喧闹法则》（全文）；活动《登临意》（全文）

## 活动《登临意》补全

- **随女赴玉门**：得知林雨霞领了魏彦吾的任务（彻查玉门巨兽信徒），暗中跟随（"你领了魏彦吾的任务，我总得跟过来看看"——"我就是用尾巴尖都能想到，魏老二用的是哪一套说辞"）；委托老鲤照应女儿（"她要是想留下，龙门自然有她的安身之所……无论她选哪条路，我都想拜托鲤先生，能给她一些照应"）
- **天灾中出手**：玉门迎击超规模天灾时，以沙石源石技艺相助钦天监术师（"操弄了几十年的沙子，要是这种时候再派不上一点用场，我这把老骨头还真不如就地埋了算了"）——**重伤咳血**（"四波源石尘暴，林先生在法阵中心，分担了大半的冲击"）；"再大的风也吹不动百年的树"
- 对林雨霞："没见过另一条路，就不能算自己的选择""但愿这次能早些了事，不耽误你去维多利亚的行程"——林雨霞结局选择回龙门留下
