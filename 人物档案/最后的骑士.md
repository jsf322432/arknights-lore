# 最后的骑士（The Last Knight）

- 身份：**卡西米尔骑士**（海嗣化的人形海嗣）；坐骑**罗辛南特**（海嗣）；"击碎巨浪"的疯狂执念者
- 首次登场：活动《愚人号》（act17side）；《长夜临光》提及（"最后的骑士"传说/逐魇骑士梦魇线呼应）
- 关键信息：
  - 卡西米尔骑士（冲锋姿势/库兰塔骑士特征；"你是卡西米尔人？——骑士！"）；"罗辛南特"为坐骑之名（嘶鸣回应）
  - 海嗣化（"他眼中敌人全非活物，冲锋目标只有群峦、城市和波涛"）；"击碎海浪。踩着白昼，斥责痛苦"；"巨浪将至，我们等待""我不允许，海，再有丁点涟漪"
  - 与深海猎人交手：被歌蕾蒂娅击退（"他只是比我想象中要更结实一些"）；对灯塔无执念（"这不是巨浪"）；追猎海嗣（"同类，聚集。驮起方盒，远去。我们跟上，找到暴风的尽头"）
  - 结局：与乌尔比安同行（"巨浪即将来临。我们战胜巨浪。我们，即是巨浪"）——乌尔比安："你在疯狂中窥见的目标，还真是过度雄伟"
- 经典台词："我不允许，海，再有丁点涟漪！""我们，即是巨浪。""击碎……海浪。踩着白昼，斥责痛苦。"
- 信息来源：活动《愚人号》（全文）
