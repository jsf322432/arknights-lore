# 甘比诺·里奇（Gambino Ricci）

- 身份：**叙拉古黑手党首领**（甘比诺家族）；从叙拉古败退逃来龙门；反派
- 首次登场：活动《喧闹法则》（act5d0）
- 关键信息：
  - 叙拉古失败后逃来龙门（"在叙拉古的失败之后，我就明白，我们不该放过任何一个机会，要不择手段地摧毁敌人"）；与卡彭（在龙门经营多年的副手）理念冲突
  - 计划："绑架拜松，分裂企鹅物流和峯驰物流，刺杀大帝"；"能靠死人解决的问题，就不要让活人互相扯皮"
  - 与鼠王对抗（"你只是坐在下水道里的王座上……"）——被鼠王流沙镇压；被卡彭刺杀（"该结束了，甘比诺"）
  - 结局：逃亡中被拉普兰德追击（ex02）
  - **《新沃尔西尼狂欢节》（续篇）**：与卡彭投靠威尼斯载具公司（安东尼奥手下）；"西西里人"的执念（"它没经过老子的同意，就成了老子的标签！……叙拉古必须承认甘比诺·里奇，他是个西西里人！"）；被拉普兰德收编（劫持陆行舰/换掉港口调度员——"调度员"伪装（原调度员被灭口））；放过卢奇诺（"小子，说真的，我有点喜欢你了。你让我想起了年轻的时候"）；结局市民积分清零、与卡彭重新开始（拉普兰德留黄色出租车——"要花多久的时间，才能在这座城市开起一家出租车公司？到时候名字就叫'西西里'"）
- 经典台词："能靠死人解决的问题，就不要让活人互相扯皮，对吧？""这一次，我宁可像一个真正的西西里人那样死在这里，也绝不会让敌人看到我夹着尾巴逃跑的背影。""叙拉古必须承认甘比诺·里奇，他是个西西里人！"
- 信息来源：活动《喧闹法则》（全文）；活动《新沃尔西尼狂欢节》（全文）
