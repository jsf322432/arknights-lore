# 真龙 / 炎礼（Emperor / Yanli）

- 身份：**大炎当今真龙**（本名**炎礼**）；魏彦吾（炎武）的胞弟；太师/颉的学生；"炎氏"血脉
- 首次登场：活动《春分》（act40side，帷幕后的身影）；活动《相见欢》（act49side，正式登场）
- 关键信息：
  - **身世（重磅）**：本名**炎礼**（"炎礼……你可以放下了。你应当放下了"——炎武语）；**魏彦吾（炎武）的胞弟**（四十年前魏彦吾带赤霄剑入宫劝谏/老真龙驾崩/魏彦吾消失——炎礼继位）；太师的学生（"世事诡随，谨致良知"——太师教诲）；与颉（"她是炎国的三公之一……也是我的老师"——太师；颉=太师的学生/炎礼同门）
  - **四十年前的往事**：老真龙晚年（矿石病/政举失偏）——炎武（兄长）与太师阻止真龙——老真龙驾崩之夜（炎武带赤霄剑入宫）——"太师使皇子弑君"（史书——冤案）；炎礼继位（"牺牲一人，换得社稷稳固，天下人心安定"）；**炎景公主**（炎武炎礼的胞妹/陈的母亲）——"她是想劝自己的两位哥哥……重归于好"
  - **《春分》**：准许望入岁陵（"我的子民有冤屈，我准许他去申诉冤屈"）；与煌的对话（太师的故事——"别忘了他们"承诺/百灶下雪——沉冤昭雪）；开启岁陵
  - **《相见欢》（重大）**：与太尉约定望日伐岁限期；决定**亲自启动"不反"**（"如果大炎当真有非流不可的血……那也应当……从真龙始"）；自我赦罪（"也赦我自己，昏庸不明，致使亲子相疑、骨肉离散、朋党为祸、国家动荡之罪"）；面对"新的岁"（望）——"若你是新的岁，我便以身为炎除害。若你是望……我仍然会遵守诺言，放你一命，赦你过去的欺君之罪……和现在的，弑君之罪"；被炎武（魏彦吾）救出（兄弟和解）
  - **理想**："我那时最大的理想，是希望在有生之年，能够修完前人未能完成的，大炎境内的水文图志""我曾经也真的以为……我可以在这座天镜阁里终老一生。这应当是我最好的归宿"
  - **与太尉**：太尉（主战）逼伐岁/太尉想用书刀改史（让"不反"认定魏彦吾）——炎礼拒绝（"比起与岁兽这一战可能要损失的军队将士……大炎更不需要的，还是一个垂暮真龙……还有这个，千年来只在真龙之手的权柄"）
  - **"不反"**：真龙权柄（源石装置——只有在位真龙能用/全力启用需以性命为代价——镇压岁兽）；炎礼曾视察"不反"（四十年前登基时——"有这等神物，在炎国传了千年，也不曾有一位真龙开启过'不反'。如果在我手中，大炎沦至需要使用'不反'的地步……那我便是大炎第一号无能之君"）
  - **与陈**：陈=炎氏后裔（外甥女辈）；陈与真龙之女（下一任真龙）——传承
- 经典台词："如果大炎当真有非流不可的血……那也应当……从真龙始。""也赦我自己，昏庸不明，致使亲子相疑、骨肉离散、朋党为祸、国家动荡之罪。""人也好，巨兽化身也罢，都是我大炎的子民。我的子民有冤屈，我准许他去申诉冤屈。"（春分）
