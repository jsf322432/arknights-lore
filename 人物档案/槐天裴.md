# 槐天裴 / "槐武痴"（Huai Tianpei）

- 身份：槐琥之父（失踪十多年）；武痴（"天下武功，都是搏杀之术"）；玉门医馆伙计（三年）
- 首次登场：活动《登临意》（act23side）；《龙门/槐琥线》被提及
- 关键信息：
  - **武痴**：追求武学巅峰（"追求武学巅峰是他的道"）；与梁洵/老鲤是结义兄弟（三兄弟：槐天裴/梁洵/老鲤——"欲买桂花同载酒，终不似，少年游"）；"我这辈子，能成一件事就够了"
  - **在玉门等宗师比武三年**："他答应与我比武——短则三五年，长则十余年，他是这么说的"；在医馆当伙计（欠债还钱/帮医生干活抵账）；护截云（"先养伤，再还医药费"）
  - **《登临意》**：与宗师比武（第十合——"他练了四十年，就能胜过你一拳"）；**宗师托付佩剑**（"你是从古至今，唯一一个赢了我一拳的人""把它当作他日我们再战的信物""等我再练四十年，再来找你"）；与槐琥重逢（父女拆招——"你教了我许多。可我不是在追赶你""我总会练得比你更强"）；以拳击退睚（"我这双拳头打不坏的东西，剑也未必好使"）
  - 与槐琥：失踪十多年（"我当不好丈夫，也当不好父亲"）；槐琥拒绝原谅（"既然这十多年，你都没出现过，那今后也不必再出现了"）
- 经典台词："我练了四十年，就能胜过你一拳。那我再练三百六十年，就能彻底胜过你！那时我就是天下第一！""这世上，我这双拳头打不坏的东西，剑也未必好使。""欠了债，总是要还的。"
- 信息来源：活动《登临意》（全文）；活动《怀黍离》（提及）；活动《春分》（提及）

## 活动《怀黍离》补全

- **被绩的幻象戏耍**：绩（"商队老板"）以幻象制造重岳/梁洵/老鲤/槐琥的幻影（"赢了你，我是不是就是天下第一？""你女儿的命，怎么样？"）——绩欲买其宝剑未果（"没得商量！"）；"心头血热，拳锋上还留有余温。登高临绝顶，毕生夙愿已然了却——不，不对！"（识破幻象）

## 活动《春分》补全（重大进展——疯了）

- **武疯子**：老鲤/槐琥循传闻找到槐天裴（"打遍武林，甚至多次故意伤人的武疯子""那个传闻中打遍武林，甚至多次故意伤人的武疯子，也实在没法想象会有第二个人了"）；山洞中疯癫状态（"沉重的拳头不住地砸在岩壁上……这个'山洞'，竟是被此人一拳一拳打出来的"）
- **疯语**："四十年……天下第一……我何时……""剑……不可给人……丢了……还是丢了！""女儿……不许伤害我的女儿！"
- **宗师佩剑=劫数（重磅）**：老鲤："难道那把剑，真的是劫数……？""梁洵啊梁洵……要是槐天裴有个三长两短，这笔账就只能记在你的头上了"（**梁洵/宗师托付的佩剑——封印岁兽十二分之一意识的剑侵蚀槐天裴心智**——衔接《登临意》托剑）；槐琥来唤醒（"或许现在只有你能叫醒他"）

## 活动《镜中集》补全（盗《武典》/对决"朔"幻象）

- **玉门闹事/盗《武典》（重磅）**：演武场打伤守军（"那疯汉闯到了演武场，不由分说就打伤了我们好几十号兄弟"——左宣辽认出槐天裴）；**军武库盗《武典》**（"宗师留下的那本《武典》……丢了"——信留书架——左宣辽送信司岁台/天师府）；与莫佚交易（"你帮我取来了这本书，我自然也会帮你——一场万众瞩目的擂台，让你和那位宗师，再好好打上一架"——十天后邙山山顶）；"有人的武功比我高，那就练到胜过那个人，天地造化比我深，那就练到胜过这片天地"
- **vs"朔"幻象（重磅）**："我弄丢了剑，我违背了约定，我不该见你。我夙愿未了，我命数有时，我必须见你"——**拳拳相交平分秋色**（"以拳对拳，以力敌力"——对"武"的化身"朔"虚影）；三十合（"他已经将武融进四肢百骸"——云青萍）；**槐琥呼喊"阿爸！！"**——"我想起来了"——**击碎幻象**——**跌下山崖**（生死未明——左乐派人搜寻）
