# 水月（Mizuki）

- 身份：**阿戈尔少年**（蓝发/无底胃袋）；"吃豆人队"（大胃王海选）选手；罗德岛干员（后续）
- 首次登场：活动《多索雷斯假日》（act12side）
- 关键信息：
  - **《多索雷斯假日》**：大胃王海选出线的单人选手（"外表人畜无害，却吃掉了我们一家餐厅仓库存量的食物，拥有着无底的胃袋以及与这片海洋相得益彰的蓝色头发"）；"玩腻了就把你们都吃掉哦"（参赛宣言）；被陈救助（"谢谢你帮了我""姐姐你是个好人呢"）——送赤金答谢（"我本来就不是很在乎比赛，能够认识陈姐姐这样的好人，对我来说已经很满足了"）
  - **结局（伏笔）**："这座城市里的人还真是无聊，比赛过半就不想跟他们玩了""要是早知道最后会变成这样，中途确认陈姐姐没事后应该和她一起上船的""算啦，反正这座城市也差不多玩腻了，看一看陈姐姐她们会去哪里吧。**陈姐姐来的地方，肯定也有许多和陈姐姐一样的好人吧**"——**加入罗德岛的伏笔**（衔接肉鸽《水月与深蓝之树》/深海线）
- 经典台词："陈姐姐来的地方，肯定也有许多和陈姐姐一样的好人吧。""玩腻了就把你们都吃掉哦。"
