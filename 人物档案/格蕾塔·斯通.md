# 格蕾塔·斯通（Greta Stone）

- 阵营：蓝卡坞（电影制片人）｜种族：斐迪亚
- 首次登场：活动《红丝绒》（act43side，2025）
- 关键信息：
  - **"我相信的只有自己的眼光"**：蓝卡坞从业二十年；剧本拍卖会上以六十万金券拍下《杜邦夫人之死》；邀请米兰妮/阿布纳/卢西恩入组（"我吃准阿布纳恨我但还是会加入剧组"）
  - **黑历史（蓝卡坞学院奖）**：年轻时贿赂评委被公开（"组委会公开了斐迪亚的所作所为……她失去了一切"）；用十年重回蓝卡坞（"我主动向命运讨要了一个玩笑……我不该怀疑自己"）
  - **劳拉坠亡案（五年前）**：压下警方案情/封锁电视台关注；给劳拉家人抚恤金；将阿布纳拍下的坠亡画面剪入电影（"我让她在电影中永生"）；"我难辞其咎。但忏悔，不是现在"；每年劳拉祭日去扫墓
  - **天灾实景拍摄**：拜访特里蒙大学天灾预测专家，设计地块与风暴擦肩的拍摄路线（"我们缺少的从来不是技术，而是胆量"）；"我会成为最后一个离开移动地块的人"
  - **《红丝绒》**：解散剧组/结算全部酬劳/向众人自陈罪责；请卢西恩担当主演；与莫伊拉对峙（"我从不怀疑自己的眼光"）；天灾中救出斯蒂芬（"怎么会有你这样的蠢货……她死不死，都不影响她是一个好故事的主角！"）
  - **结局**：让《杜邦夫人》上映（"我会让《杜邦夫人》顺利上映……然后我会去一趟警局，做我该做的事情"）
- 经典台词："我从不怀疑自己的眼光，自然也谈不上会放弃。""我只是由衷觉得……'杜邦夫人'，是值得我举牌的。"
- 信息来源：活动《红丝绒》（全文）
