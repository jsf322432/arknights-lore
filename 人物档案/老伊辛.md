# 老伊辛（Old Isin）

- 阵营：萨尔贡沁礁黑市（"沉睡的萨尔贡"庭院）｜种族：萨弗拉｜身份：占卜师（长生者）
- 首次登场：活动《凯尔希秘录》（act18d0，2022）
- 形象：神神叨叨（"老伊辛"自称）；谦卑（"老伊辛不敢，老伊辛不敢"）；"老到想象不到的地步"
- 关键信息：
  - **身世（重磅）**：**梦魇帕夏（库兰塔/梦魇后裔——伊巴特沁礁之城帕夏）门前的弄臣**；"沁礁之城"=伊巴特唯一移动城市（梦魇帕夏励精图治所建；"团结的象征，就是那座扬起漫天黄沙的城"）——天灾毁灭（帕夏疏散市民后痛斥天灾直至毁灭）
  - **长生者**："近乎无尽的生命"（以萨弗拉人平均寿命看异常长寿）；**记忆被梦魇帕夏的源石技艺扭曲**（"漫长的噩梦扭曲着你的思想……他几乎是试图在梦中拥抱过去"——帕夏的伟岸幻境令臣子沉醉；老伊辛遗忘了帕夏诉说的言语——"老伊辛罪无可赦。老伊辛忘了"）
  - **与凯尔希（22年前）**：为凯尔希/艾利奥特安排逃离萨尔贡（"沉睡的萨尔贡"庇护所/地下黑市/筹备物资）；**约定二十二年后以一枚金币支付**（"您要在二十二年后支付它……这个承诺比这枚金币更加值钱"）；"二十余年后，您将会带回一枚金币，带走这无助的魂魄"
  - **梦魇的梦**：反复梦见怯薛远征（"铁蹄拉开了一张腥红的网，他们扑向萨尔贡最南方最南方的地平线"）/"凯尔希的另一个姿态"（"当千百年前怯薛的远征粉碎了旧时代的时候，她就在那儿"——凯尔希长生者暗示）
  - **结局**：三年前消失于黄沙（"他消失在了黄沙之中，在三年前某个月明星稀的晚上"）——去寻找萨尔贡王都"**黄金之城**"（"等到那座永恒之城从风沙中显露面貌……老伊辛要找到那里"）
- 经典台词："老伊辛反复做着同一个梦……年轻的帕夏就站在老伊辛身边。……但老伊辛听不见。老伊辛忘记了。"／"老伊辛不敢死去，老伊辛只求您记得这件事情。"
- 信息来源：活动《凯尔希秘录》（act18d0）全文 14 段
