# 玛利图斯（Maritimus / 海嗣化）

- 身份：**阿戈尔人类学家兼先史文明研究者**（两百多年前失踪）；**斗智场设计者**；**深海教会最初的创立者**（后海嗣化）
- 首次登场：活动《生路》（act34side）
- 关键信息：
  - 地幔遗迹第四考察队核心成员（两百多年前失踪）；主持设计**斗智场**（"此处并无正义，唯有前路"箴言）；"理论推演能力极为出众，却很不喜欢自己得出结论"（怪脾气）
  - 地幔遗迹群最下层：见"巨物在深蓝的树影中沉眠"（前人类**生物方舟**/初生伊莎玛拉）；巨兽分享视界——**先史文明覆灭景象**（"坠落的城市、燃烧的大地、熄灭的星门……那是一切事物的终点"）
  - 觉醒与堕落：确认海嗣=存续希望（"在那个万物寂灭的未来里，有任何生命能以任何形式存活下来，都值得我以任何代价去争取"）→**吃下异种血肉**化海嗣；返回阿戈尔"死而复生"后以"几次诚挚的谈话"播下深海教会之种（"原始崇拜源于生命生存的本能"）
  - 对凯尔希/博士：寻求合作（"帮助大群理解，帮助大群进化"）；认出博士（"深蓝的洞穴，遗迹群中的无数所在，留有你的痕迹"）；"你应当比我更加理性，更加决绝……你为此而生"
  - 关键立场："没有存续，谈何文明" vs 凯尔希"没有文明，谈何存续"；"我将引领族群前往月亮"（海嗣的星际目标）
- 经典台词："此处并无正义，唯有前路。""没有任何生命能以任何形式存活下来，都值得我以任何代价去争取。""没有存续，谈何文明？""我并非在寻求你的认同。"
- 信息来源：活动《生路》（全文）
