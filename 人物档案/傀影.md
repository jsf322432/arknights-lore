# 傀影 / 卢西恩（Phantom / Lucian）

- 阵营：罗德岛（干员/刺客）｜种族：菲林｜身份：前"猩红剧团"主演（"**血钻**"）→新的"**酒神**"
- 首次登场：活动《红丝绒》（act43side，2025，异格前史/终章）；此前为罗德岛干员（档案）
- 能力：源石技艺（歌声/情绪——"血钻的歌声会撕裂我的喉咙，也将痛苦渗入你的耳朵"）；匕首/刺杀（幼时受"剧团长"亲自教导）；喉咙有源石结晶（曾自毁歌喉以触碰"死亡"）
- 关键信息：
  - **猩红剧团"血钻"**：幼时于天灾中失去家园与双亲，被剧团收留（"只有当我是剧中角色时，我的孤独才能被消除"）；受"白英花/刀舞/影子"等老师训练；剧团长最青睐的学生（"你是天生的演员，你应该成为我的学生"）
  - **自毁歌喉**：因演技瓶颈，将源石扎进喉咙感受"绝望/死亡"（"你将聆听一切你不曾聆听之低语……你将成为，万物的明镜，戏剧本身"）；成为感染者
  - **弑师**：以刀刺入剧团长胸膛（"我自以为毁掉了整个猩红剧团"）——但他"死而复生"（"死亡常在，而戏剧永恒"）；与暮落（沉渊）/剧作家策划脱逃失败（逃亡被写进戏里）
  - **《红丝绒》**：循着剧团的双生相印（剧本拍卖会）来到蓝卡坞，参演《杜邦夫人之死》"信使"一角（"我途经这种种惨剧，只是为了走向你"）；以"血钻"歌声制住莫伊拉；与酒神对峙——点破"死亡是你永远无法到达的彼岸"（长生者无法亲身完成/自证死亡）；权杖刺穿其心脏（"痛苦是我的利刃，而我终于将它，刺向授痛苦予我的——你！"）
  - **传承**：弑杀完成即传承——**成为新的"酒神"**（头戴"表演"的冠冕、手执"灵感"的权杖——"戏剧不可被杀死，但我可以赋予一切它的意涵，以戏剧取代戏剧，以审美推翻审美"）；"你又能给出怎样不同的答案——'酒神'"
  - **结局**：与暮落/剧作家重逢（"猩红剧团不复存在，你们自由了"）；"我会重新开始游历、歌唱、演出，直到我确信我所形塑的事物，足以匹配我的喜悦和痛苦"——"欢迎你们，加入'剧团'"
- 与 Miss.Christine："我更喜欢'傀影'……虽然寓意并不怎么好，但它是你自己取的名字"（Miss.Christine 语）
- 经典台词："演员登台后，一切意外都需成为演出的一部分。""这是我，可悲的宿命。""长生者，死亡是你永远无法到达的彼岸。"
- 信息来源：活动《红丝绒》（全文 19 段）；活动《如我所见》（全文）；罗德岛干员档案

## 肉鸽《傀影与猩红孤钻》（rogue1）补全

- **主演=诱饵（重磅）**：傀影明白"身为主演的他仅是剧团准备的诱饵，引诱着这些热诚而高尚的凡人一次次跃入这有来无回的陷坑"；羞愧（"可曾有人迷失在这高耸迷宫中？自己又可曾将施以援手的同伴推下舞台？"）
- **标准结局**：恢复自我——暮落接他回罗德岛（"该回家了，卢西恩"）；"对博士念诵台词只会增加我的愧疚。我会用行动补偿罗德岛""我的歌喉只会带来灾祸"
- **坏结局（剧团重生）**："剧团喉舌"倒下后，傀影不由自主坐上舞台中央的椅子——**放声歌唱唤醒全体剧团成员复活**（"猩红剧团因傀影而'覆灭'，也必将因傀影而重生"）
- 信息来源（补）：肉鸽《傀影与猩红孤钻》（rogue1）全文 5 段（entry+ending_1~4）
