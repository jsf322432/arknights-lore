# 渡桥（Dokutah / 珀耳）

- **身份**：罗德岛干员（卡兹戴尔"顾问"——自学识字的萨卡兹——油印机印刷室——本名珀耳）
- **经历（干员密录 story_mitm_1_1/2_1，重磅）**：**段1（与赫德雷）**：珀耳（办印刷室——刻蜡纸（优惠券——"纸上印字换土豆"——识字班（赫德雷——雇佣兵办识字班——珀耳拜访（"我有一个理想……一个人人识字的卡兹戴尔"——赫德雷借钱给珀耳（"这些钱借给你……去雇一个人，去教那个人读和写，去让这个街区再多一个识字的人""得是什么样的生活，才能逼得一个孩子在卡兹戴尔早早学会了读和写啊"——伊内丝）；**段2（顾问与《卡兹戴尔日报》）**：珀耳=渡桥（卡兹戴尔"顾问"——调解帮派纠纷（约定书——"怕被骗？那你们倒是自己去学啊。离这儿不远有个雇佣兵办的识字班"）；**离开卡兹戴尔（重磅）**：渡桥（"卡兹戴尔不可能离了某个人就无法发展……明天！不能再拖下去了，明天就要把《卡兹戴尔日报》办出来"——办报纸——**不辞而别**：渡桥离开卡兹戴尔（"我准备先跟着走南闯北的商队游历，炎国、维多利亚……走到哪算哪"——与妮芙约定（"三年之后，卡瓦莱利亚基"——"敬我的起点，我的故乡，我命中注定将要回去的地方"）
