# 森西（Senshi，迷宫饭）

- **身份**：《迷宫饭》穿越者——**矮人厨师**（自称"老夫"）；"因看不下去莱欧斯做饭而加入小队"（齐尔查克语）
- **穿越（活动《泰拉饭》act36side）**：与莱欧斯小队误入泰拉；被误认为杜林（"老夫不是杜林……唉，就当老夫是杜林吧"）
- **料理哲学（重磅）**："食物是和记忆连接在一起的，吃到同样的料理，脑中也会出现那时的画面""老夫做饭的时候也会想起当时一起做饭的人……这样一点一滴，都会在同样的香气和味道里再次浮现"
- **经历（act36side）**：
  - 向大鲍勃学源石虫料理（"火舌撩着源石虫的壳，激发出一阵麦香……哔啵！"）
  - 炖"蓝色肥鸟"汤给玛露西尔解毒（=大祭司）；用酸液源石虫黏液做"黄金萝卜"送别聚餐（"老夫为你们做好了"）
  - 吃被邪魔污染的角兽肉→坍缩（被齐尔查克追回）
  - 婆山镇种田（"老夫也要去田里帮忙种菜"）；与墨魉交好（果酒/果酱/果汁）
  - 盐风城：海鲜大餐（用"应急理智顶液"调味——发现是罗德岛产品）；"老夫看在眼里实在是心痛"（对麻木的居民）
  - 罗德岛：用天火的火烤栗子（"烤栗子"）；对博士的健康劝诫（"要记得这对健康没有好处，还有不少人都在关心你呢！"）；做"饱含回忆的大餐"
- **经典台词**："吃饭不仅仅是生活的一部分，其中还寄托了人们的情感。""越是这种食物越要仔细处理。"
- **信息来源**：活动《泰拉饭》（act36side）全文 16 段
