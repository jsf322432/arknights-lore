# 斯特凡诺·托雷格罗萨（Stefano Torregrossa / 安布罗修修道院主教）

- 身份：**安布罗修修道院主教**（任职约六十年）；收留萨卡兹难民的主持者
- 首次登场：活动《空想花庭》（act26side）
- 关键信息：
  - 生平：当年最年轻的修士→老主教将修道院交予他；执掌修道院六十年（"荒野的羽兽被吸引到这片移动的沃土上"）
  - 理念：收留萨卡兹（"他说我们萨卡兹和其他人没什么不同"——杰拉尔德语）；布道以"居民"称呼众人（"而非'信徒''同胞'"）；"安布罗修修道院并非乐土，但它是我们共同的'家园'"
  - 物资困境：存粮见底/圣餐减半掺花粉杂粮；**教大家拆用修道院内旧军火**（"燃料有限，冬天很长"——格芬区铳械工厂的弹药，成为圣堂大火助燃物来源的疑点）
  - 《空想花庭》：在绝望中（阿尔图罗琴声映照其心——"我一度沉沦于绝望，向心中的恶意垂首"）拟将**深海教会怪物血肉掺入圣餐**（吃下即转化），最终将面包锁入地窖柜子（"以免饥饿的居民误食"），宣布修道院同意返回拉特兰
  - 结局：向蕾缪安告解/自我审判（"我甚至不敢说……我还信着我们的'条律'"；"是荒谬"）；收下蕾缪安所赠"曾在此借住的修士的笔记"；**独自徒步回拉特兰**寻回信仰（"我需确认，我需……寻回我的信仰"；"我们会于那处乐园再会"）
- 经典台词："我们并非没有矛盾，我们并非没有隐秘，但我们试着彼此接纳。""若信仰可以是虚假的，斯特凡诺此人的存在，又有几分真实？""我们苦熬长夜，却禁受不住晨光熹微之时的寒冷。"
- 信息来源：活动《空想花庭》（全文）
