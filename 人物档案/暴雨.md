# 暴雨（Rainstorm）

- 阵营：罗德岛干员｜种族：未明｜身份：护卫（萨尔贡军事人员出身）
- 首次登场：活动《干员秘录合集》（act4d0 st07，可露希尔×凯尔希秘录）
- 形象：乖顺怯懦（"好乖的孩子！"——可露希尔语）；渴望帮忙（"但护卫的事情，我走了，凯尔希医生不要紧吗？"）
- 关键信息：
  - **身世**：**萨尔贡军事人员出身**；被凯尔希"捡回来"（可露希尔："凯尔希，你该不会有捡人的天赋吧……这已经是第几个了？"——凯尔希："这是'感染者人才收容与发掘程序'的环节之一"）
  - **《干员秘录》（可露希尔×凯尔希秘录）**：凯尔希 72 小时手术的对象（"手术小组至少轮了八、九班"）；恢复良好（"血红蛋白也回升了。你恢复的不错"）；凯尔希让其熟悉舰内环境（"以后你可能要常来这里"）；"每个干员都需要找到自己的职责……让她在她无法施展的地方浪费时间，只是我的失职"
  - **与凯尔希**：感激凯尔希（"谢谢凯尔希医生"——凯尔希："不要谢我，这只是我的职责"）
- 经典台词："是……那么我就告辞了。再见，可露希尔小姐。"
- 信息来源：活动《干员秘录合集》（act4d0 st07）
