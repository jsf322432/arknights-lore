# 能天使（Exusiai / 蕾缪乐）

- 种族：萨科塔（天使）｜出身：拉特兰｜阵营：企鹅物流（专员）；蕾缪安的妹妹
- 首次登场：第二章「异卵同生」（2-4 企鹅物流）；活动《众生行迹》（act42side，拉特兰线核心）
- 形象：活泼开朗、话多、自来熟；"拉特兰的救世主小姐"
- 关键信息：
  - 情报与路线专家：掌握龙门地形与整合运动分布（"龙门的路，我实在是太熟啦"）；提供屋顶转移路线
  - 与德克萨斯搭档；性格互补（德克萨斯寡言，能天使话痨）
  - 身世：圣席奥多尔综合学校城际网络安全预科第一名（提前修完预科/自办"告解车合唱团"毕业典礼——"热烈庆祝蕾缪乐开始她的冒险"）；离开拉特兰去龙门（为了查明姐姐蕾缪安受伤的真相——"你可是我老姐啊！"）
  - 《众生行迹》（回拉特兰）：在"车载电子告解师"（实为**博士**）指引下制造爆炸/计划炸毁育婴圣堂（阻止降生仪式）；发现圣堂住满无辜难民而拆除炸弹；与蕾缪安姐妹对峙（口令"蛋黄酱苹果派"）；被"圣徒"转化（堕天/光环熄灭——"厉害啊，居然有办法关掉我脑袋上的这顶日光灯"）
  - 与博士：五年老友（龙门相识）；告解车 ELCARO-001 配合（"老板，义人，博士！"）；"就让我们再漂亮地合作一回吧，老板"
  - 祈祷哲学："祈祷是无用的。但它需要我们不去怀疑，它需要我们心怀希望。我们愿意为彼此祈祷，本身便是一件很美好的事情。它把我和其他人，真正连接在一起。"
  - 终局：以特制子弹+爆破击溃"圣徒"（"正宗天意！福音摇滚！弹幕嗨破天！叉烧苹果派！"）；"如果拒绝它，意味着需要将连接我们的光环都切断，那就切断。因为，哪怕是那样，我们也绝不会放弃为彼此祈祷……"
  - 结局（st03）：在 PCS 残骸前**许下第一个愿望**（新的拉特兰）；开"苹果派物流"（"祈祷我能借此机会做大做强……顺便还能有很多时间陪爸爸妈妈姐姐"）；在律法残石上涂鸦许愿
- 经典台词："任务是不是很快就完成了？'企鹅'的服务如何？""我们当然不会放弃活着，但绝不是以你们算出来的那种方式。""只要还有朋友在身边，就没有什么是不能一起笑着面对的。"
- 信息来源：第二章 2-4~2-8；活动《喧闹法则》；活动《众生行迹》（全文）
