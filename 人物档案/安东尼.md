# 安东尼·西蒙（Anthony Simon）

- 阵营：西蒙公司（独子）→ 罗德岛｜种族：菲林｜身份：前囚犯/越狱者
- 首次登场：活动《孤岛风云》（act15d0，2021）
- 形象：温和有礼、崇尚理性（狱警："平时喜欢看书，写字，听音乐，多么高雅"）；武力极强（刚入狱打服整个 C 区）；"他才是这座监狱里最厉害的家伙"
- 关键信息：
  - **身世**：西蒙公司 CEO **史密斯·西蒙**的独子；公司（前物流业→建材业）与海德兄弟竞争失败覆灭；六年前（7 月 24 日）父亲让其逃亡，逃到铸铁城后被捕；按本州法律被关进州立曼斯菲尔德监狱 C 区重犯塔——推测**入狱是父亲老史密斯安排的"保护"**（"我在这里得到了一个囚犯本不应有的优待"）；家人全部在堡垒山城监狱服刑（受海德兄弟影响受尽折磨）
  - **狱中六年**：建立威信（打服 C 区/提议建立地下图书馆/狱警敬他三分）；"我可以在这里生活得很舒服，甚至能够将这里改造成属于我的王国。但这又怎么样呢？我只不过是一个最自由的囚犯罢了"
  - **越狱**：接受卡夫卡协助（"请你协助我越狱"）；招揽杀手罗宾（"你可以继续尝试刺杀我，或者就此收手"）；越狱日制服设伏的罗宾却不杀她（"你依然可以尝试刺杀我……我确实会有些失望，但也仅此而已"）
  - **与杰斯顿对峙**：拒绝抛弃杜玛（"我不愿意为了自己的目的而牺牲杜玛""这些并不比一个朋友的生命重要"）；"我在这里生活了六年，这六年里，我无时不刻想要出去……我要告诉那些让我家破人亡的人，我们还没完！！"
  - **结局**：塞雷娅登场救场并向他确认"斐尔迪南"（"我从父亲那里听说过这个名字"）；随赫默/梅尔前往罗德岛（"我已经开始期待这一段旅途了"）
  - **人生哲学**："力量很重要，智慧也很重要，但最重要的，是勇气，是为自己的选择买单的勇气""我们只能依靠自己"
- 经典台词："我不能把选择权交给别人……你必须自己去思考每一件事，去做出每一个选择，并为每一个选择负责。否则的话，你是无法主宰自己的命运的。"
- 信息来源：活动《孤岛风云》全文 18 段
