# 帕斯卡拉（Pascal / "神偷"）

- 身份：伊比利亚小偷/"神偷"（富商没落之女）；盗窃审判庭罗盘的元凶；结局选择留在陆上追寻"好日子"
- 首次登场：活动《出苍白海》（act39side）
- 关键信息：
  - 身世：富商家庭的女儿（"当年我家可是有名的富商"；罗盘原是家中财产，被变卖后落入审判庭）；家族没落后被审判庭认定是贼（"我那天只是想回家，拿回我小时候的东西……那是我奶奶给我做的手环！我拿自己的东西有错吗？"）——被赶出镇子（"我求你们说我想在镇子里找份工，好好生活，你们都永远认定了我就是个贼！"）
  - 性格：油嘴滑舌/精明（"暴力和虚伪，对，这就是我们活下去的办法"）；偷窃成性（连伊西多的钱袋/安纳斯塔西奥的徽章都扒）
  - 《出苍白海》：偷罗盘被安纳斯塔西奥追杀→被伊西多所救；把罗盘交给胡安娜（"不止罗盘，我还有另外一个大发现"——伊西多是炼金术师）；哗变中巧言争取一周时限（"再等一周，罗盘的修复就能有结果"）；为救蒂奇拼命（"我不放！"——"她失去了很多东西，但这份温暖如今好像是属于她的了"）
  - 结局：拒绝出海（"我还是想过那种有钱的好日子，出海嘛……对我来说太辛苦，太颠簸了"；"我可是个卑鄙的小毛贼，心肠很坏的"）；随车队去哥伦比亚"挣笔大的"；与极境告别（"祝你有一天真的得到想要的一切，过上好生活"）
- 经典台词："我拿自己的东西有错吗？……现在我真的是个贼了，你们满意了？""你们没资格审判我！""暴力和虚伪，对，这就是我们活下去的办法。"
- 信息来源：活动《出苍白海》（全文）
