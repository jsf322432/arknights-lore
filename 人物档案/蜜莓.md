# 蜜莓（Honeyberry / 佐伊·伯里斯）

- **身份**：罗德岛干员（矿石病防治/心理疏导——雷姆必拓村庄出身——本名佐伊·伯里斯）
- **经历（干员密录 story_glider_1_1，重磅）**：**父母被村子驱逐（父亲=村里第一个感染者——被赶走没多久去世——母亲随她到罗德岛）**；**回村解决感染者问题（矿业公司委托）**：加斯（感染者——妹妹莉迪亚）；莉迪亚（蜜莓童年好友——相思成疾——与马丁森之子卡尔的恋情）；蜜莓的坚持（"我只是希望村民们能放下心中的偏见和隔阂。我不想让悲剧再发生一次"）；**结局（重磅）**：卡尔站出来抱住莉迪亚——但村民仍拒绝感染者——蜜莓坦白身份"我是佐伊·伯里斯"——村民恐惧依旧；砂轮点醒（"我们只是来解决感染者问题，仅此而已"）；信件（莉迪亚和卡尔被矿业公司录用——村民允许感染者住在村旁——"他们还是迈出了至关重要的一步"）
