# 黍（Shu）

- 身份：**岁兽碎片化身**（岁兽"岁"分离出的十二份之一——"其数为六。定天时，规二十四节气……于大饥荒时现身于大荒城，躬耕千年未曾离开"——司岁台档案）；大荒城"资深授业天师"；炎国岁兽线核心人物
- 首次登场：活动《怀黍离》（act31side）
- 关键信息：
  - **岁兽碎片（排行六）**：岁兽"岁"分离出的代理人之一；兄弟姐妹包括重岳（朔/大哥）、望（二哥）、绩（三哥）、令（姐姐）、颉（妹妹，已死）、年、夕等；与大地/农事相连
  - **与神农的约定（核心）**：千年前被人类"神农"收留（"在我像一个孩子一样漫无目的地游荡的时候，有一个人把我留在了身边，给了我一个'家'……她告诉我，不必在意什么人兽有别。我可以……我应该像一个人一样活着"）；与神农共开垦大荒城（"明明是我们一起做过的事，你怎么好全推在我身上"——神农语）；神农北上寻种未归（离世）后，黍履行"守护好这片土地，让更多的人能吃饱饭"的约定千年
  - **大荒城守护者（压制邪魔千年）**：神识与大地相连（"千年来，无数次天灾，每一次……你都会提前知道……这片土地上的一切，你都会感同身受"）；**邪魔污染早已侵入大荒城地底（天机阁建立之前），千年间全靠黍以神识压制**（"她在这里……所以这么多年来邪魔影响都没有扩散"——年语）；"我救了这一次，之后人们便只会想着这样的'神迹'如何才能再发生。可我做不到每一次都能救下所有……总有一天，我会消失不见的。到那时，我现在用的力量，只会变成害人的'恶因'"
  - **预见终局**：在"巨兽心脏"（十二楼五城核心）中看到的风景="无尽的稻田，轮转的四季"；预见的结局="白茫茫一片大雪，从来没有变过"（"春种秋收，繁盛过后，最终都被一场大雪掩埋"）；"来这世间走过一遭，这本身不就是结果？"
  - **消散与重生（《怀黍离》结局）**：邪魔污染全面爆发时，**牺牲自己清除地底邪魔污染**（"一个被禁锢了千年的游魂在此时消散。万物生长"）——黍消散，人们对她的记忆被抹去（禾生/小满忘了她）；神识被绩收入**十二楼五城核心（"巨兽心脏"）**中苏醒（混沌意识自称"岁"——岁兽本体的召唤；黍战胜"影子"："不，你只是一个影子……是我自己的影子……我已真实地活过，与大地上万千生灵一同"）；结局**重获自由**（荣晚晴："再见，黍。你该自由了"），以"温柔的女性"身份与禾生短暂相遇后离开
  - **与望**：为望看手相——"孤宿无两；劫数茫茫，九死一生"；以一把种子作答（"这是你的因果。如果你没有行差踏错……这把种子会在合适的时候发芽，结出你想要的果"）；反对望/绩"杀死祂，成为祂"的激进路线（"看看外面受灾的田地，受苦的百姓……我可没办法听过这句话就算了"）
  - **与绩**：绩的姐姐（绩幼时与黍一同在大荒城耕作——"养蚕种桑，跟在黍身边的小呆子"）；绩多次邀她离开被拒；"我拦不住你……你要是还有什么不舍的，最好活着回来"
  - **与令**：令在梦中探望（"我那个最辛苦的妹妹"）；"看得太透，就看不到'自己'了"（令语）；谈及颉（"颉曾经也留下过那么多书卷字帖……她说过的话又从那些学生的嘴里说了出来……'重要的是我能留下来的'"）
- 经典台词："人和庄稼，都一样。天地万物，都在轮回。""哪有人真的能预测命数呢，不过是给发生的事找个理由罢了。""我早已不是那傲慢孤寂的巨兽，也并非飘荡无依的游魂。我已真实地活过，与大地上万千生灵一同。""这世间万物可爱，在它此时此刻的模样。""春草年年绿，我们来过，存在过，还不够吗？"
- 信息来源：活动《怀黍离》（全文）

- **神农往事（重磅）**：黍（岁兽碎片——遇见"神农"（质朴的农人——"你曾经的身体比山还要高……你为什么要变成人的模样跑出来？"——教黍"人"的活法（"等你学会了人种地的办法，说不定也就能体会'人'的心情了"）；**"做'人'，辛苦吗？"**；神农（"民胞物与"——"眼前的花草树木很好看，就想多种一点；饿肚子的滋味不好受，就不想让别人也体会这种感觉"）
- **神农之死（重磅）**：年迈的神农（想去北边找"神谷"——病逝（书上记载：最终病逝在去北边找寻"神谷"的路上——塑像却面朝南方（"她最后，应该也是在望着故乡吧"）；神农临终（"我走了以后，你可以替我留在这里吗？不需要你来当这里的守护神，只是作为一个人，生活在这里""来年那边山坡上迎春花开的时候，你能帮我编个花环吗？"）
- 结局：黍（"你看，他们都还记得你呢""你一副淡泊名声的样子，倒是让别人惦记了你一千年"）；**"怪他去后花如许，记得来时路也无"（重磅台词）**——神农=大荒城千年传说
