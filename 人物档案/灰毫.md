# 灰毫（Ashring / 格蕾纳蒂）

- 阵营：罗德岛干员（红松骑士团）｜身份：红松骑士团成员（前竞技骑士）；重炮手（"打败锈铜骑士时用的那门炮"）
- 首次登场：活动《红松林》（act12mini，2021）；罗德岛干员（游戏实装）
- 形象：沉稳冷静（"比起在赛场上解决单一的敌人，确实是要复杂一些"）；对感染者共情（"那些大企业永远掌握着新闻报道权，抹杀一个人的声音对他们来说甚至算不上需要耗费精力的事"）；外冷内热（头盔刻名签名）
- 关键信息：
  - **红松骑士团（重磅）**：与焰尾（索娜）同为红松骑士团成员（前竞技骑士——加入罗德岛）；茨沃涅克调查感染者组织；救泽诺（"城市会如何让感染者消失。你不能留在他们手里"）
  - **头盔签名（重磅）**：用焰尾的剑在头盔上刻名赠泽诺（"看到像您这样的骑士站在竞技场上，对我们普通的感染者来说，更是一种鼓舞"——泽诺语；婉拒耀骑士签名——"耀骑士的确是很伟大的骑士……可是看到像您这样的骑士……更是一种鼓舞"）
  - **理念**："不该再有更多人成为政治和商业把戏的牺牲品了！"
- 经典台词："不该再有更多人成为政治和商业把戏的牺牲品了！"／"他们根本不给感染者成为骑士之外的出路。"
- 信息来源：活动《红松林》（act12mini）全文 7 段；活动《红松林·索娜线》（act9mini）全文 7 段

## 活动《红松林·索娜线》补全（卡利斯卡家族/火炮传承）

- **身世（重磅）**：**卡利斯卡家族**（南方林业巨子——"那片林子是我们靠功勋、靠火炮换回来的"）大小姐；感染后**被家族全票表决逐出**（"一桌子叔父叔母面前被全体表决逐出家族，全票通过"；父母被要挟投出女儿——但回家后仍给她准备了大骑士领的资金）；"有人恨不得让她彻底从大地上消失"（索娜帮她挡过）；家族衰落被归咎于她（"所有人都将家族的逐渐衰落归咎在她身上"）。
- **祖母与火炮传承（重磅）**：祖母（威严——教她"架盾、起炮、轰击！炮声轰鸣，胜利已在眼前！"——卡利斯卡格言；"古木哪有不烂的道理……不如做新芽的肥料"）；爱用**火炮**（从老家带来的炮——"它的威力能够补足灵活性上的不足"——祖母的传承；"小坚果"是父亲对她的昵称）。
- **竞技场战（重磅）**：灰毫骑士 vs 锈铜骑士英格拉（"沸血骑士团——竞技场屠夫"）；拉锯战（盾击挡开接一炮/误导对手）；英格拉鞋底推进器/斧劈炮弹；**头槌+徒手打击+借炮击加速度突进**（"偷学索娜的招"——炮口摁在后背开火）；胜利后**最后一发炮弹对天发射**（"这一枚炮弹是献给观众的。你不配"——不羞辱倒地的对手）；"比赛已经结束了……不然我和他又有什么区别？"
- **红松骑士团创立**：与索娜创立红松（"我们什么时候是一个骑士团的了！？——迟早的事，小灰"）；招揽艾沃娜（"她的确是个有趣的家伙"）、查丝汀娜（初认生——"她总觉得你和我们不太一样"）。
- 信息来源（补）：活动《红松林·索娜线》（act9mini 全文）
