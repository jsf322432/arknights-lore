# 西尔卡（Syrka）

- 身份：第四集团军间谍（库兰塔/"退伍军人"）；特殊战术兵团"谢钦"少尉（斯乔帕的副手）；**安德里安元帅（叶甫根尼之父）的私生女**
- 首次登场：第十七章「相变临界」（"谢钦"线/泽尔格勒线）
- 关键信息：
  - "谢钦"少尉：以"无声环境"源石技艺闻名（"被战争术师抛弃的技艺"）；在十二月叛乱剿灭中感染矿石病——"这是我最后向元帅展示忠诚的机会。利用感染者身份，潜入现在的泽尔格勒"
  - 被叶甫根尼"抓捕"实为伪造（战争术师模仿其声音作要挟道具）；真身潜伏泽尔格勒：杀情报员普罗霍尔（耶夫塞·卢基奇）、**刺杀阿纳托利**（割喉——源石自行修复，"那看上去甚至不像是人类身体应有的组成部分"）
  - 与整合运动合流（被救后加入撤离行动）；以第一集团军私人频段接入叶甫根尼通讯，当众揭露**安德里安元帅与斯韦特兰纳的旧情传言**（"至今仍有人并不认同您的这一做法，还在试图剥夺您的继承权"），诈称"私生女在泽尔格勒城内"激怒叶甫根尼与阿纳托利（"或许有一天，我们会因同样的血脉再见……我亲爱的兄弟"）
  - 目标："和那里面某个早就该死的人……还有笔账没算完"（指阿纳托利）；被叶甫根尼视作"工具"（"死一个本来就要流放的感染者肯定比直接葬送一整支舰队要划算得多"）
- 经典台词："我代替叶甫根尼元帅，感谢你的服役。""我向你保证，在我成功刺杀那位小将军的功劳里，也会有你的一份。""你们先走吧，我有一件必须取回的东西。"
- 信息来源：第十七章（17-03/17-04/17-05/17-07/17-12/17-15/17-17）
