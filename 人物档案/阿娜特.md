# 阿娜特·艾尔-艾伊丁 / 莎草（Anat el-Eidin / Cyperus）

- 阵营：米纳特哈玛仪（法尔贾万达巴德博物馆代理馆长）｜种族：（萨尔贡人）｜身份：考古学家/博物馆馆长（干员"莎草"）
- 首次登场：活动《太阳甩在身后》（act35side）
- 关键信息：
  - **代理馆长**：学究世家出身（"从小在父亲的严格管教和过度保护下长大"——萌娘百科注）；博物馆馆长（紧张体质——"把观众看成博物馆里的文物，这样就不会紧张"——缇缇教她的；演讲中暑）。
  - **《太阳甩在身后》**：借祖拜尔给佩佩（"除了署名、投资、赞助，还有新展馆的冠名费，一个都不能少哦！"——第二颗宝石——私人收藏家赠送）；解构装体的历史谜题（"哈拉赫特"=认证口令——"那个人究竟是怀着什么样的心情，将关键口令选择为——'哈拉赫特'？"）；"历史与知识对所有人都是平等的"（不设贵宾票）；与缇缇的争执（商业化vs坚持——"这座城市的立身之本可是历史！"）；埃里克森《大地巡旅》崇拜（"我一定要和他成为笔友！"）。
  - **结局**：卸任代理馆长（"我从记事起就一直透过窗户看着这座城市，现在我觉得，或许我已经把它读完了""我想像埃里克森先生一样，去看看大地上其他的地方"）；告诉佩佩弟弟已入黄金之城（"你弟弟并不开心……他说他希望你能记得他的声音"）。
- 经典台词："历史与知识对所有人都是平等的。""我能拥有的最大勇气，就是穷尽短暂的生命，向无限的时间求索。""有些时候，没结果也是一种结果。"
- 信息来源：活动《太阳甩在身后》（全文）
- 后续：离开博物馆（游历大地——埃里克森式）；罗德岛干员"莎草"
