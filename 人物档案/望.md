# 望（Wang）

- 身份：**岁兽碎片化身**（"岁老二"）；伪装成天师府/天机阁最高层"**老天师**"潜伏炎国；炎国岁兽线核心人物/激进派领袖
- 首次登场：活动《怀黍离》（act31side）
- 关键信息：
  - **岁兽碎片（排行二）**：岁兽"岁"分离出的代理人之一；重岳（朔/大哥）、绩（三哥）、令（姐姐）、黍（六姐）、颉（妹妹，已死）、年、夕等；"岁老二"（"老天师"骂语）
  - **"老天师"身份（伪装）**：天师府/天机阁最高层"老天师"（金色顽童形象/持扇）；**装疯卖傻以"心智不受邪魔侵染"**（"你为了心智不受邪魔侵染才装作这一副疯疯癫癫的样子，倒没忘了自己真正该做的事"——望对"老天师"语，二人互相点破）；当年曾"挨个找过我们兄弟姐妹，问过每个人一个问题，又给我们各自指了路"——"你在这片炎国大地上看到了什么？"（对绩："我的答案从来没有变过，想来二哥他也是"）
  - **军略/棋手**："北边有战事，行军布阵，总要身在一线的"（望的真实身份在边军）；学会围棋（"规则简单，原理竟与兵法相通……纷纷世事，看似混沌无序，但只要掌握了那个规则，就能计算出最终的结局"）；黍为其看手相——"孤宿无两；劫数茫茫，九死一生"（"我很期待……我会等着的"）
  - **"杀死祂，成为祂"（计划）**："我要回到那副躯壳中去，我需要祂的力量。**杀死祂，成为祂。用祂的力量，为这普天之下万千生灵谋一份'大利'**"（"我们何曾，真正作为自己活过？"）；"我终于……看到了另一个结局"（积雪下探出翠绿禾苗的意象）；对黍："黍，我想借你的一点力量。我们十二人，多一个人的力量，多一分胜算"——黍以一把种子作答（"这是你的因果"）
  - **与颉（妹妹）**："你可曾再见过她？""可是最近这几年，我已经忘了许多事……关于她的事……我分明记得，她曾与我对弈一局，她想要在局中告诉我什么，如今却无论如何想不起来了"（岁兽本体对碎片的影响/颉之死伏笔）；"即使同为'我'们，也逃不过这样的影响"
  - **与绩合谋**：与绩对话（"胜算有几成？""半目胜负，生死之间""万事俱备，只欠……"）；绩织就"山河百景图"供其"去见祂之前"使用；与"老天师"（另一重身份的对峙？）——实则望即"老天师"，与绩的对话是合作
  - **与小满（"大嗓门"）**：以天师学徒"大嗓门"身份接近/保护小满（赠竹笛、要回扇子、托她找"红色水稻"——调查污染）；其徒弟（"沉默的樵夫"=小满之父）牺牲于抗击邪魔（"我可不想再亲手杀一个徒弟"）；"回去吧，还有一个那么机灵的女儿，总不能让她双亲都不在了……哪怕没法再让她认你"
  - **《怀黍离》结局**：现身与年/夕/黍对峙（"你们，还有心思在这里胡闹？"）；以炽白火焰烧毁一匹布（逆向分解"因果"）；"天机阁如今损失惨重，你要是再有三长两短，大炎北边的防线可就岌岌可危了"（借天机阁之名警告）；"权衡利弊，我们未必没有可以合作的可能。后会有期"——与绩先后离开
- 经典台词："纷纷世事，看似混沌无序，但只要掌握了那个规则，就能计算出最终的结局。""我要回到那副躯壳中去，我需要祂的力量。杀死祂，成为祂。用祂的力量，为这普天之下万千生灵谋一份'大利'。""舍小取大，各取所需，如此而已。""我们何曾，真正作为自己活过？"
- 信息来源：活动《怀黍离》（全文）；活动《春分》（全文）

## 活动《春分》补全（岁陵决战，重大进展）

- **与睚对峙**：拦下巨兽睚（"你在大炎的地界上撒泼耍浑，还想让我当看不见？""我们当年能把你们揍一顿，从这片土地上赶出去，现在照样能"）；点破睚与岁兽本体合谋（"那个臭棋篓子到底许了什么好处，让你心甘情愿听他使唤？""你们还惦记着，百灶城下的那个东西"=岁陵）
- **与余（古寺）**：回到棋局开始的地方（"这盘棋局是从这里开始的，有始有终"）；余劝饭（"二哥，我真的希望……你能活着回来"）；"你恨司岁台坐视三姐丧生，你恨大哥阻止你去复仇……你最恨的人，还是你自己吧"（余语——**颉之死**：司岁台坐视/望自责）；接受余的力量（一碗汤）
- **入岁陵（重磅）**：真龙开启岁陵（"我的子民有冤屈，我准许他去申诉冤屈"）——**望走入岁陵**（时隔一百二十年——上次入陵=颉消失）；"我来帮你们……变成人""要分胜负的，始终是我与我""我们早已不是你的附庸，我们必须生死相搏。胜者生存，败者消亡。一如千年前的战场，这是无可回避的命定"——**与岁兽本体生死对决**（"杀死祂，成为祂"的兑现）；绩（"账已经平了，后面的路，我自己走"）

- **与岁兽本体的对决（岁陵）**：被岁兽本体拖入梦境/记忆牢笼（重复过去——颉给书刀/《急就章》被涂画成"岁"字）；**用颉的书刀刮"岁"字**（一千三百九十四次——每刮一次经历地狱异象）；**三枚黑子换一次"死亡"**（欺骗岁兽本体/摆脱梦境）；**看见颉留给他的信**（棋谱背面——"殊途同归……残局将尽"——"她从不曾输给过谁。她以自己的决意，换来了我们剩下的人的生机"）
