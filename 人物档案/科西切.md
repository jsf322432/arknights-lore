# 科西切（Kaschey / "黑蛇"公爵）

- 身份：乌萨斯贵族公爵；"**不死的黑蛇**"——乌萨斯帝国意志的化身（意识可转移的古老存在）
- 关联：**塔露拉的养父/塑造者**（继承人）；曾与魏彦吾、爱德华（塔露拉之父）敌对（被驱逐出龙门）
- 首次正式登场：第八章「怒号光明」（回忆线+决战精神体）
- 关键信息：
  - 教导塔露拉统治之术，灌输"魏彦吾杀了你父亲"的谎言；塔露拉自染矿石病反抗后，被其亲手所杀（肉体）
  - 临死种下**意识转移诅咒**："你会成为我""黑蛇将与你同行。这不朽的意志永不死去"——当塔露拉开始恨人（阿丽娜之死、烧村复仇），诅咒发芽，其意识逐步侵蚀塔露拉
  - 第八章决战：以塔露拉之躯作战（"我是乌萨斯一切的见证者"）；意图杀陈以彻底吞噬塔露拉；被塔露拉本我挣脱压制——"即使在这大地的尽头也会有我"（未彻底消灭，伏笔）
  - 理念：以不平等塑造假象、以战争锤炼乌萨斯；"统治他人者必将受更强者统治"
- 经典台词："塔露拉，你的终点也在我。""黑蛇将与你同行。这不朽的意志永不死去。""我祝福你，我的女儿。"
- 信息来源：第五章（陈噩梦"老公爵"）~第八章

> 待补充：真实来历、后续回归（第九章起"不死的黑蛇"伏笔）
