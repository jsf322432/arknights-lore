# 西尔弗（Silver / 雅隆镇证裁官）

- 身份：伊比利亚雅隆镇**证裁官**（镇子的拯救者/治理者）；被安纳斯塔西奥杀死
- 首次登场：活动《出苍白海》（act39side）
- 关键信息：
  - 生平："伊比利亚……那些侥幸没被海洋吞没的聚落，没有一座不在混乱中崩溃。曾经的雅隆也是如此。是我把半生都投进了这里，是我把它从同类相食的惨剧和惨无人道的暴政中拯救了出来"
  - 治理：曾颁布禁令/布道控制镇民（"我当年用来控制这些可怜人的每一句话，如今都还扼在他们的喉咙上"——人们不敢吃太饱/黄昏后不敢出门）；后撤销禁令（"时代不一样了"；想用商队的新货改善镇子）
  - 《出苍白海》：处理伊西多盗墓案（判绞刑）；想以"赦免强盗换罗盘与盐船图纸"振兴雅隆（"如果他们能为我所用……镇子也会变好起来了"）；与安纳斯塔西奥分歧（"您没有这个权力！"）
  - 悲剧：亚诺阿医生被强盗撞倒去世（寡妇难产而死——"一个刚刚学会做药膏的人，当不了医生……不然，寡妇和孩子也不会死了"）；被安纳斯塔西奥杀死（"你初次见到我的时候，我也是受了伤……但你那时问我的，是我需不需要帮助。可现在呢？你也被欲望所腐化了"）
  - 收藏：镇民送的花（干枯的/腐败的/黑灰的花——"长久以来，镇民们为表感谢，向他们的证裁官阁下送上的每一朵花"）
- 经典台词："对秩序的遵从为你们带来了食物、清水与居所。""我当年用来控制这些可怜人的每一句话，如今都还扼在他们的喉咙上。""……我的，雅隆。"
- 信息来源：活动《出苍白海》（全文）
