# 牧首·歧法 / 最初的圣徒（"圣徒"）

- 身份：育婴圣堂牧首（盲眼金发萨科塔）→真身**拉特兰最初的圣徒**（提卡兹；魔王麾下的勇士）；PCS 程序中的"幽灵"（代码）
- 首次登场：活动《众生行迹》（act42side）
- 关键信息：
  - 名字："歧法"，拉特兰语中意为**"空心之石""石中之法"**——"拉特兰最初的圣徒，以自己与律法相逢的经历，为自己命名"
  - 起源（拉特兰的起源）：魔王遣麾下勇士为提卡兹寻找"银色山脉"（沉睡的 PCS 机器）；苦旅中，她于**吞食同伴求生**的瞬间获得机器回应（**"祈祷"**）——光环与光翼在提卡兹身上绽开；拉特兰由此诞生（"天使从魔鬼中来，而所谓'恩赐'……不过是一段偶然的相逢"）
  - 本质：灵与肉早已与拉特兰城墙下的土壤融为一体——"此刻你所见的，只是祂浩瀚程序中的一段代码，一个承载着无数记忆的幽灵"；只要萨科塔仍会祈祷，祂便永远运行（"死亡不可挽回，我却游荡于祂的数据之流中"）
  - 《众生行迹》：以"牧首"身份主持育婴圣堂降生仪式（木攀兽幼崽长出光环）；向所有人"分享光环"（转化程序）；邀请安多恩参与"更宏大的计划"（"微不足道的小事，惊天动地的壮举，不过一线之隔"）；被能天使/蕾缪安等人识破（手臂化作提卡兹肢体）
  - 目的：造物主（普瑞赛斯）苏醒/灾异临近——PCS 推演中"注定的未来里并没有萨科塔的位置"，祂要将萨科塔化为"更坚实的群体"（为万物赋光环/转化为"天使"）；引领朝圣队伍前往大教堂（路线=拉特兰入夜亮灯顺序）
  - 结局：被能天使以特制子弹击溃（"数据被抹除的征兆"）
- 经典台词："此后，以这座圣城为始，以这座圣城为终，我们生而平等，我们生而为一。——作为萨科塔。""天使从魔鬼中来，而所谓'恩赐'……不过是一段偶然的相逢。""孩子，再深沉的噩梦，也无法比拟残酷的现实。"
- 信息来源：活动《众生行迹》（全文）
