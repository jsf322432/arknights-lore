# 西西里夫人（Signora Sicilia）

- 阵营：叙拉古（实际统治者/灰厅之主）｜种族：（萨科塔后裔？拉特兰出身——"从拉特兰带回了'铳与秩序'"）
- 首次登场：活动《叙拉古人》（act21side）
- 关键信息：
  - **叙拉古的"女主人"**：六十年前自拉特兰归来，带回"铳与秩序"；建立**灰厅**（十二家族圆桌）与**法院体系**（法官=其意志的代行者，监视并预防十二家族之间的斗争）；"所有家族，成了同一个家族。于是，叙拉古成了叙拉古"
  - **名言**："政府就像是灰厅中那张圆桌的桌布"（三十年前市政厅大清洗后流传——试图反抗家族的一代人集体消失）；底线"**绝不赶尽杀绝**"（"这就意味着，除了赶尽杀绝，各大家族还有很多施展的空间"）
  - **与阿格尼尔**：旅居拉特兰时阿格尼尔是她的向导（"我们为此日夜讨论，争执"）；"到最后，将我与西西里绑在一起的，并非理念，并非局势，甚至可能并非情感。而是岁月"
  - **《叙拉古人》**：贝纳尔多谋划逼其下场；结局现身灰厅与莱昂图索/拉维妮娅/德克萨斯/拉普兰德对话——"如果我真的将叙拉古交给你，你能保证，叙拉古一定能够走上更好的道路，成为一个更好的国家吗？"（莱昂图索答："我不能保证。但正如您今天愿意坐在这里听我的想法一样……我也会坐下来，听一听他的想法"）；**答应"借一座城市"**（新城无家族——"一座新的城市，确实应当注入一些新的血液"）
  - "我的寿命并非永恒，但我还有几十年的时间。在我闭上双眼的那一瞬间之前，叙拉古都将享受我所带来的安宁"
  - 与文（文索内希俄斯）是老朋友（"诞生于文明，却自疏于文明之人"）
- 经典台词："没有理所应当的存在，只是，它在我出生以前，就已经在这片土地上存在了千百年。""叙拉古不需要未来。"（莱昂图索转述——"她对于叙拉古只能在她活着时维持和平毫无负担"）
