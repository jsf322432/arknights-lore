# 帕特里奇昂（Patrician / 老铳骑）

- 身份：拉特兰老**铳骑**（菲亚梅塔的祖父/监护人/导师）；第二届万国峰会协助者；"分享光环"的信奉者→觉醒者
- 首次登场：活动《众生行迹》（act42side）
- 关键信息：
  - 生平：为拉特兰效力数十年（"宽恕过或斩杀过的萨卡兹不计其数"）；"我老到连仙人掌挞都嚼不动啦"（准备退休）；把第一把守护铳传给菲亚梅塔（"我们生而不一，但最终殊途同归"）
  - 与牧首：接受"分享光环"的启示（"若拉特兰的信仰能为不信者也带去慰藉……我们的秩序，必将包容万物"；"共享光环的拉特兰，将成为一个真正的整体，连某种无从想象的、威胁全泰拉的灾厄都能够解决"）；随朝圣队伍行进（奥罗拉：队伍里有我想杀的人）
  - 旧事：吉雅（被驱逐的黎博利挚友）/潘格尼尼/奥罗拉（被驱逐的学生——"我亲手将她驱逐出拉特兰"）；"离别"的执念（"我尝试过做些什么，但好像什么都做不了"）
  - 觉醒：潘格尼尼为救他中弹身亡（"别在那想一些矫情的事……你可是铳骑啊！"）；他让梵里妮开枪使自己堕天（脱离共感/离开队伍——"唯有如此，唯有堕天，你才能从其中脱离""不要惧怕堕入地狱。这是你应该学会的第一课……也是我的第一课"）
  - 反思："我一直坚信，如果乐园能成为真正的乐园，我们的联系就能牢不可破。可如果在这个过程中，我们已经失去了更多呢？……如果我们曾是魔鬼，如果我们曾相携着背负罪孽，那我们的联系又怎会断绝？"
- 经典台词："我们生而不一，但最终殊途同归。""梵里妮，好孩子，不要惧怕堕入地狱。""信仰的宠儿、荣光的萨科塔啊，你到底有什么好惧怕？"
- 信息来源：活动《众生行迹》（全文）
