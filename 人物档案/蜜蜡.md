# 蜜蜡（Beeswax）

- 阵营：罗德岛干员｜种族：萨尔贡人（库兰塔？——未明）｜身份：术师干员（沙/源石技艺）；游历中的"想家"者
- 首次登场：活动《干员秘录·棘刺（汐斯塔）》（act11d7，2020）
- 形象：温柔随和（"好哦。"——帮忙挖箱子）；钝感乐观（"伊芙利特有时会骂人'笨蛋'，但我知道这也是在夸人"）；会读氛围（"棘刺先生是很热心的好人"）
- 关键信息：
  - **萨尔贡出身（重磅）**：梦到家/金色摇篮/母亲的手（"我知道那都是沙子，其实一点也不温柔，但在梦里，那感觉让人很怀念。那是不管我去哪里，最后总会回去的地方"）——萨尔贡沙地（呼应太阳甩在身后/萨尔贡线）；"我也有点想家了，但是在完成游历之前，还不能回去"
  - **汐斯塔**：音乐节期间帮伊芙利特/刻刀烤肉摊（帮忙挖出嵌进沙里的箱子）；提议"如果你们想玩沙子的话，听说嘉维尔医生正准备回家一趟，可以和她一起去玩，我记得医生家附近应该也有沙地"（嘉维尔=萨尔贡人）
  - **与棘刺**：为棘刺辩护（"棘刺先生是很热心的好人！我刚刚还看到他拦住了一群要去找博士麻烦的人……棘刺先生还抓到了小偷呢！"）
- 经典台词："那是不管我去哪里，最后总会回去的地方。"／"伊芙利特有时会骂人'笨蛋'，但我知道这也是在夸人。"
- 信息来源：活动《干员秘录·棘刺（汐斯塔）》st01
