# 瑟奇亚克（Sercik / "塑料骑士"）

- 阵营：卡西米尔（前竞技骑士）｜身份：退役独立骑士（自制塑料盔甲——"塑料的盔甲也够用了，我可是个弓箭手"）
- 首次登场：活动《红松林》（act12mini，2021；st04）
- 形象：嘴硬心软（"我要接我儿子"——拒绝记者采访）；被时代淘汰的手艺人（"它们凭什么能用那些劣质产品抢走我们的手工艺生意？"）；深藏功名（救出二十二名孩童——"那并不是我做的"）
- 关键信息：
  - **身世（重磅）**：前竞技骑士（"塑料骑士"——自制盔甲参赛——被大公司劣质产品抢走手工艺生意——"等我穿着它打赢比赛接受采访的时候，我就要宣告全城，这是我亲自做的。我要用这种方式，狠狠地打那些大公司的脸"）；退役后搬到茨沃涅克避风头（"很快大家就会忘记'塑料'瑟奇亚克"）
  - **爆炸事件（重磅）**：废弃街区爆炸——**救出二十二名孩童**（媒体误认他是英雄——"那并不是我做的"）；儿子（紫发男孩——被救/被玛恩纳目击送医）；与"织网人"（情报贩子）合作找儿子（"我要找到我儿子，带着他从这里出去"）
  - **与玛恩纳**：对峙（"你们临光家的人就这么喜欢袒护感染者？""我们都离开大骑士领这么远了，你凭什么把我们卷进事端？"）；被玛恩纳告知儿子下落（"紫发的男孩我见过一个……现在应该陪同伴去医院了"）
  - **结局**：拒绝儿子当骑士（"不要做什么当骑士的美梦……更不要想象骑士能保护什么人。梦想得越漂亮，你越会失望"）
- 经典台词："我要用这种方式，狠狠地打那些大公司的脸。它们凭什么能用那些劣质产品抢走我们的手工艺生意？"／"梦想得越漂亮，你越会失望。"
- 信息来源：活动《红松林》（act12mini）st04；活动《红松林·索娜线》（act9mini st04）
