# 埃芒加德（Emengarde / 巫妖信使）

- 身份：**巫妖王庭的信使**（驻维多利亚）；弗莱蒙特的学生（"小埃米"）；莱辛的"另类的弟弟"
- 首次登场：第十二章（提及）；第十三章正式登场；活动《崔林特尔梅之金》（act29side）
- 关键信息：
  - 以"小方块"（空间术式载具）出行；被赫德雷/W/伊内丝炸毁载具后接触
  - 告知军事委员会的秘密运输（血魔法阵/骸骨巨兽）与**巫妖的后手计划**：特雷西斯若成功→重建卡兹戴尔（"建国日"）；若失败→**拆分卡兹戴尔为十几块、按氏族藏进荒野**（"卡兹戴尔将会迎来又一个流亡时代"）
  - "卡兹戴尔不仅是一座城市，还是每一个把那里视作家的人"；认可赫德雷"让所有人都有家可回"
  - 《崔林特尔梅之金》：从卡兹戴尔赶回（"我的小方块都被这一路的风摩擦得多了不少线头"）；与莱辛并肩守住荒域通道（"莱辛，我另类的弟弟……我会在风中留意你的声音"）；以绳结（黑键）为线稳定通道
  - 巫妖的立场："我们行走于大地，收集知识，守卫知识……只要任何地方不再安定，我们就会立即离开""巫妖没法把自己变成莱塔尼亚人"
  - 结局：随弗莱蒙特离开莱塔尼亚回卡兹戴尔（"知识圣殿的看守人，准备回家了"）
  - 提及凯尔希曾警告巫妖（"我的老师为什么会有一位菲林老朋友"——巫妖与凯尔希渊源）
- 经典台词："我们也不知道他们（特雷西斯兄妹）究竟哪来的自信，但既然是他们两兄妹的计划，就一定有早就准备好的手段。""规划路线，平衡生产，确保卡兹戴尔变成移动城市这件事不是毫无意义。对萨卡兹而言，其他人类的敌意就是天灾。"
