# 文索内希俄斯 / 文（Vinsentios / Wen）

- 阵营：叙拉古（神秘艺术评论家）｜种族：？（"诞生于文明，却自疏于文明之人"）｜身份：《沃尔西尼艺术周刊》评论区作者
- 首次登场：活动《叙拉古人》（act21side）
- 关键信息：
  - **神秘的艺术评论家**：在《沃尔西尼艺术周刊》评论区活跃；对歌舞剧极有心得（指导空的表演——"你太习惯于舞台了，这反而让你难以作为一名歌舞剧演员站在舞台上"）；"以文明之名，行暴力之实，这就是家族的本质"
  - **西西里夫人的老朋友**："每个时代的人，总会被自己所诞生的时代束缚""怀念也是一种情感"；评价贝纳尔多的计划（"他只能想到用暴力去拆解，却无以为继"）、莱昂图索（"这是诞生于这个时代的萌芽"）
  - **《叙拉古人》**：与丹布朗（洗车工）的对话（艺术/文明/酒的价值观）；为丹布朗收尸（"只是这个无名之辈的朋友罢了""你与卢比奥一起，戳破了名为家族变迁的谎言"）；见证庭审/卢比奥之死（"当所有人都不再将血腥味认为是血腥味时，血腥也就成了文明的一部分"）
- 经典台词："规范使人在表面上拥有了对事物相同的敬畏，虚假的高台于是拔地而起，真正的敬畏却反而难见踪影。""发自内心的渴求，与将文明作为粉饰自己的表皮始终是不同的。"
