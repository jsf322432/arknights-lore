# 风笛（Bagpipe）

- 阵营：维多利亚军队（**风暴突击队**）｜种族：瓦伊凡（破城矛）
- 首次登场：第九章「风暴瞭望」
- 关键信息：
  - 号角的副手/挚友（"瓦伊凡的女人一定要坚持到底"——母亲的教诲）
  - 性格：热血直率、爱护平民；"在战场上，我还从没有怕过"
  - 调查达米安案；目睹脏弹轰炸；与深池激战
  - **结局**：号角掩护下以破城矛弹射飞出小丘郡，携情报出城（"不能回头看，这是命令"）
  - 与 Outcast 短暂并肩（"她真是我见过最震撼的破晓"）
- 经典台词："故乡变坏了就不是故乡了吗？用自己的双手让土地重新变得肥沃，这不是每个生活在这里的人都该做的事吗？""无论这片大地上发生了什么，天还是会亮。"
- 信息来源：第九章全部相关段落

> 待补充：后续去向（第十章起）
