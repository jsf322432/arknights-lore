# 埃克提尔尼尔

- 身份：萨米**雪祀**（"首席萨满/大萨满"——不一定最年长，但一定最有能力且有权威，相当于一个地方的首领）；北地"**树痕**"战士的领袖；萨米人心中最有权威的北地战士
- 首次登场：活动《麦哲伦冰原》（act15mini st06）
- 关键信息：
  - **形象（重磅）**：手握**荆棘战锤**（"荆棘朝他战锤所指的方向蔓延，扭转，结成隔绝邪祟的圆环，所有战士的源石技艺追随着他的武器延伸"）；不带惧色、不为自己是否会受污染而犹疑，走向被转化死者高举战锤（"念出的与被遗忘的名字都在一记重击之中消散"）
  - **"树痕"战士（重磅）**：北地阵线的精锐战士部队（"树痕"——埃克提尔尼尔正是为挽留所有迁往南方的萨米人而来）；主张不退缩不迁徙（"我们退无可退""我主张将那层雾彻底扫去""群山将成为无比坚固的防线，就像许多年前，恐惧还没有渗入萨米人心灵的那个世代""我们绝不离去，萨米人绝不消亡，无论要守卫多少世代，消亡的终将是灾异自身"）
  - **与南迁部族的矛盾（重磅）**：主持仪式的萨满（"当年雪灾时，您也这么说：'不可后退，不必迁徙，我们会停下雪灾'——十一月的狩猎后，暴风雪确实停了，黑色的雪线最终没有移到山的另一边"）；"你明白萨米人不必逃避的道理。你只是在替你的族人说话……而我主张将那层雾彻底扫去"
  - **认知与恐惧观（重磅）**："所有人都能克服恐惧""那是在千百场战斗之后"；"我们察觉到邪魔的痕迹，我们便为它打开了通道。我们恐惧，我们软弱的心灵成为它的苗床。认知到邪魔的人越多，每一场仗只会越加艰难"（萨满的担忧）×"所有人都会恐惧，所有人也都能克服恐惧"（埃克提尔尼尔）
  - **埃克提尔尼尔×寒檀（重磅）**："寒檀木裔，降生于冰寒的女儿"——点破寒檀"曾因为眷恋老树枝桠下的荫蔽而踟蹰，未能成为雪祀"；"矿石病已使我时日无多""这不是你连目标都失去的理由""你比任何人都更清楚复仇的虚无滋味。正因空虚，它才变成永无止境的事业，需要不断寻找新的生命去填补"；"比约妲""安妲萨"（祖灵之父的意志警示——"萨米抬起的山脉不足以隔绝灾异，我们唯一的敌人正在侵蚀这片土地"）
  - **灾异认知（重磅）**：率"树痕"战士救援船葬事件的泽地部族（"安德斯科塔尔尼尔"=敌人）；"邪魔在自然中的种种掠夺，你们都已经历过。无论生者还是死者，它们都一并夺去。命运将它们赐予萨米人，我们便要去面对它们，承受它们"
  - **北征（衔接）**：带战士前往南方（"将萨米的低语告知每一个部族"）——埃克提尔尼尔北征（寒檀密录 story_sntlla 提及："你撕裂萨米的部族，将萨米人与未来赌在一场无望的远征上"）
- 经典台词："我们退无可退。""消亡的终将是灾异自身。""所有人都会恐惧，所有人也都能克服恐惧。""群山将成为无比坚固的防线。"
