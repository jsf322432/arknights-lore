# 山（Mountain / 安东尼·西蒙）

- **身份**：罗德岛干员（前曼斯菲尔德监狱囚犯/越狱者——礼服爱好者——本名安东尼·西蒙）
- **经历（干员密录 story_f12yin_1_1/2_1，重磅）**：段1：赏金猎人任务（礼服战斗毁坏——柏喙（裁缝干员）/梓兰（前时尚杂志编辑/设计师）帮忙做战斗礼服——"你还未曾真正明白自己已经获得了自由"——柏喙父亲工业装备材料做面料）；段2：父母之死（堡垒山城——伯父留下积蓄——海德兄弟在曼斯菲尔德期间暗杀其父母——复仇之心）；噩梦（血泊中手刃海德兄弟）；杜玛（医疗部医生/曼斯菲尔德监狱时期帮他越狱的人）——"可你从未杀过人"；递交辞呈准备回堡垒山城复仇（把书留给杜玛——"这本书我还没有看完，请她代为保管"——插图=囚室中男人指向画外）；结局：独自离开罗德岛（"复仇是我自己的事，我绝不允许旁人被卷进来"）
