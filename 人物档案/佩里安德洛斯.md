# 佩里安德洛斯（Periandros）

- **身份**：**科林尼亚的祭司**（"科林尼亚的商人之子"——商人秉性/"做商人最讲究的就是诚信"）；雅赛努斯观礼嘉宾
- **经历（重磅，活动《雅赛努斯复仇记》act48side》）**：暗中考察雅赛努斯（向贝赫努打探——"里底娅小姐为了仪式也是尽心尽力"）；建议公投推缇缇当负责人；与里底娅的博弈（"您更关注的，与我一样，从来都是米诺斯自己的家事"）；提醒帕拉斯（拉刻代蒙祭司西妮斯卡的来历）；结局**提议城邦联合**（"回归往日的城邦联合，重启古老的盛典……重铸米诺斯的荣光"——考察里底娅/西妮斯卡的响应）
- **理念**："已经清账的交易属于过去，更重要的，是为未来寻找机会""只要出得起价，都可以（出售）——包括尊严、良心、灵魂"
