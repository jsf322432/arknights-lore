# 尤莉叶（Yurie / 尤莉叶）

- 身份：萨卡兹雇佣兵出身；追随特蕾西娅的战士；后为特雷西斯麾下刺客（"刽子手"）
- 首次登场：活动《巴别塔》（act33side，1091 年追随特蕾西娅）
- 关键信息：
  - 无父无母（名字是别人送的，"她说名字会让我有归属感"）；"受够了打来打去"而追随特蕾西娅（"殿下总有一天会让我们不再打来打去，所以我来替她看看"）
  - 1094 年春赴**伦蒂尼姆卧底**（蛰伏特雷西斯雇佣兵军中、伺机掀起叛乱"借刀杀人"）；阿斯卡纶代殿下转交绣名旧衣（"我不希望你们两个相见……不想让殿下难受"）；伦蒂尼姆郊外截杀派往卡兹戴尔的刺客（"我会用火抹去你们的面孔……好像我们也没什么区别。我也回不去了"）
  - 与巴别塔刺客小组行刺特雷西斯失败（"我们正在进行一场赛跑……你们的终点，是我的，或是她的性命"）——**最终被特雷西斯接纳为"刽子手"，派往诸王长眠之所伏击蒸汽骑士**（st01："我们是不是，不可能活着离开那里？""大可去争取。"）；"在我发誓追随特蕾西娅殿下时，从未想过那一对改写了卡兹戴尔历史的混血双子的故事会如此落幕"
- 经典台词："谁不想最后见一眼殿下呢。""我会把对你的憎恨，带进坟墓。"
- 信息来源：活动《巴别塔》（05_beg/08_beg/08_end/09_beg/st01）
