# 号角（Horn / 斯卡曼德罗斯）

- 阵营：维多利亚军队（**风暴突击队**中尉）｜种族：鲁珀（狼）；贵族出身（"白狼伯爵"之女）
- 首次登场：第九章「风暴瞭望」
- 关键信息：
  - 皇家近卫学校优等生（汉密尔顿："阿斯兰的亲信要族之后，伦蒂尼姆的军中新贵"）
  - 调查源石制品失窃案；与汉密尔顿上校正面对抗（"维多利亚以他为耻"）
  - 立场："战争不是目的，而是手段"；拒绝脏弹暴行；"我以三角铁小组的名义起誓……我一定会把你抓上军事法庭"
  - **通讯塔之战**：重伤后掩护风笛弹射出城（"风笛——活着出去！这是我们最后的机会！"）——生死未明
  - **第十章**：城墙死守拖延曼弗雷德（重伤幸存，被 Misery 所救；"维多利亚打造出来的武器，依旧驻在伦蒂尼姆的城墙上"）
  - **第十二章**：自救军撤离战断后（"剩下的，就交给运气吧"）；被突然现身的**最后的蒸汽骑士**救下（喷气声再响；"维多利亚。"）
- 经典台词："维多利亚以他为耻。""我不习惯用未经审判就匆匆砍下来的人头交差。""风笛——活着出去！""军人本就该死在战争中。""坚持最后两分钟，我会掩护你们撤退！"
