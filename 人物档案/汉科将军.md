# 汉科将军（General Hanko）

- 阵营：玻利瓦尔（"真正玻利瓦尔人"领袖/将军）｜身份：老将军（"用半个世纪为玻利瓦尔找到的答案"）
- 首次登场：活动《丛林症结》（act21mini，2026；st04 和平协议时期——玻利瓦尔内战开端）
- 形象：衰老疲惫（"镜中曾映照过一张年轻、英俊的脸。如今那张脸老了，眼睛也逐渐没了光"）；胸前挂满奖章（两年前一枚在心脏位置替他挡下刺杀——"奖章中心已然凹陷"）
- 关键信息：
  - **和平协议（重磅）**：与联合政府谈判两个多月；同意条款——"除各通商口岸外七成哥伦比亚武装部队撤离玻利瓦尔本土""玻方解散真正玻利瓦尔人军队""西线与辛嘉斯政府的争端由哥伦比亚出面调停"＋**新增"所有士兵需按规定前往各区种植园，参与劳动和重建工作"**（"清洗"计划——"有的人天生就是肥料"）
  - **立场**："持续的内战让你目光短浅：玻利瓦尔现在最需要的，是拥有我们自己的作物和工厂。只需要哥伦比亚人的一点微小的助力，我就能让耕地和工厂无限扩大、让玻利瓦尔重新拥有站起来的可能"；"如果哥伦比亚人给你承诺……循序渐进，我们总能做到"（杜宾斥其"循序渐进地，变成下一个联合政府？"）
  - **遇刺（重磅）**：被心腹**杜宾上校**以匕首刺穿后背（"这是你自己的选择……仅仅是我，一个在泥地里翻滚……将我的亲人、友人，一个接一个埋入地底的玻利瓦尔士兵的愤怒"）；临终："真正属于玻利瓦尔人的玻利瓦尔……那样的玻利瓦尔压根就不存在！"
  - **"领袖之死"的影响**：签字仪式由联合政府代表接管（"谁签字谁就是玻利瓦尔实际的领导者"——军阀/雇佣兵/种植园主争抢签字，**内战开端**）；ST01 军官语"这两年那些真正玻利瓦尔人因为领袖的死而在内战中打得不可开交"（"领袖"即汉科）
