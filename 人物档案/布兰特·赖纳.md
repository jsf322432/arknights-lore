# 布兰特·赖纳（Brandt Rainer / 金律法卫）

- 身份：**金律法卫**（面具/金色帷幕使用者）；霍赫贝格家族旧部（沃尔纳/恩斯特的挚友）；珂拉的故友
- 首次登场：活动《崔林特尔梅之金》（act29side）
- 关键信息：
  - 忠诚："金律法卫的剑与法术，都只属于金律乐章与莱塔尼亚"（"你效忠的，早已并非霍赫贝格家族"——赫琳玛特）；曾与沃尔纳/恩斯特一同长大（被选中接受金律法卫训练前想留下，被二人劝离——"你要守护的，远比任何一个人的性命，远比霍赫贝格家族更重要"）
  - 心结：**23 年前政变之夜未及时驰援**——"霍赫贝格家族在巫王塔下死伤惨重。碍于金律法卫的身份，布兰特未能及时驰援。这导致了他最好的朋友，霍赫贝格家族的继承人恩斯特战死……也导致了你的父亲沃尔纳不得不继任选帝侯"；对霍赫贝格家族的愧疚"一直蚕食着他的心灵"
  - 源石技艺：金律法卫的"黄金旋律"（审问/束缚/金色帷幕——"这是十个以上的金律法卫才能使用的法术"）；可凭"演奏"画幅剥离颜料层
  - 《崔林特尔梅之金》：与薇薇安娜搭档查案（画作/残党）；在路德维格大学展开金色帷幕封锁（"没有巫王残党能活着离开这座塔"）；**阿尔图罗以琴声共鸣其心扉**（"布兰特·赖纳，他的心灵终于对我的旋律敞开"——他直面"金律法卫的意志是否只是谎言"之问）；最终在"湮灭奏鸣塔"与"救薇薇安娜"之间**选择救她**（"就算要拼上我的性命……我也会把你安全地送走"）
  - 结局：珂拉死后首次摘下面具（"这是我第一次，见到您的面容"——薇薇安娜）；"只是一位'金律法卫'，不应来缅怀一位破坏女皇庆典、篡改金律乐章的主谋"；向伊维格娜德效忠（"赫琳玛特……是一名伟大的君主。我们将铭记她的付出"）
- 经典台词："再伟大的个体意志，都无法与莱塔尼亚本身相提并论。""那么，我会杀死混乱本身。""我以我的血肉与灵魂保证——没有巫王残党能活着离开这座塔。"
- 信息来源：活动《崔林特尔梅之金》（全文）
