# 赫琳玛特（Helimart / 黑塔女皇·"无情权威"）

- 身份：莱塔尼亚**双子女皇**之一（黑塔/"无情权威"）；本名**希尔德加德**；诞生于术式的双子（弗莱蒙特提供塑造术式）
- 首次登场：活动《崔林特尔梅之金》（act29side）
- 关键信息：
  - 性格/威名：严酷无情（"下一个巫王"之讥；"找得到的，全都死了"——清除与维多利亚勾结的贵族）；"人们这么怕你"；米夏埃尔："赫琳玛特虽然很凶狠，但并不邪恶！"
  - 与巫妖合谋：让弗莱蒙特取走"尘世之音"、研究召唤"始源之角"（"我们必须立刻找到巫王的遗产"）；目的——"可控的力量，会成为属于莱塔尼亚的最锋利的剑"（对付未知威胁）
  - 本名与称呼：伊维格娜德称她"希尔德加德"；她称伊维格娜德"莉泽洛特"（"你先去吧，莉泽洛特"）
  - 《崔林特尔梅之金》：一剑碾碎"赝品"巫王塔（"莱塔尼亚的土地上，不允许再投下赫尔昏佐伦的阴影。尤其是，赝品。"）；金律法卫"帷幕"的发动者（号令/低音号与米夏埃尔）；与伊维格娜德合奏迎战巫王（剑）
  - **结局：舍身留荒域**——以始源之塔碎末建成"塔"（丰碑横亘现实与荒域之间）挡住混沌中的"邪魔"（"虚无中的眼睛，混沌中的威胁，恐惧凝结的实体……'邪魔'。我，赫琳玛特，莱塔尼亚的女皇，莱塔尼亚最锋利的剑——我在此宣布，你永远无法入侵我的国度。"）；自此"失声"（留在荒域）
  - 与米夏埃尔：救下 7 年前来觐见的鲁珀少年（"是时候放你离开了……终有一天，你需要为莱塔尼亚的明天承担起更多责任"）；"我们没有办法选择自己的出身，但至少应当能选择什么时候转过身去"
- 经典台词："莱塔尼亚的土地上，不允许再投下赫尔昏佐伦的阴影。""这是我的命运。但这绝不是……莱塔尼亚和莱塔尼亚人的命运。""赫尔昏佐伦，你曾经将机会带给每一个莱塔尼亚人。但你毁于自己的欲望。"
- 信息来源：活动《崔林特尔梅之金》（全文）
