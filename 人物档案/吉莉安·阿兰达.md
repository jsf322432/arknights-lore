# 吉莉安·阿兰达（Gillian Aranda）

- 阵营：玻利瓦尔裔（哥伦比亚警备背景）｜身份：哥伦比亚警备队后备员/物流安保公司武装押运人员
- 首次登场：活动《丛林症结》（act21mini，2026；st01）
- 形象：正直、理想主义（"如果因为正确的事情太困难就不去做的话，如果因为简单的事情不够正确也不去做的话——不就什么都永远不会改变吗？"）；佩洛（推测）
- 关键信息：
  - **身世**：玻利瓦尔人（讲话带哥伦比亚口音，被游击队称为"假玻利瓦尔人"）；年初工作物流公司倒闭，返回故乡碰运气（联合政府物流业"普遍只收联合政府公民"）
  - **洛伦茨种植园（重磅）**：倒在路边被洛伦茨小姐收留；被识破为"线人"身份（洛伦茨替她圆场）；得知种植园"液体化肥"（黑流）的真相——"这些钱财本来就是用他们的生命换来的，当然也就应该属于他们"（洛伦茨）
  - **游击队袭击（重磅）**："真正玻利瓦尔人"游击队员炸毁种植园（"假玻利瓦尔人当然不是我们的同胞"）；埃玛（猎犬病死）、胡安（拒弃尸）、小贝拉（埃玛之女）；**吉莉安以盾支撑将塌建筑力竭**（"你们既然自认有能力对抗哥伦比亚人，难道你们就没想过建起一些工厂让这些走投无路的人活下去？"）；被游击队新兵认为"已经到极限了"（生死不明——故事中与洛伦茨一同被弃于废墟）
- 经典台词："什么是对的，什么是错的，嘴上讲起来很简单。但就算讲出来，也什么都不会改变，什么也不会发生。……所以要去做。"／"救人难道是错的吗？让更多无辜的人活下去难道是错的吗？"
- 信息来源：活动《丛林症结》st01
- 备注：与米格鲁存在经历对应（哥伦比亚警备预备队背景）——按"梦境舞台"框架，吉莉安或为米格鲁顶替的"剧本"之一（文本未明示）
