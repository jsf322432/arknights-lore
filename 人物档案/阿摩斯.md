# 阿摩斯（Amos / 第七厅枢机辅佐官→代理枢机）

- 身份：第七厅调查员→枢机辅佐官→代理枢机；奥罗拉的丈夫；在灾异中为掩护蕾缪安牺牲
- 首次登场：活动《众生行迹》（act42side）
- 关键信息：
  - 性格："我是个没什么追求的人"（蕾缪安："七厅倒是还有很多事需要你做"）；"我是不是真是个很没用的家伙？"（自疑）
  - 与奥罗拉：妻子是堕天被驱逐的铳骑（他无法面对帕特里奇昂——"那件事情，完完全全就是我妻子的错"）；盼着当上万国信使去玻利瓦尔见她一面（"我只是想着能见她一面，为当年吵的架道个歉什么的"）
  - 觉醒线索：接任枢机后批准自己的万国信使申请——**申请凭空消失**（"它就那么消失在了我的终端里，像是从来没有存在过"——证明拉特兰的不真实）；向蕾缪安分享（"或许您妹妹想做的事情，是正确的"）
  - 牺牲：在育婴圣堂外断后掩护蕾缪安（"我会守住这个街口……我会守住的"）；被围攻（"他们直接对我开火了，看来我们的推断没错"）；遗言（通讯未断）——"我是不是真是个很没用的家伙？""我年轻的时候，可是拿了七厅新员工入职射击比赛第五名的啊！""真遗憾啊，没能成为彼此的救赎。"
- 经典台词："我只是想着能见她一面，为当年吵的架道个歉什么的。""是梦也好。是梦的话，就不用有什么顾忌了。""起码，你是个很好的调查员。"（蕾缪安）
