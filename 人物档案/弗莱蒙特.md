# 弗莱蒙特（Fremont / 老巫妖）

- 身份：**巫妖**（巫妖王庭辈分最高者之一）；路德维格大学最古老高塔的隐居者（数百年）；赫尔昏佐伦的挚友；莱辛的养育人；埃芒加德的老师
- 首次登场：活动《崔林特尔梅之金》（act29side）（主线第十二~十三章曾以巫妖身份暗线铺垫）
- 关键信息：
  - 巫妖：萨卡兹中的流浪者（"巫妖只是知识殿堂的守门人……从不干涉各个国家。这是巫妖王庭与你们先祖的契约"）；"命结"=系在帷幔中的绳结（生命共振/近乎无限的生命）；影子裂成丝弦；"放逐"巫术（可将目标湮灭于虚空）
  - 与赫尔昏佐伦：年轻时为莱塔尼亚新君提供塑造双子的术式；赫尔昏佐伦改写金律乐章时借用他的密室（"我是不是该跟赫尔昏佐伦陛下顶嘴？"）；**曾将命结借予他**研究荒域（巫王早已归还——"死亡不会追上你，它只是追上了我。为何对你来说，承认它却如此艰难？"）
  - 路德维格大学：以学者身份隐居数百年（"我在莱塔尼亚待了好几百年"；从维杜尼亚到崔林特尔梅）；赫尔昏佐伦调教手下的空间术式是他教的
  - 《崔林特尔梅之金》：从黑键脑中取走"尘世之音"（召唤"始源之角"失败——"就跟一堆人紧张兮兮地凑在一起准备点个火把双子塔炸上天，结果却只在下水道放出了一只和你半斤八两的钳兽"）；被金律法卫识破巫妖身份；率巫妖们以丝弦/星辉退却黑焰后**离开莱塔尼亚**（"赫尔昏佐伦死的时候，我们就该走了。只是……迟来的告别罢了"）
  - 荒域：随阿尔图罗进入帕维永；与巫王诀别（"放逐"送走老友——"你只是来道别吗？弗莱蒙特啊，我的挚友。这座高塔，为何仍如此矮小……"）；以命弦支撑崩塌的空间（"湮灭的时刻就快到了。要是真让荒域渗出去……大家一块完蛋"）
  - 结局：率巫妖启程——"告诉你在卡兹戴尔新交的好朋友，巫妖王庭……不，没有什么王庭，告诉他们，知识圣殿的看守人，准备回家了"
  - 警示：曾窥见虚空（"虚空……无穷无尽的……邪魔。虚空从来不是……空的"）——"禁忌不可被轻易触碰"
- 经典台词："巫妖只是知识殿堂的守门人。""我怎么可能吵得赢一个回声，杀得死一个死人？""赫尔昏佐伦，你这活该再死一千遍的老家伙，看看你给我们留下的烂摊子。"
- 信息来源：活动《崔林特尔梅之金》（全文）；主线第十二~十三章（巫妖线索）
