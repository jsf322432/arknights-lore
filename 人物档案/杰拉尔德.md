# 杰拉尔德（Gerald / 本名霍斯特·蒂芬达尔）

- 身份：修道院萨卡兹猎户（化名"杰拉尔德"）；本名**霍斯特·蒂芬达尔**——中庭公证所通缉犯/前卡兹戴尔内战雇佣兵；萨卡兹难民群的领袖
- 首次登场：活动《空想花庭》（act26side）
- 关键信息：
  - 过去：卡兹戴尔内战中崭露头角的雇佣兵（曾追随特蕾西娅殿下——"不知道什么时候起，我不再能看见殿下描绘的图景……在卡兹戴尔的两位殿下身上，我找不到我们萨卡兹的未来"）；**三十二项罪名**，曾**灭杀教皇厅旗下三支执行小队**；带领"愿意离开的人"逃出卡兹戴尔
  - 修道院生活：隐姓埋名为猎户（带队打猎/护卫）；与爱侣爱琳（已故，葬于修道院）共同留下；爱琳："搞不好几年、十几年之后，凶名赫赫的雇佣兵都要变成乡下猎户咯"
  - 《空想花庭》：得知福尔图娜堕天深受打击（消息来源成谜）；圣堂大火后决定率萨卡兹**连夜撤离**（"明早不论如何都会动身"；探路队先行）；赫曼失踪（"祈祷执行者阁下说的'怪物'不会是你"）
  - **结局：自尽献首**——"罪人"霍斯特·蒂芬达尔自愿献上头颅，承认所有恶事均为其一人所为（请求放过福尔图娜/莱蒙德/其他萨卡兹）；佩刀交费德里科（"接下萨卡兹雇佣兵的武器=名号的传承"）；遗言托克莱芒转告斯特凡诺："谢谢，我很抱歉""或许最开始我们就不该贸然停下"
  - 临终自问："我究竟是个猎户，还是……依然是那个雇佣兵？"
- 经典台词："如果用我的脑袋就能交换其他人的生路，也算是值得。""杰拉尔德，我们回不了头了。你我都是。""我没事。至少现在，我们已经有了新的生活。"
- 信息来源：活动《空想花庭》（全文）
