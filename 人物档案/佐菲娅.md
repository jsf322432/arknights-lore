# 佐菲娅（"鞭刃" Zofia）

- 身份：**"鞭刃"骑士**；临光家陪侍（玛嘉烈/玛莉娅的"姑母"——实际只大她们五岁）；玛莉娅的教练
- 首次登场：活动《玛莉娅·临光》（act13d5）
- 关键信息：
  - 特锦赛十六强战重伤退役（对手"裂隙"骑士——装备差距："自己攒的装备，自己磨练的技巧……孤立无援地拼着命"）；右臂旧伤（"用从未使用过的那只手抚上剑柄……肌肉的剧痛从腰部传递到手臂"）
  - 曾是玛嘉烈的仰慕者（"像我这样单纯钦佩着那个玛嘉烈，头脑一热就成为了骑士的人不在少数"）；佩剑为西里尔·临光所赠
  - 成为玛莉娅教练（"我好歹是临光家的陪侍"）；反对玛莉娅继续参赛（"在竞技场里，没有一场胜利是属于骑士的，胜利只属于卡西米尔，属于企业"）又转而认可（"你证明了自己……你和你的姐姐一样，你是骑士"）
  - 玛嘉烈回归时扇其一巴掌（"刚才那巴掌是我替玛莉娅打的"）；"你回来了……真好，真的"
  - 《长夜临光》中继续支持玛嘉烈夺冠（酒吧众人之一）
- 经典台词："在竞技场里，没有一场胜利是属于骑士的，胜利，只属于卡西米尔，属于……企业。""你证明了自己。""你回来了……真好，真的。"
- 信息来源：活动《玛莉娅·临光》（全文）；活动《长夜临光》
