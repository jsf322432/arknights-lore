# 珂拉·洛文斯坦（Cora Lowenstein / 皇家乐团调音师）

- 身份：莱塔尼亚皇家乐团**调音师**（盲眼）；沃尔纳·冯·霍赫贝格的故友；薇薇安娜的守护者/"珂拉阿姨"；**巫王残党"首席"**（卧底任务）
- 首次登场：活动《崔林特尔梅之金》（act29side）
- 关键信息：
  - 身世：曾为巫王塔中的小侍从（"从来到维杜尼亚的第一天起，我就进了那座漆黑的塔"）；**二十三年前政变之夜失去视力**（被沃尔纳从废墟中救出——"他亲自动手把我从废墟里拉了出来"）
  - 与沃尔纳/露辛达：二人将生活的美好带给她（"我所能感知到的所有生活的美好，包括布兰特，都是沃尔纳和露辛达带给我的"）；13 年前送薇薇安娜去卡西米尔（皇家乐团出访作掩护——"调音师，一个相当便利的身份"）
  - 源石技艺："调音"——为他人法术/乐器"调音"（可反制法术）；能"听"出颜料频率（弗里达画作分层）等
  - 《崔林特尔梅之金》：以"调音师"身份协助薇薇安娜查案（父死/画作/残党）；被揭穿为**巫王残党"首席"**——"成为巫王残党的'首席'，给予他们诱饵和希望，引他们自己步入深渊，是女皇交予我的任务"（二十三年的卧底）
  - **背叛女皇**：沃尔纳死后（"他离开得太决绝，放弃得太轻易，又太无可奈何"），决意借残党之手给金律乐章"调音"——**摧毁乐章**（"金律乐章就是困着莱塔尼亚的螺旋楼梯本身""过时的乐章不再困住每一个人"）；女皇们知情并放任（伊维格娜德："你想问我是否对珂拉有所放任，对吗？在这件事上，你不也一样？"）
  - 结局：**被薇薇安娜杀死**（"我很高兴，最后杀死我的，是我最爱的人"）；将全部情感与记忆留给阿尔图罗的琴声（"我的全部情感与记忆都留给你了"）；遗言"你值得过上更好的生活，薇薇安娜……如果真有的话……"
- 经典台词："我们并不是没有矛盾，但我们试着彼此接纳。""金律乐章就是困着莱塔尼亚的螺旋楼梯本身。""总要有人去做的。我的生命本就乏善可陈，仅剩一点……甚至未曾完全属于我的光亮。"
- 信息来源：活动《崔林特尔梅之金》（全文）
