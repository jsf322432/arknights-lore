# 爱琳（Erin / 杰拉尔德的伙伴·已故）

- 身份：萨卡兹；杰拉尔德的伙伴/爱侣（已故，葬于安布罗修修道院）
- 首次登场：活动《空想花庭》（act26side，st02 回忆/遗言）
- 关键信息：
  - 与杰拉尔德：一同离开卡兹戴尔（"我们那时离开卡兹戴尔，已经背弃了特蕾西娅殿下……杰拉尔德，我们回不了头了。你我都是。"）；劝慰杰拉尔德放下过去（"你也别再想之前的事了"）
  - 性格：乐观豁达（"老人家就得放宽心，少操心少管事，这样才能长寿！"）；喜爱修道院的花期风景（"爱琳特别喜欢那种风景"）
  - 与修道院：与杰拉尔德同住多年（"现在这日子……比从前好多了"）；与杰拉尔德的约定（"如果你愿意，你可以亲自确认"——变作乡下猎户的未来）
  - 死后：葬于修道院墓地；杰拉尔德临终"先一步去见爱琳"（"抱歉，爱琳，我现在的样子，恐怕你看了也不会感到满意吧"）；克莱芒晨间为其找花（"杰拉尔德总不能空着手去见爱琳"）
- 经典台词："搞不好几年、十几年之后，凶名赫赫的雇佣兵都要变成乡下猎户咯。""你我都是。我们回不了头了。"
- 信息来源：活动《空想花庭》（全文）
