# 萨卢斯（Salus）

- 身份：**赦罪师**（萨卡兹王庭/军事委员会所属，巫术/实验派）；为赦罪师首领与特雷西斯效命
- 首次登场：第十三章「恶兆湍流」
- 关键信息：
  - 在温德米尔军舰遇袭的混乱中**掳走阿米娅**（"卡特斯，不，奇美拉。你终究不是特蕾西娅呀"），意图抽取其头顶**黑冠**（"它也应该能被抽取出来才对呀"）——"我们，已经探究了魔王数个千年了"
  - 试图读取博士的记忆失败（博士的精神力量排斥赦罪师巫术）；被 Logos（女妖之主）与阿斯卡纶击退逃脱
  - 带走**夜莺（丽兹）**（"我开始有些想念丽兹了"——闪灵/夜莺线伏笔）；提及特雷西斯对博士"格外关注"
  - 自称首领废弃的实验洞窟（萨卡兹石像/雕像）——黑冠研究现场
  - **第十四章**：守卫"提卡兹之血"（"我会用自己所有血脉的力量……用我的生命来守护它"）；与阿米娅/博士对峙（"你们为什么，觉得自己应该反抗？""我们难道不都是……被寄托了希望的奇美拉？"）；被阿米娅宣判后仍挣扎——**以自身之血引爆仪式、壮烈牺牲**（"先于首领，先于奎萨辛娜，先于我所有的家人……走进我所向往的未来之中"）
- 经典台词："你是个被人赋予王冠的幸运孩子，但你真的了解你的力量吗？""我们会先留这位博士一命，我也会教你利用自己的情感。""我……会走进我所向往的……未来之中。"
- 信息来源：第十三章、第十四章（14-08/14-11）
