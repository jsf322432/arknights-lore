# 沃里克伯爵（"颂古者" / Count Warwick）

- 阵营：塔拉文化复兴（"塔拉人之家"）｜种族：（塔拉人贵族）｜身份：爱布拉娜/拉芙希妮的老师；塔拉民族主义先行者
- 首次登场：活动《照我以火》（act22side，1090 年橡林郡/回忆）
- 关键信息：
  - **塔拉文化复兴者**：组建"塔拉人之家"（塔拉人自己的剧院/历史剧作——"首场演出就有两百人前来观看"）；研究盖尔王传说/塔拉历史（"从盖尔王的传说开始找回塔拉的历史"）；观点（"我们不得不使用维多利亚的语言""太过精致的知识正是我们的敌人"）；威灵顿公爵曾向其宴会派出使者（"这艘战舰的巡游正是从那时开始"——威灵顿的关注）。
  - **寻找德拉克（重磅）**：半生搜寻幸存的德拉克（"塔拉未必不会再有下一条红龙""如今我们谁也没见过德拉克，又怎么知道自己身边走过的人其实不是瓦伊凡呢？"）；收留/培养爱布拉娜与拉芙希妮（教塔拉历史与仇恨——"他教我们，毁去无辜者的生活，激化塔拉人与维多利亚人的矛盾……他还谋害了落魄的政敌"——苇草回忆）；爱布拉娜眼中的老师（策划复仇/野心）。
  - **结局（被毒杀）**：爱布拉娜说服其仆从背叛、以甜酒毒杀（"既然你已经说服所有人背叛了我……那这杯甜酒，我为什么不喝呢？"）；死前欣慰（"贪婪的德拉克，野心无穷无尽的德拉克……我半生的搜寻，没有找错""我看到……属于塔拉的新时代……近在眼前"）；临终望向窗外大雪（"十年前冬夜，他念完传奇小说，手指抚过书脊上烫金的塔拉字母"）；遗言："拉芙希妮……你会是谁的学生？"——姐妹俩道路的抉择之问。
- 经典台词："太过精致的知识正是我们的敌人。""我放下战士的荣誉，只为以后塔拉的土地不必再被鲜血浸泡，德拉克的同族不必再刀剑相向。""我看到……属于塔拉的新时代……近在眼前。""拉芙希妮，你会是谁的学生？"
- 信息来源：活动《照我以火》（全文——1090 年橡林郡/毒杀回忆）
- 后续：已故（约 1090 年，被爱布拉娜毒杀）；其"寻找德拉克"的执念成为深池的源头之一
