# 帕拉斯（Pallas / "胜利女神"）

- 阵营：米诺斯（阿克罗蒂）｜种族：丰蹄｜身份：祭司（"带着十二英雄的启示"）；村民信仰的"女神"
- 首次登场：活动《灯火序曲》（act7mini，2021；st02）
- 形象：神神叨叨（"我该称呼您为……？"——萨尔贡来客语）；博爱（"我们不能以正在进行的战争为借口放弃救助生命"）；语言华丽（"异乡的战士啊，你对她的举动作何感想？"）
- 关键信息：
  - **身份（重磅）**：米诺斯祭司（"英雄殿里人们夸我是最亲切的祭司"）；村民称"**胜利女神**"（"你是米诺斯人的指挥官，是培养这里的民族战士的指引者，是米诺斯这些村子信仰的什么个'女神'角色"——萨卡兹佣兵语）；"带着十二英雄的启示，来此地守护米诺斯人的尊严与自由，对抗萨尔贡的侵扰，并总能以少胜多"
  - **阿克罗蒂（重磅）**：米诺斯近萨尔贡边境村落地区；米诺斯×萨尔贡的战争（"这里正在和萨尔贡的部族发生战争"）；萨卡兹佣兵被米诺斯人雇佣（三个月）
  - **救暴雨（重磅）**：边境救下昏倒的萨尔贡库兰塔逃兵暴雨（"一位或许无辜的年轻人……她已经通过了你的考验"）；说服萨卡兹佣兵冷静（"这一次是我判断，萨尔贡的敌人没有在此时袭击的理由"）；送暴雨离开（赠指南针——"前进是一种选择，绝妙的选择"）；**与萨卡兹杀手对峙**（杀手=被雇来"解决"暴雨的——"我绝不会允许"）
  - **理念（重磅）**："找寻到自我的容身之所"（对暴雨）；"你的眼睛暂时浑浊，但历经一些风雨，理应会重新清澈"
- 经典台词："前进是一种选择，绝妙的选择。"／"我们都在没有终点的旅途上行进……眼下却有必须经历的，最重要的事情——找寻到自我的容身之所。"／"我们不能以正在进行的战争为借口放弃救助生命。"
- 信息来源：活动《灯火序曲》st02
