# 托尔瓦尔德（Thorvald / 已故）

- 身份：**塞弗林独子**；塔佳娜的未婚夫；火灾"遇难者"（非感染者）；**火灾真凶之一**
- 首次登场：活动《沃伦姆德的薄暮》（act11d0，sub-1-1 揭示真相）
- 关键信息：
  - 表面：好孩子（"托尔他本来是个好丈夫""埃克哈德……毕德曼……托尔瓦尔德"——火灾八名遇难者之一）；塞弗林"失去的儿子"
  - **真相（sub-1-1）**：火灾前与**危机合约极端信使**密谋——信使策划"点燃一把火"引贵族关注（"只需要一场火灾"）；**托尔提供"留声机"施术单元核心**（城防装置过载→瞬间高温=火灾真相）；"你似乎很确定感染者会出事，托尔"（毕德曼质问）；托尔以冰雪法术掩盖行踪（"快被自己的源石技艺冻死了"）
  - 结局：死于暴乱（"那里是我的坟墓……还挺近的"——信使在留声机处"了结自己"）；毕德曼被灭口（托尔或信使所为）
- 经典台词（毕德曼质问）："你似乎很确定感染者会出事，托尔。平时是那副好孩子嘴脸，为什么现在这么坚决地认定事情会往最坏的方向发展？"——"因为一定会发生。"
- 信息来源：活动《沃伦姆德的薄暮》（sub-1-1 外传）
