# 杰西卡（Jessica / 杰西卡·布林雷）

- 阵营：黑钢国际（B.P.R.S. 雷蛇小队副手）→ 罗德岛关联｜种族：菲林｜身份：狙击干员（装备与应用技术部门出身）
- 首次登场：第四章「急性衰竭」（4-1）；重磅补全于活动《不义之财》
- 形象：怯生生、容易慌张（"我可不能……拖后腿"）→ 经达维镇事件后蜕变（"平生第一次在一个瞬间内做出决定"）；23 岁
- 关键信息：
  - **身世（重磅）**：**雷神工业负责人兼大股东伯尼·布林雷之女**（"杰西卡·布林雷"）；"不想受家里人的庇护，走家里人为我规定好的道路"才当佣兵（初衷："排除危机，解决冲突，在险境中保护别人"）；有哥哥姐姐（"为了证明我自己不比哥哥姐姐差，为了证明我不是家族里的平庸之辈"）；家族律师"比今天在场的佣兵还多"
  - **黑钢履历**：约七年前进巴伦基地（先做装备测试员，后转作战）；被雷蛇选为 B.P.R.S. 副手（"不是因为你手中的铳械，而是因为你的眼泪"）；当过五年佣兵；与卡尔（精铁）在切城一同侦察（卡尔伤重死在眼前——"夺走一个人的生命，我只需要一秒钟……但若要我忘记那一秒钟，却得耗尽我整整一生"）
  - **主线**：废城目睹梅菲斯特焚炉暴行后心理创伤；被阿米娅安抚重新振作；与陨星/霜叶并肩作战（第四章）
  - **维多利亚**（主线 9-14 章相关）：亲历萨卡兹登上地块的惨剧（市政厅地下室求救录音"无论是谁……求你，帮帮我们"）；回巴伦基地后冲进指挥部质问（"数百名维多利亚平民"）；被克里夫警告"不要再犯和维多利亚那时同样的错误"
  - **《不义之财》（达维镇）**：受克里夫之托带子弹给伍德洛；帮里昂卖股份还债（自掏支票补漏洞，被西尔维娅协助）；试图以家族名义替全镇还债失败（需两千八百四十五万金券）；参与金库劫案（"算我一个"）；里昂殉镇（"我没看到他走出来……我等了……可我没能等到他"）；被围捕后向天鸣铳自首（"我的铳械会为他们的悲伤而鸣"）
  - **结局（重磅）**：拒绝家族律师的脱罪方案，**自愿去拓荒地服刑**（"我触犯了法律，这是我应付出的代价"）；离职申请被克里夫驳回（仍是黑钢员工——"说不准哪天在拓荒地出任务，我们就得去找她"）；与伍德洛同行（"这次不一样，这次我不追了。因为从一开始，我就会在"）；祖父教诲（沙堡比喻："当一切都失去时，未来仍然存在……不要惧怕重新来过"）
- 经典台词："我的眼泪……不能代替他们表达自己的悲伤。但我的铳械会为他们的悲伤而鸣。"／"我救不了它，但我至少……能让它在一个温暖的怀抱里离开。"
- 信息来源：第四章 4-1~4-10；活动《不义之财》全文 19 段
