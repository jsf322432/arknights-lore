# 颉（Jie）

- 身份：**岁兽碎片（五姐——"一十二之五，承名为颉"）**；**史官**（协助炎国编撰史书数百年）；"书刀"之主（"其笔，际究天人；其刀，变通古今"）
- 首次登场：活动《相见欢》（act49side，回忆/生机/真相）；此前在《将进酒》《怀黍离》《春分》中被多次提及（已消失的妹妹）
- 关键信息：
  - **岁兽碎片（五姐）**：与历史/文字共生的代理人；给兄弟姐妹取名（"我精心为大家取的这些名字……不想让它们在历史上消弭无踪"）；教余读书写字（接龙游戏/"纸"的发明——"写在纸上的文字，也许能保存数百年……只有记下来的东西，真正被人们记住了，那才能永远地留存下去"）；"大姐口吐莲花，二姐口含天宪，我也只好占一个口轻舌薄了"
  - **书刀与权能（重磅）**："其笔，际究天人；其刀，变通古今"——**书刀可以删改"一个人的名字，一个人的存在，甚至是一整段历史的存在"**；**颉的力量与历史共生**（"大炎的历史越是厚重，与历史同生的她，也将越发难以制约……再过个百年千年，她恐怕会成为比岁兽本身，都更加强大、更加恐怖的力量"——司岁台忌惮）；"经过她手的史册文章，只要她不愿意，便无人能够修改"；**颉的史观**（"应该做的是论辩、澄清，在过程中形成新的共识，而不是一删了之""历史从不是谁的一家之言，是万万人无声之言""我留下这柄书刀，只是为了让人们记得，我们总还有修正错误的机会"）
  - **丹燕案**：拒绝工部尚书把修缮驰道牺牲人数（三千余人）改为"百余人"（"三千变为一百，未免亵渎""让那些无法发声的人们，保住一些可被看到的文字"）
  - **与太师**：太师的学生（"他是你的老师，也是我的老师"——真龙语；"世事诡随，谨致良知"）；太师临终举荐颉入礼部
  - **与望（重磅）**：与望共同谋划除岁（"除岁一事，一直是我和他在谋划"）；**把书刀交给望**（500 年前——"她第一次对我提出可以付诸实践的，消灭岁的设想"——但望的记忆被岁兽本体干扰）；**120 年前入岁陵救望**（"她以自己的决意，换来了我们剩下的人的生机"——用书刀抹"岁"字/以己身代望——"唯有她自己动用权能，抹去那一个名字——"）；临终托付均（"这柄书刀……必须托付给一个绝对公正，绝不会偏私的人"）；"也许……我会和二哥一起回来？"（留给均的话）
  - **颉的梦**："我看到了你们每个人……都可以真正作为自己而活着""我不觉得，那只是一场梦……"（预见岁兽线结局）
  - **生机（伏笔）**：界园信物（伥物）=**颉残存生机**（望从岁兽残识中截取+注入兄弟姐妹记忆所造）；被重岳带入岁陵（"我也想带她见你一面"）；"颉还会回来吗？"（开放结局——生机安顿在天镜阁顶楼——椿/陈昭芊等待）
  - **与椿**：颉的秉烛人（衍兽精灵）——共事多年（"她的上一个秉烛人，被弹劾'与代理人关系密切'"）；临终问椿"家人去世的感受"（椿撒谎诱导——颉识破："你只是选择向我传递了大炎的一部分意志"——"对不起"）
- 经典台词："世事诡随，谨致良知。"（太师语）"历史从不是谁的一家之言，是万万人无声之言。""我留下这柄书刀，只是为了让人们记得，我们总还有修正错误的机会。""也许有朝一日，我们拥有的力量会超越祂……前提是，我们绝对不可以忘了自己是谁。"
- 信息来源：活动《相见欢》（全文）；《将进酒》《怀黍离》《春分》（提及）

> 待补充：颉是否归来的后续
