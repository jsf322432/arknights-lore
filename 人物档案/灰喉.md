# 灰喉（Greythroat）

- 阵营：罗德岛（狙击干员，**非感染者**）｜武器：弩
- 首次登场：第六章「局部坏死」（6-1）
- 关键信息：
  - 身世：父母是矿石病学者，为感染者研究矿石病，死于感染者与当局的冲突（阿米娅讲述）
  - 曾对感染者说"我不知道你们感染者有多痛苦"——被煌敌视；第六章与煌和解（"你做了对的事，这点变不了"）
  - 与浮士德（萨沙）短暂对峙：被其点破"没有自己方向的人只是机器"；战后回收浮士德的弩
  - 理性、服从命令、不擅表达；"我只是想确认自己该做什么"
  - 决战霜星时留下作战（"现在最强的，是我"）
  - **《沃伦姆德的薄暮》（前史，随安托赴莱塔尼亚）**：曾陪安托抵达沃伦姆德（"我该陪着她竭尽全力，抱歉，我没陪在她身边"）；带卡达/断崖驰援暴乱（"我见过你一面，罗德岛的干员"）；与泥岩对峙（"你是第一个这么称呼我的整合运动"）；"我只想少死一些人"；对感染者恐惧的挣扎（"我不掩饰，我依旧对感染者感到……恐惧"）
- 经典台词："我是不会伤害你的人。""我不会。""你经历的还不够多。"（转述浮士德）"只愿逝者安息。"
- 信息来源：第六章 6-1~6-15；活动《沃伦姆德的薄暮》
