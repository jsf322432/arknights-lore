# 大长老（蔓珠院）

- 身份：**蔓珠院之主**（谢拉格宗教领袖）；姓名被遗忘，只余"大长老"尊称
- 首次登场：活动《风雪过境》（act14side）
- 关键信息：
  - 主导圣女制度（"每一任圣女都在这座山上郁郁而终"）；调和三族/维护信仰秩序数十年
  - 信仰论：**"人们信仰的，是信仰本身"**；**"信仰是懒惰，是逃避，是颓废！信仰是安定，信仰是停滞！"**——表面虔信实则深知信仰被利用的本质（耶拉冈德化身雅儿在场）
  - 旧事：**"灵药"害死瓦莱丝之父**（当年喂药者为阿克托斯）——谢拉格旧权贵内部清算的遗留
  - 雪山事变前**昏迷**（被恩希欧迪斯布局/"下毒"指控事件）；事变后**病逝**——"他永远地停在了那里，一如他梦中的谢拉格雪山"（临别将谢拉格交予圣女恩雅）
- 经典台词："人们信仰的，是信仰本身。""信仰是懒惰，是逃避，是颓废！信仰是安定，信仰是停滞！"
- 信息来源：活动《风雪过境》（全文）
