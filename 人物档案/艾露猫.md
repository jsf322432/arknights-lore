# 艾露猫（Felyne / 学者猫·工匠猫·随从艾露猫）

- 阵营：独立（异世界来客）→罗德岛（"艾露猫特别行动小组"）｜种族：艾露猫（怪物猎人世界类猫种族）
- 首次登场：活动《眠于树影之中》（act24side）
- 关键信息：
  - **来历**：来自怪物猎人世界（"泰拉明明是完全不一样的世界，却和我们那里有太多相似之处"——生态规律一致）；因"奇怪的光/力量"与雄火龙一同穿越到泰拉；把泰拉当"没有调查团来过的新大陆"（学者猫想成为"泰拉首席学者"）。
  - **学者猫**（贝鲁纳村，原王立古生物书士队学者）：研究记录泰拉生态（"这里是第一期泰拉大陆调查团！我是团长学者猫喵！"）；观察"这片森林没有怪物……有什么消失了"（犰爪兽灭绝致生态失衡）；与黑角探讨源石（"主动接触源石那么危险的东西，怎么想也无法理解喵"——源石×怪物类比："源石和怪物都是无可避免的威胁，但也提供着生存下去的机遇"）；被黑角说服（"要有人站出来承担这个代价，指明前路"）。
  - **工匠猫**（波凯村）：制造装备（用火龙素材做防具/麒麟衍生武具——夜刀换装摘下面具）、自制**眩光手雷**（本地源石虫闪光替代闪光球——击败火龙的决胜道具）、异臭球（羽兽粪便）；贪吃/爱收集"新素材"（偷臭羽兽蛋惹祸）。
  - **随从艾露猫**（资深随从）：跟随"猎人"多年的老随从（可可特村回忆——"在'猎人'尚未出现的岁月里，正是村长首先挺身而出"）；传授夜刀双剑"**鬼人化**"（"进入如凶兽一般，舍弃防守的状态"）、黑角太刀"**气刃兜割**"/居合、绳索束缚术（"在东方村落学会的"）；观察火龙异常（源石影响）；主张"狩猎需深思熟虑"（"拥有强大武力的'猎人'通常是平衡生态的关键存在"）；结局主张由泰拉人自己决定火龙命运。
  - **结局**：加入罗德岛——正式编制"**艾露猫特别行动小组**"（组长=随从艾露猫；学者猫坚持自封"泰拉大陆调查团"团长）；负责对付特殊生物/记录泰拉生态/寻找回家的办法。
- 经典台词："这里也是新大陆喵！""主动接触源石那么危险的东西，怎么想也无法理解喵！""要有人站出来承担这个代价，指明前路。"（黑角）"（狩猎是）古老的传统……据说在某些东方村落也会训练牙猎犬参与狩猎。"（随从艾露猫）
