# 杜玛（Duma）

- 阵营：曼斯菲尔德监狱（入殓师）→ 随队越狱｜种族：未明｜身份：医务室医生兼入殓师
- 首次登场：活动《孤岛风云》（act15d0，2021）
- 形象：气质诡异（"给人的感觉比较诡异，别说狱警，我们没事都不太愿意靠近"）；救过许多人；会源石法术（"需要我用法术舒缓一下你的精神吗"）
- 关键信息：
  - **身世**：被上一代入殓师在监狱停靠时捡来的孤儿，从有记忆起就在监狱长大（"狱警们的刻薄，囚犯们之间的仇恨、恶意、暴力，还有死亡。除此之外，我再也没见过别的东西"）；"我也偶尔会在停靠的时候出去走走，但是我能感觉到，我并不属于那里。我……害怕"
  - **与安东尼**："安东尼是我唯一的朋友"；帮安东尼越狱但本不打算离开（"只要能帮助他出去，我就心满意足了……我已经做好准备了，一旦哪个环节出了差错，我赌上性命也要把这个错补上"）；被罗宾劝动（"像你这样善良的人才是最不应该生活在这样的监狱里的"）
  - **《孤岛风云》**：提供废弃结构/通往监狱外的地道信息（靠近停尸间）；为安东尼缝制越狱服装；被杰斯顿挟持（试图自杀未遂）；结局随队离开
- 经典台词："直到安东尼来到这里，我才知道，这片大地上还有他这样的人。"
- 信息来源：活动《孤岛风云》全文 18 段
