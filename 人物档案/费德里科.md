# 费德里科（Federico / "送葬人"）

- 身份：**拉特兰公证所执行者**（"送葬人"）；**圣徒**（拉特兰建城千年以来历任教宗外的首位受选者）；阿尔图罗的远亲；后续罗德岛干员
- 首次登场：活动《吾导先路》（act16side）；活动《空想花庭》（act26side，圣徒首秀）
- 关键信息：
  - 公证所执行者（冷漠/律法至上——"缉捕对象的情绪与我无关"）；共感能力缺陷（无法感知他人情绪——"你和我一样，我们都多少拒绝了共感"）
  - 《吾导先路》：发现费莉亚（塞茜莉亚之母）遗体；追查其行踪记录→**奥伦**（"你与这件事有关"）；缉捕奥伦（"第七厅已解除你的万国信使职位。请放弃抵抗"）
  - 追查目的：**阿尔图罗**（远亲/通缉犯——"比安多恩名气还要大得多的通缉犯"）；奥伦提供线索（三年前在莱塔尼亚见过她）
  - 《空想花庭》（圣徒首个年头）：教宗册封其为**圣徒**（"执行者的第六年，圣徒的第一个年头"；"没有人能给他启发或指点"）；率队赴安布罗修修道院寻失联的蕾缪安/奥伦（"我接到的任务是寻找失联的枢机辅佐官蕾缪安与万国信使奥伦"）
  - 修道院事件：鸣铳示警维持秩序（"那么我来维持秩序"——令奥伦约束特勤队后退一公里）；锁定**克莱芒**为"系列异常事件主导者"、击毁其点火器但拒杀（"你的行为并未直接导致任何拉特兰公民的死亡"）；保管杰拉尔德佩刀（拒绝承认萨卡兹"名号传承"，仅以"猎户杰拉尔德的匕首"名义）
  - 与阿尔图罗对峙：多年未见的"姐姐"（"叫我一声姐姐？"）；放走被莱塔尼亚选帝侯使者接走的阿尔图罗（"你现在不能直接对阿尔图罗动手，这可能会影响拉特兰和莱塔尼亚之间的关系"——奥伦）；"我拒绝你的提议"
  - 向教宗汇报：坦承"任务未完成"（人员伤亡三名）并提问——"如果不存在错误的环节，那么为何无法得出最优的结局？我们的条律是否能够适用于所有情况？"（教宗："我无法回答你"）
  - 《崔林特尔梅之金》（圣徒第二年）：入境莱塔尼亚追捕阿尔图罗（给宪兵队长官洛里斯寄 27 封合作信）；与赫琳玛特密使米夏埃尔合作；受洛里斯遗嘱之托查尤利娅失踪案（"完成洛里斯·博尔丁的嘱托会成为我的下一个任务目标"）
  - 路德维格大学/女皇塔：击碎雕塑/敲晕受幻觉者一路突进（"情感是信息"——从阿尔图罗的演奏逻辑推断其目的未达成）；"杀死洛里斯·博尔丁并非阿尔图罗的意图"（"像那座雕塑一样对生命毫不尊重的作品，在她眼中，'丑陋到难以忍受'"）
  - **荒域**：找到尤利娅·许勒尔的意识体；见证其第二次死亡——"这是第一次，他真正触摸一个人在最后时刻的情感"（"她永远生活在自己的'崔林特尔梅'……如此简单。如此强烈。"）；"我仍未弄清此时此地的真相。这里没有律法，没有坚实的土地，唯有无穷无尽的危险与未知"
  - **协助阿尔图罗**（演奏自己联结众人）："行动评估：阿尔图罗，你的行动有利于稳定局面。执行者费德里科·吉亚洛将协助你。你停下演奏前，不会有任何人干扰到你。"
  - 结局：按双边协议**带走阿尔图罗**（"我承认条律有其空白，情感或许可以作为补足的力量，帮助拉特兰应对危机。但这无从界定，必然伴随着未知的风险""如果发现任何可疑的地方，我会击毙你"）；"拉特兰城入夜后，启示石塔右侧的街道会首先亮灯"（童年约定之答——"依然好看"）
  - 《众生行迹》（圣徒第三年）：察觉拉特兰"梦境"异样（告解车数据/铳械管控/兰登修道院职能/里凯莱的异常支援——"我再无疑惑"）；与越狱的阿尔图罗合作；允许离群萨科塔入城（"我来，并不是为了重申拉特兰曾对各位下达的判决"）
  - 深入大教堂地下（圣徒行记机关/迷宫）与安多恩觐见律法（PCS 机器）；**以律法的语言与 PCS 对话**——指出悖论（"天使无始无终，何以如此强烈地想要存在？……愿望与天使，本就相悖"）；"律法本身即是悖论，祂无法被执行，也不该被执行"；**与安多恩炸毁 PCS（弑神）**（"指令合理，存在可执行性"）
  - 与 PCS 对话的核心结论："生命的存在即是奇迹……秩序，是为了维护生而为人——珍贵的脆弱"
  - 与奥伦（"虽然我不反对这个观点。或许等你的审判结束后，我可以到监狱里和你交流"）
- 经典台词："缉捕对象的情绪与我无关。""花还在。却不是想要的那一朵？""不伴随行动的言语毫无力量。""理解与否，并不影响律法的执行。但我是为了克莱芒得到应有的处置而前往圣堂。他罪不至死。"
