# 佩佩 / 珠娜佩卡佩-萨琪特-哈特谢普苏特（Pepe / Junapecape-Sachit-Hatshepsut）

- 阵营：萨尔贡（帕夏之女/史官家族传人）｜种族：（萨尔贡人）｜身份：考古工作者/探险家；梦想成为黄金之城的史官
- 首次登场：活动《太阳甩在身后》（act35side）
- 关键信息：
  - **史官家族传人**：全名珠娜佩卡佩-萨琪特-哈特谢普苏特（"辉煌的史官家族传人、王者与英雄的传颂者、足迹遍布萨尔贡的探险家、博闻之人、尊贵的帕夏之女"）；家族世代传袭史官职位（"真正贯穿我们家族每一代的荣耀"）；弟弟被选定为史官继承人（提前入黄金之城——"他只是不想我一个人留在那里"——姐弟互护——"我也不想他一个人留在那里"）。
  - **梦想**：成为黄金之城的史官（"我想要参与记述萨尔贡的历史！我想要沙阿的荣光在我的笔下焕发出永恒的生命力""在千年万年后，有一个我注定无缘得见的家伙，他会从那些文字中，与我，与沙阿产生共鸣"）；为证明自己寻找沙阿宝库（"只有找到沙阿的宝库才能向父亲和陛下证明自己的能力"）。
  - **《太阳甩在身后》**：深夜潜入博物馆研究"无名将领"（祖拜尔）——将宝石放入其胸腔使其苏醒；带祖拜尔寻找五颗宝石（丰获集会黄金拖鞋/米奥吐宝石等）；**通过米奥的考验**（进入祖拜尔的记忆幻境——见证祖拜尔的童年/姐姐/沙阿与哈兰杜汗/父亲失踪——"如果不该遗忘，那就记住，即便会带来痛苦"）；祖拜尔带她进入沙阿宝库（米纳特哈玛仪地下）；关于祖拜尔的论文吸引学界关注；**黄金之城使者到来——陛下亲授旨意：请哈特谢普苏特亲临黄金之城**（开放结局）。
  - **性格**：执拗/活泼（"你从来都是不到头不死心"）；爱考古（"我今年参与了两座古历纪时期坟墓的考古工作"）；用黄金拖鞋参加丰获集会（"拿个第二才是令人苦恼的地方"）；"我们干过考古的体力也很不一般"。
- 经典台词："我想要参与记述萨尔贡的历史！""如果不该遗忘，那就记住，即便会带来痛苦。""我只是不想他一个人留在那里。"
- 信息来源：活动《太阳甩在身后》（全文）
