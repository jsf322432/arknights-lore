# 卢奇诺·德蒙塔诺（Luchino Demontano）

- 阵营：独立（德蒙塔诺裁缝店学徒）｜种族：（鲁珀/叙拉古）｜身份：小裁缝；翁贝托之孙
- 首次登场：活动《新沃尔西尼狂欢节》（act38side）
- 关键信息：
  - **身世**：父亲卢卡·德蒙塔诺（歌舞剧女演员之恋，尸体在出城载具上被发现）；卢奇诺幼年被寄养在郊野农庄，三/四岁时被爷爷翁贝托接回德蒙塔诺（"老人牵着自己离开了农庄，路不知道通向哪里……'爷爷给你讲个童话故事吧……每一位猎人进入荒野前都会遇见狼'"）。
  - **性格**：聪明、爱观察（"那些来试衣的客人，哪个其实是政府的高官，哪个在为家族做事"）；向往"大人物"（偷偷仿制萨卢佐家徽纽扣——"如果能认识萨卢佐家族的家主，对德蒙塔诺来说不是坏事"）；被爷爷严厉管教（"在你缝的扣子够多之前"）。
  - **《新沃尔西尼狂欢节》**：为拉普兰德送萨卢佐礼服（两套"德蒙塔诺出品"——拉普兰德给阿尔贝托的道别礼）；目睹车祸（莱昂图索被撞）被卡彭/甘比诺绑架（"把他带回去，说我们把现场唯一的目击者控制住了"）；被老威尼斯放走；得知爷爷的过去（"剪裁师"）与父亲之死真相（"他们谈论的的确是自己的爷爷，可他怎么都和眼前的老人对不上号"）。
  - **成长**：混上威尼斯陆行舰，用缝纫线串联源石炸药企图引爆军火（"别小瞧一个裁缝！你永远不知道他们能用针和线做到多少事！"）；被瓦古阻止（"幼崽，无论你想成为何种人物，在做那些事之前，先缝好自己的扣子"）；甘比诺放他（"小子，说真的，我有点喜欢你了"）；最终被瓦古扔下陆行舰（"自己还是太年轻了，卢奇诺这样想"）。
  - **结局**：与爷爷和解（"爷爷，您能再教我缝一遍扣子吗？"）；翁贝托死前把最后一套西装的收尾留给他（"卢奇诺，收尾的工作就交给你了"）。
- 经典台词："你们根本不算什么大人物，爷爷他瞧不上你们！""我自己惹了麻烦，我自己解决，不需要谁知道。""或许到头来我还是只能当一个裁缝，但起码现在我不这样想！"
- 信息来源：活动《新沃尔西尼狂欢节》（全文）
- 后续：德蒙塔诺的继承人（"将是一位好裁缝"）；翁贝托死后继承店铺
