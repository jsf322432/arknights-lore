# 洛里斯·博尔丁（Loris Bouldin / 宪兵队长官）

- 身份：前拉特兰公民（黎博利）→崔林特尔梅**宪兵队长官**（子爵）；"第一个踏进巫王塔的士兵"；尤利娅案的执念者
- 首次登场：活动《崔林特尔梅之金》（act29side）
- 关键信息：
  - 生平：28 年前从拉特兰来莱塔尼亚当宪兵（年轻时因踩到巫王画像入狱，被一瘸一拐的老黎博利宪兵救下——老人在密林公园被处决）；**23 年前第一个冲进巫王塔**（"第一个踏进巫王塔的士兵"——双子女皇授子爵爵位，统领宪兵队）
  - 自我放逐：因尤利娅失踪案（抓不到贵族嫌疑人）而"酗酒，收受贿赂，对地位更高的贵族点头哈腰"（"我恨崔林特尔梅，我恨自己没办法……"）；15 年来卷宗一直在变厚（"他从未放弃调查真相，也从未放弃寻找你的下落"）
  - 《崔林特尔梅之金》：处理《巫王之死》画作案（掩盖希曼夫人之死真相）；限制费德里科行动（"您在崔林特尔梅行动期间，最好不要离开我的视线"）；与费德里科关于"律法是否总是正确"的对话（"当您不得不像我这样怀疑自己……您就会发现，律法指引不了您"）
  - **结局：为救黑键独自断后战死**（"快走，我的人已经在路上了"——"他当然可以留在原地……只是转身离开而已"）；遗体被残党铸成旋角雕塑；遗愿（电话）："尤利娅的案子，希望有人能接手""钥匙在博登区的房子里"（遗留给扬上大学/交给费德里科）；**遗言**："我还算不算，英雄？"
- 经典台词："律法何曾在乎过一个人的得失生死？！""我终究……做不到像你一样，死得像个英雄。可我为什么……这么失望？""你是前拉特兰法定公民，该请求应视为你的遗嘱。"（费德里科）
- 信息来源：活动《崔林特尔梅之金》（全文）
