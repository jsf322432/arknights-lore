# 重岳 / "宗师"（Chongyue / "Zongshi"）

- 身份：玉门守护百年的"宗师"；**岁兽"朔"的碎片化身**（岁兽十二分之一意识）；炎国岁兽线核心角色
- 首次登场：活动《登临意》（act23side）；此前被提及（《将进酒》等炎国活动）
- 关键信息：
  - **岁兽"朔"的碎片**："朔这个名字，还有那缕残魂，都一并封印在了那把剑里。现在的我，不过是一个稍擅拳脚的凡夫俗子罢了"——放弃巨兽之力/以人类身份守护玉门百年（"我是我，祂是祂"）
  - **守玉门百年**：玉门以军事建城/北境要塞；宗师与守军并肩（"他守护玉门安危百年"）；与左宣辽共事几十载（"我和他，本来有一群共同的朋友"）；声望卓著（"天下的武功，有近半数是他发明的"传说）
  - **佩剑"朔"**：封印岁兽十二分之一意识（"藏有岁兽十二分之一意识的物件"）；太傅："宗师的剑，封印着岁兽本体十二分之一的意识"——需托付合适之人（比武第一+品行考验）
  - **《登临意》**：离任前遭遇睚（巨兽）——与其在时间停滞的空间对决（"春生夏荣秋伤冬藏，裁错春秋，剪宇怀腹"——点破睚的剪裁空间能力）；**一拳击倒睚**（"万法归一，武道至简"）；将佩剑托付槐天裴（"你是从古至今，唯一一个赢了我一拳的人"）；与太傅/魏彦吾/令告别；离开玉门（"一百余年，该去别的地方了"）
  - **与故人（截云的师父）**：曾救下并教武的阿纳萨一族（额间玉石/教武功/安家）；为其寻医未果（"寻隐不遇。我还要再找的时候，收到了玉门发来的急报"）；故人病逝荒野（"想来她在生命的最后，也没有太过寂寥"）
  - 与弟弟（"罪人"/岁兽碎片）："棋局无趣，要分胜负的，是我与我"（弟弟语）；"你一定会阻止我，前提是，你能看见全局"（弟弟语）；"我们还会再见的。保重，兄长"
  - 指点左乐："莫在行事时，忘了最初的情和理""身在局中，手握决断权柄，亦是手握杀伐重器"
- 经典台词："重岳，是我的名字。""我是我，祂是祂。""黄沙远来三千地，洗罢流年一屈指。""人活着，总不能指望处处都被体谅理解。"
- 信息来源：活动《登临意》（全文）；活动《相见欢》（全文）；活动《春分》（提及）

## 活动《相见欢》补全（岁兽线终局，重大进展）

- **与望的过往（回忆）**：大狩猎"最后的遗害"——朔/望参与诛杀矩兽（朔以一当千/望算无遗策）；望**私自放走矩兽**（"留一手伏兵，好过毫无底牌"）；**朔把"自己"封在剑里**（"你把'自己'封在了那柄剑里……司岁台把剑还你了吗？"——望语）；朔 vs 望的理念冲突（"堂堂正正的本手，也好过激进的无理手" vs "我们没有更多时间了"）；令的调解（"我在路上浅醉片刻，你们就能闹出事来"）
- **与左宣辽（玉门旧事）**：朔=玉门武学教习（"在下的职责是在军中一应事务上协助将军"）；与左宣辽讨伐北祟邪魔（"假我二十年，以此剑为界，我必然平定所有作乱祟物！"——左宣辽）；重岳离任（"我在玉门的任期以百年为限……恐怕离祂苏醒的时日又近了些"——衔接登临意）
- **救望（重磅）**：重岳被拦在百灶城外（"陛下有令……先生暂时不可进城"——朝廷不让朔进城）；**以武撕裂梦境救望**（"一记重击……祂意识到自己，在这一瞬间失去了与那庞大躯体的连接"——重岳击碎岁兽本体的梦境边界）；**带颉的生机（信物/伥物）入岁陵**（"我也想带她见你一面，让你知道，你这些年的筹谋……毕竟没有白费"——"他拼命将这缕生机带到人间，我又怎么可能逆他的意思，将其消耗呢。不过是让他安心罢了"）；"活下去……活着回来"
- **结局（寻找望）**：矩/后（巨兽）告知望"天人路隔"（"他这一局，算尽了自己……如此勉强用事，必遭其反"）；重岳："我相信，在那座陵墓之外，他的痕迹，必定还留存在什么地方""在下一次，他需要帮助的时候，不会是孤身一人"（**重岳踏上寻找望的旅程**）；路过村落棋摊（少年赌棋——望的痕迹伏笔）
- **家宴**：岁兽碎片团圆饭（重岳出席——"出来时神色不祥"——望缺席）
