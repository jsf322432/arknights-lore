# 杜宾（Dobermann）

- 阵营：罗德岛
- 身份：行动组 E1 组长（教官）；感染者；**前玻利瓦尔军队上校**
- 首次登场：序章「黑暗时代·上」（序章·下）；活动《丛林症结》（act21mini）补全过去
- 性格：严苛、务实、毒舌，老兵作风；对感染者处境有切身体会
- 关键信息：
  - 讲述乌萨斯对感染者的宣传与迫害机制（恐惧化→抓捕时民众拍手称快）；"以前经历的战争中"有暴君式领袖（暴君论）——战争经历含乌萨斯见闻
  - 对失忆的博士先存疑，后认可其能力："是该客观评价你的能力了"
  - 与阿米娅私下确认"三小时后天灾吞没切城"的倒计时
  - **玻利瓦尔过去（重磅，活动《丛林症结》）**：前"真正玻利瓦尔人"军队上校——"您在玻利瓦尔的军队中有些麻烦的过去"（米格鲁语）；**和平协议时期以匕首刺杀汉科将军**（"这是我自己的选择……仅仅是我，一个在泥地里翻滚……将我的亲人、友人，一个接一个埋入地底的玻利瓦尔士兵的愤怒"）；拒绝签署含"士兵回种植园"条款的协议；**离开玻利瓦尔加入罗德岛**
  - **拒绝精英干员邀请之谜**："您为罗德岛战斗了这么长时间，为什么会拒绝成为精英干员的邀请？"（米格鲁问——杜宾未答；或与玻利瓦尔的过去有关）
  - **米格鲁之死**：劝阻米格鲁参加玻利瓦尔救援（"我见过太多的理想被现实和利益浇灭，单纯的善意被仇恨裹挟、毁灭"）；"等你回来以后，我会很荣幸出席你的精英干员晋升仪式的"——米格鲁牺牲于特科马（伏笔）
- 经典台词："这样的人，是暴君。""把仇恨和恐慌当做口粮，喂养他们……"／"我见过太多的理想被现实和利益浇灭，单纯的善意被仇恨裹挟、毁灭。"
- 信息来源：序章 0 下、0-1~0-11；活动《丛林症结》st04/st06

- **玻利瓦尔三股势力（早期设定，2020）**：①名义官方=**莱塔尼亚掌控的傀儡政府**（主导的对抗哥伦比亚战争取得胜利）；②**议会分化出来的自治政府**（资金来源充足，可与傀儡政府叫板）；③**玻利瓦尔反抗军**（苦于两拨实力斗争而揭竿起义的普通民众）；**杜宾=自治政府上校**→辗转加入反抗军→离开（"我发现，那里也是一样的"）→加入罗德岛（早期设定；与《丛林症结》的"真正玻利瓦尔人/联合政府/汉科将军"设定并存演化）
