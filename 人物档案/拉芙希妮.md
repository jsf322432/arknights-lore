# 拉芙希妮（Loughshinny / 深池"领袖"）

- 阵营：深池（名义领袖）｜种族：德拉克（红龙，火系术师）
- 首次登场：第九章「风暴瞭望」（重伤现身）
- 关键信息：
  - 深池的"领袖"——被推到台前的**影子**（Outcast："你是被推到台前来的影子。那个提线的人，拥有和你一模一样的血脉"——其姐姐为幕后主导）
  - 在脏弹轰炸中受重伤（腹部被活性源石贯穿）——**Outcast 违背命令将其救下**（"一个感染者之后会因权力斗争而死"）
  - 对矿石病感到释然（"渴望挣脱原本的命运"）；昏迷前警告 Outcast 有危险
  - 被风笛/简妮护送，随罗德岛撤离小丘郡
- 经典台词：（昏迷中）"危……险……""我只是，人们理想中'领袖'的影子。""这终于是我自己的火焰了。"
- 信息来源：第九章 9-11~9-16；活动《照我以火》（全文）
