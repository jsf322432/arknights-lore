# 车尔尼（Czerny / 感染者音乐家）

- 身份：莱塔尼亚唯一享誉全国的**感染者音乐家**（钢琴家）；夕照区出身；《晨暮》与《光影》的作者；罗德岛干员（结局申请赴前线）
- 首次登场：活动《尘影余音》（act18side）
- 关键信息：
  - 生平：夕照区（感染者聚居区）出身；匿名发表曲子（感染者身份受歧视）→格特鲁德当赞助人后《晨暮》署真名传出夕照区；曾与格特鲁德"大吵一架"（理念分歧——她视音乐为工具）
  - 《晨暮》：为**知己之死**所作（"你应该用'悲愤'来形容。那是我第一次理解到音乐对我的意义——反抗既定的命运"）
  - 性格：毒舌/直率（对黑键"被捧习惯了"的批评）；坚持"音乐家最重要的是真诚"（"就算是刻骨的憎恨，能用合适的技法表达出来，一样有其意义"）；对夕照区有执念（"正因为天要黑了，夕照才更显可贵"）
  - 告别音乐会：为收治中毒感染者**以全部版权抵押**换取医院合同（"现在我可以从零开始了"）；拒绝取消音乐会（"我不能仅仅因为虚无缥缈的'担忧'，就让整个夕照区的努力和希望付诸东流"）
  - 《尘影余音》：解读计划书（无"转移"尘世之音之法）；彻夜为黑键与白垩创作《**降b小调长笛-大提琴-钢琴三重奏"光影"**》（"我要你们在乐曲中挖掘自我……然后，由我来为你们作一首新曲子"）；黎明前呕血倒下（"今天，就是车尔尼的死期！但车尔尼的音乐永远不会死去！"）
  - 结局：申请赴罗德岛前线（"我不奢求在战场上找到将其表达出来的方法，但我想，用一种完全不同的方式为感染者奋斗"）；对黑键："他活得好好的，给他一些时间吧"
- 经典台词："反抗既定的命运。""音乐是你生活的写照，是你的步伐，是你窥探大地的双眼！""不要被你的情绪蒙蔽，但也不要背叛你的情绪。"
- 信息来源：活动《尘影余音》（全文）
