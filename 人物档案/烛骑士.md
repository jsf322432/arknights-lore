# 烛骑士·薇薇安娜·德罗斯特（Viviana Droste / "微光"薇薇安娜 / 本名薇薇安娜·霍赫贝格）

- 身份：卡西米尔大骑士"**烛骑士**"；施彤领选帝侯**沃尔纳·冯·霍赫贝格之女**（私生女）；**女皇之声**（后辞职）；散华骑士团所属；伊奥莱塔·罗素的养女
- 首次登场：活动《长夜临光》（act13side）；活动《崔林特尔梅之金》（act29side，莱塔尼亚线核心）
- 关键信息：
  - 出身：莱塔尼亚大贵族私生女（"在那座塔楼之上，我甚至都听不见地面闹市区的鼎沸人声……母亲会偷偷为我带来一些蜡烛"）；借烛光阅读骑士小说长大（《最后的骑士》——"无名的骑士……坐骑罗辛南特"）；因出身被"驱逐"到卡西米尔，为生存成为骑士
  - 法术：**影之法术**（"烛与影"——当房间里点燃一支蜡烛时，真正将你包裹的是周遭器物的影子；"片刻的黑暗也能侵吞我的法术"）
  - 《长夜临光》：与耀骑士堂堂正正对决（拒绝联合会安排）；救索娜、引荐罗素；随散华骑士团赴奥格尼斯科（"也许是为了写首诗吧"）
  - 《崔林特尔梅之金》：父亲沃尔纳遇刺→被珂拉救下护送入崔林特尔梅；伊维格娜德任命其为**女皇之声**（沃尔纳遗愿）；查父死因（金律乐章副本/残党）；与布兰特搭档
  - 身份揭示：母亲露辛达·德罗斯特（平民诗人，金盏花小巷与沃尔纳相爱）；父亲"十分钟的错过"（"金盏花，和月亮……本就没有关联。这只是一个梦"）
  - **杀死珂拉**："您知道，我最不能赞同您的……是什么吗？您是真的……狠心。"（珂拉："我很高兴，最后杀死我的，是我最爱的人"）
  - **荒域**：走过一百多扇"可能之门"（不同命运：父亲带母亲回施彤领受祝福的"薇薇安"/父亲隐姓埋名做普通人的世界）；握住**印有临光家徽记的骑士剑枪投影**战胜混沌（"薇薇安娜·德罗斯特，别忘记，你是一名骑士！"）；感知混沌中的"邪魔"（"敌人正在向我们飞快地行进。它们即将侵入我们所知的一切"）
  - 结局：**拒绝女皇之声职务**（"我从来都，有能力做选择"）；回卡西米尔（荒域见闻写信告知临光家——玛恩纳亲自来接："我需要知道，全部"）；"向灯塔去。也向灯塔消失的地方去。"
- 经典台词："我只是一直想在这个时代见证一下骑士的光彩。真正的光彩。""可为什么，每一次都……让人如此失望。""薇薇安娜·德罗斯特，别忘记，你是一名骑士！"
- 信息来源：活动《长夜临光》（全文）；活动《崔林特尔梅之金》（全文）
