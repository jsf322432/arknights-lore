# 奥罗拉（Aurora / 前铳骑·堕天使）

- 身份：前铳骑第三小队队长（被驱逐的堕天使）；阿摩斯之妻；玻利瓦尔修道院十年的守护者
- 首次登场：活动《众生行迹》（act42side）
- 关键信息：
  - 罪案（1090 年）：率队护送商队遭萨卡兹佣兵暴动，当场格杀被押解的佣兵；为掩盖罪责举铳威胁同僚，杀害同僚后被剥夺公民身份/永久驱逐（费德里科："混乱中你杀害了同僚"）
  - 玻利瓦尔十年：保护努艾达的修道院/孩子们（"是你拿起了铳，我才能教会他们唱诗"——努艾达）；堕天后无法使用守护铳，淘来黑钢铳械
  - 与帕特里奇昂：师徒之怨（"我永远记得你对我做过什么。在那间移动修道院，你亲手将我打伤，亲口宣读教皇厅对我的驱逐令"；拒绝出席她与阿摩斯的婚礼）；回拉特兰"趁乱报复"（狙击帕特里奇昂）
  - 信仰的自白："因为憎恶，在玻利瓦尔的这十年，我从未有一刻忘记过它！……这即是我与拉特兰的连接，这即是我的信仰！""你的学生就是这样残忍、凶恶、自私……哪怕没有堕天，她也算不上什么'天使'！"
  - 结局：教皇厅提供雇佣合同（蕾缪安：去做一些你刚刚做过的事情）；"对拉特兰，我们都有自己的执念"
  - 与阿摩斯：分居/大吵（"我只是想着能见她一面，为当年吵的架道个歉什么的"——阿摩斯）；阿摩斯死于灾异（"没能成为彼此的救赎"）
- 经典台词："因为憎恶，在玻利瓦尔的这十年，我从未有一刻忘记过它！""这即是我与拉特兰的连接，这即是我的信仰！""我难得觉得堕天是这么幸运的事。"
- 信息来源：活动《众生行迹》（全文）
