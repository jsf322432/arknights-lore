# 菲亚梅塔（Fiammetta / "微光守夜人"/"黎明破坏者"）

- 身份：**公证所执行者**（黎博利）；莫斯提马的"护卫"/监视者；前戍卫队四人小队成员；后续罗德岛干员
- 首次登场：活动《吾导先路》（act16side）
- 关键信息：
  - 四人小队（安多恩/莫斯提马/蕾缪安/菲亚梅塔）：八年前接临时支援离开4小时——"回到那个废墟的时候，什么都迟了"（安多恩夺锁与匙/莫斯提马堕天/蕾缪安重伤）
  - 对安多恩的执念："蕾缪安原谅你，莫斯提马原谅你，伊万杰利斯塔十一世原谅你，就算整个拉特兰都原谅你——我也绝不原谅"
  - 追查塞茜莉亚事件（与帕蒂亚/奥伦周旋）；与莫斯提马的搭档（"你还要选，对吗，关于你到底是谁"）
  - 结局：加入罗德岛挂靠（代号"黎明破坏者"）；持有安多恩的铳（"如果他真的还认为自己是一个萨科塔，他会来取回这把铳的"）
- 经典台词："我绝不原谅。""我对于成为一个高尚的人没有兴趣。""要找你算账，是因为我就是要找你算账！""你，我，每个人，谁不是为了执念站在这里？"
