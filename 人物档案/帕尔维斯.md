# 帕尔维斯（Parvis）

- 阵营：前莱茵生命（创始人之一）｜种族：？（"老山羊"——斐尔迪南称其"奸诈的老山羊"）｜身份：生物学家（赫默的老师）
- 首次登场：活动《孤星》（act25side）
- 关键信息：
  - **莱茵创始五人之一**；赫默的老师（"你一直是我最好的学生"）；年轻时在莱塔尼亚仰望天空见巫王高塔剪影（"假如巫王是被命运选中的唯一奇迹，那我们其他人的生命都有什么意义呢？"）
  - **嵌合实验（数十年）**：以生物工程创造强大造物；萨卡兹古籍"死魂灵"研究（"灵魂层面上的嵌合""人造意识"）；斐尔迪南×多萝西的**递质**被他视作"人造意识诞生的土壤"（"递质的性质……足够成为人造意识诞生的土壤"）
  - **神经退行恐惧**（"我最近总是在背中枢神经系统的基本结构……没有完整背出来过一次""我的神经在退行……也许只要五年，或者三年，我就会变成一个只会晒太阳的痴呆老人"）
  - **哲学**："科学属于超人""庸众可以去选择政客，庸众可以去崇拜领袖……但唯有科学，他们不配染指""假如巫王是被命运选中的唯一奇迹……她（克丽斯腾）具有创造奇迹的可能性"
  - **结局**：在万星园将**自己的灵魂投入能量束**（"超越者踏上她的旅程，我想……她不在意，自己的长路跟上了个……胆小的搭车客""至少，这比成为一个昏聩的痴呆老人……要好得多"）；**身体成空壳**（赫默："帕尔维斯的身体已经成了一具空壳，再没有任何一点意志存于其间"）
- 经典台词："平庸、无聊、保守、瞻前顾后……我们这些拥有知识、拥有能力的人，所要做的从来不只是'探索'或'进步'。我们背负科学，我们被它命令，供它驱策。""我所有的努力，我所有的追索……必须有意义。"
- 信息来源：活动《孤星》（全文）
