# 火神（Vulcan）

- 阵营：罗德岛干员｜种族：米诺斯人｜身份：铁匠/锻造师（"罗德岛的铁匠，代号火神"）
- 首次登场：活动《干员秘录合集（三）》（act7d5，2020；st03/st04）
- 形象：寡言沉稳（"只是个普通铁匠"）；对武器看得很准（"对于武器，我不会看走眼"）；外冷内热（"饼自己收好，想吃的时候就吃""在罗德岛没有坏人"）
- 关键信息：
  - **米诺斯铁匠（重磅）**：米诺斯人（"火神，是米诺斯人？"——刻俄柏问）；罗德岛锻造师（维护干员武器/修理盾牌等）；米诺斯工艺的辨识者（"米诺斯工艺，真令人怀念"）；**"米诺斯不是东国，没有动不动就把名号刻在武器上的传统。能够留下的，大多意义非凡"**
  - **与刻俄柏（重磅）**：受托照料流浪佩洛（芙蓉/炎熔托付）；读出斧头古米诺斯语名字"**刻俄柏**"；取名"小刻"（"我叫你小刻吧"——"算是糊弄过去了"）；让她自己判断是否加入罗德岛（"火神大姐说的，是去当英雄吗？"——"是，就是当英雄"）；**担保人**（"需要担保人的话，就填我的名字"）；人事专员追问理由——"喜欢武器的都不是坏人"
  - **谜团（重磅伏笔）**：刻俄柏的斧——"我锻不出来。但那种锻法，我一定在哪里见过……"（亲切感）；"我想帮助她解开谜团。这样，说不定有一天，她也能回过头来为我解惑。说到底，只是一个铁匠的私心罢了"
  - **评蜜饼**：炎熔烤的蜜饼——"皮不够脆，蜜糖调味有些问题。除此之外，和米诺斯的味道一模一样"（米诺斯风味）
  - 与角峰：同楼邻居（"以后有机会，我可以请隔壁的角峰做给你吃。他做这种食物很有心得"）；看破角峰心情变好（"你照照镜子再这么说"）
- 经典台词："喜欢武器的都不是坏人。"／"我是一个铁匠，不怎么会看人。但对于武器，我不会看走眼。"／"在罗德岛没有坏人。"
- 信息来源：活动《干员秘录合集（三）》st03/st04

## 干员密录补全（story_firwhl_1_1：阿格妮）

- **身世（重磅）**：阿格妮——**雷姆必拓矿主之女**（大学生——玩火源石技艺——"从小到大的玩火经验"）；父亲=矿业公司老板（"你晚一年毕业，我就得晚一年把矿上的担子交到你手里"）
- **建学校（重磅）**：与同学为穷村建学校（香槟庆祝——瓶塞卡门框）；村长冷淡（"村里根本不需要学校"——**矿业公司毁了啤酒花种植/建立供应链替代村庄经济**——"他们想让我们失去土地，去采矿平台，去过朝不保夕的生活"）；**学校被采矿平台震塌**；阿格妮留下当老师（一个月教孩子认字/加减乘除）
- **父亲的约定（重磅）**：父亲雇老师换阿格妮回去（"用我关心的人做筹码"）；村长拒绝（"矿老板资助的学校""你不觉得你在和你父亲做一样的事吗"）
- **结局（重磅）**：拒绝继承产业（"雷姆必拓永远不缺体面的好人。爸，我怕，我真的怕体面人当得太久，我会看不见身边发生的事情，比如……一座学校的倒塌""所以我不会继承你的产业……爸爸"）
- 信息来源（补）：干员密录（obt/memory/story_firwhl_1_1）

## 干员密录补全（story_hpsts_1_1：修复角峰的盾）

- **修复角峰的盾（重磅）**：角峰（谢拉格银灰家守卫——盾=父亲/祖父传承（"承载了我们出战即为死者的誓言"——银灰老爷家的工匠打造——代表使命：保护二小姐）；火神坚持修复（"以一个朋友的身份……希望你同意我，继续修复这面旧盾"——**根的哲学（重磅）**："我知道我自己是个铁匠，这是我的根""不论你在罗德岛待得如何适应，你的根也会一直在谢拉格的雪山上"）
- **寻找新材料**：源石虫矿物结晶（井深三百米——迷药陷阱——"只是取走一点点你们身上的结晶"）；新锻造方法（夹钢——精钢夹柔韧材料）；杜宾测试（"真是一面好盾！"）
- **结局**：修复完成（"强度也不比原来的差……在背面增加了源石回路"——角峰"我真的太感谢你了"）
- 信息来源（补）：干员密录（obt/memory/story_hpsts_1_1）
