# 橡杯

- **身份**：萨米**萨满学徒**（"橡树之子"——"这个名字在萨米与'智慧'同义"，艾尔启语）；自称"我是一名萨满学徒，有一群羽兽告知了我你们的处境"
- **经历（活动《泰拉饭》act36side）**：为莱欧斯小队解读**萨米密文板**（"北方"+"隐者"→独眼巨人——"萨米应该是想要告诉你们：去北方寻求独眼巨人的帮助，他们会协助你们找到回家的路"）
- **萨米占卜观（重磅）**："外来者对萨米的占卜经常会有你们这样的误解。我们很少为他人的未来、他人的愿望而占卜，我们的占卜只为自己的生存""我们只会在必要的时候请求萨米的意志引导我们……在那之外，我们依照自然的法则生活"；"狩猎，被狩猎；活着进食，死了变食物"
- **性格**：随性（"萨满一般不应该是更加严肃的人吗？""我也拿这个问题问过我的师父，他的回答是连续两天用我的角当酒杯"）；直觉准（"我的直觉告诉我，你是对的"）

## 活动《麦哲伦冰原》（act15mini）补全

- **原初森林向导（重磅）**：在原初森林（萨米的心脏）遇到寒檀/提丰/麦哲伦——自荐当向导（"一个'指木人'，一位……向导！这儿没有比我更合适的向导了！"）；话痨/多语言（哥伦比亚语/乌萨斯语/萨米语——"我的嘴闲不住，见到什么人都想聊天"）
- **师父=雪祀（重磅）**：萨满学徒（"橡树之子"——师父喝醉抓他角当酒杯）；"我师父就是一位雪祀"；雪祀=首席萨满/大萨满（"不一定是最年长的，但一定是最有能力且有权威的，相当于是一个地方的首领"）
- **密文解读（重磅）**：麦哲伦捡的老树皮=**族树传达给侍奉它的萨满的密文**（"雪祀""喜悦"——"即使是相同的符号，依时间与人物的不同，祂真正要表达的意思也会大相径庭"）
- **岩角兽送行（重磅）**：为被邪魔致伤的岩角兽解脱（萨米式临终送行——"安玛注视着你，你将在她的林地栖息……你将与众生的灵一起驰骋在，萨米的脊背上"）；收留小岩角兽（"以她的血……她的泪……她的角……停在你的蹄上"）
- **"黑印"传信（重磅）**：寒檀请橡杯转告师父（树冠贤者）——"乌萨斯的'黑印'与这件事有关"（"和乌萨斯有关系，多半没好事"）
- **萨米观（补充）**："猎手杀死猎物，幼兽长大后前来复仇，人类会做，动物也会做。我们和它们的区别没有你们'文明人'想象中的那么大"；"萨满的学徒总不会在森林里饿死吧"
