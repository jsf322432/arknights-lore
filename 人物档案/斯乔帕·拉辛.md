# 斯乔帕·拉辛（Stiopa Rassin）

- 身份：乌萨斯**特殊战术兵团"谢钦"指挥官**（少校）；"自由民"（非乌萨斯人）领袖
- 首次登场：第十七章「相变临界」（"谢钦"线）
- 关键信息：
  - "谢钦"：由异族人（非乌萨斯）组成的特殊战术兵团（"被隔绝与被消耗的、摇摆不定的刽子手"）；为第四集团军（叶甫根尼）执行脏活（镇压叛乱、"斩首行动"）；"老祖母"之歌为团魂
  - 曾暗中帮助感染矿石病的战友逃离军营（副手**西尔卡**为其安排护送）；被叶甫根尼以"西尔卡被捕"（实为战争术师模仿的声音）胁迫执行自杀式任务——夺取第一集团军新武器
  - **识破"假西尔卡"**：战争术师无法读取记忆（"在死亡到来之前，我们不会再见了"）；向全舰广播**脱离第四集团军**（"我要这艘船上的人不再为散播恐惧服务，不再为欺压平民服务。我要我们脱离第四集团军，脱离任何只把我们当作武器的地方"）；移交指挥权给**奥列格**
  - 以废弃短咒对抗叶甫根尼亲卫队（战争术师，"莫尔凡"冻结空间）——黑焰吞没对峙双方、战争术师撤退；"我最多只能争取两分钟时间"
  - 理念："我们不是战争这庞然巨物的养料……我们需得自由，但不是被大人物指派的自由。我们可以选择，且不止战斗和死亡这两条道路。"
- 经典台词："我们需得自由，但不是被大人物指派的自由。""向乌萨斯要求兑现承诺的时候到了。""就算去见维伊，我也要夺取属于'自由民'的，真正的自由。"
- 信息来源：第十七章（17-03/17-07/17-08/17-12/17-15/17-17）
