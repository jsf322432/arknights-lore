# 博士（Dr.{@nickname} / Doctor）

- 阵营：罗德岛
- 身份：战术指挥官（前线指挥）；失忆前为**神经学博士、顶尖矿石病研究学者**
- 首次登场：序章「黑暗时代·上」（0 欢迎/苏醒，从切尔诺伯格"石棺"中救出）
- 现状：完全失忆（连阿米娅也不记得），但指挥才能未减；PRTS 权限水平 8
- 关键信息：
  - 沉睡于切城核心区生命维持装置（石棺）中，罗德岛此行目的即营救他
  - 梅菲斯特对博士的身份与来历极为在意（"你和我们有点不一样"）
  - 开场神秘声音提到"12月23日"、"她需要你"、"你必须想起来"（伏笔）
  - 杜宾称"罗德岛本身就很像你的专业"
  - **第八章揭示**：三年前重伤被凯尔希放入石棺治愈（"这台仪器能够治愈你的病痛，也只能治愈你的病痛"）；凯尔希称"你"杀了**特蕾西娅**（巴别塔领袖、凯尔希挚友）；石棺记忆中忆起**普瑞赛斯**（"不准忘记我"）
  - **第十三章**：与凯尔希/阿米娅/Logos 穿越赤鬃山脉深入赦罪师祭坛；"提卡兹之血"与"阿喃那"相关
  - **第十四章（真相揭示）**：死魂灵幻象证实——**失忆前的博士是杀死特蕾西娅的凶手之一**（与刺客们一同见证了倒在血泊中的特蕾西娅；W："害死特蕾西娅的凶手，怎么着都数不出第二个人"；阿米娅："我早就猜到了"）；凯尔希："我认同特蕾西娅当时的选择，告诉现在的你真相于事无补"
  - 在源石"内化宇宙"中忆起**前文明宇宙**（与普瑞赛斯相识、"罗德岛"飞船）；**源石=普瑞赛斯与博士共同创造的造物**；能使用"未知语言"改写源石规则（令罗德岛显形/重构飞空艇）；菱形=源石/普瑞赛斯标志
  - 结局：得知"阿喃那"（最初的源石）的位置，与阿米娅/凯尔希/维什戴尔/Logos 冲出源石内部
  - **第十五章（真相）**：前身代号"**预言家**"——与普瑞赛斯共同创造源石（预言家视其为留给后世的信标/礼物）；创造 AMa-10（凯尔希）并赋予其"找到自己"的使命；留下石棺加密程序与"祝福/馈赠"；是唯一有权限开启 Abyss（石棺/PRTS 核心）之人
  - **拒绝普瑞赛斯**（"我不会让源石毁灭泰拉"）；与阿米娅深入"文明的存续"（越过文明奇点、解出"普瑞赛斯"之名）；以逆转"安眠桥"公式削弱普瑞赛斯对源石的控制；目睹凯尔希牺牲
  - **《巴别塔》（失忆前的真相，1090-1094）**：被凯尔希/特蕾西娅从石棺中唤醒（1090，PRTS 检索"保存者/深蓝之树/天堂支点"全无信号——前文明遗产谱系伏笔）；泰拉=**塔卫二**（源石"将来自塔卫二的生命，塑造成与我们相近的模样"）；"我以拯救者的身份被唤醒，我却是他们注定的毁灭者"
  - **与特雷西斯的交易（1093 冬）**：以"碎片大厦"情报交换——承诺摧毁巴别塔/令其战败；特雷西斯要求"那就杀死他们的王"；博士"让命运的天秤倾斜……不必杀死特蕾西娅，至少尽可能少失去一些生命"
  - **特蕾西娅之死（1094）**：作为**内应**放刺客登舰（"有敌方的大人物在帮我们"）；特蕾西娅被弃名死士所杀，死前**抹除博士的全部记忆**（"我杀死了他，也救下了他"）；凯尔希将其送往切城石棺（=主线序章起点）；"我是谁？是我们自身的守望者？还是后来文明的背叛者？"
  - **《生于黑夜》（回归罗德岛）**：切城事件时以兜帽形象现于罗德岛（"巴别塔的亡灵"——被 W 认出后放走）；伊内丝"棋子论"（"我们都是物，死物。好像整场战争只有他才是那个人，唯一一个人"）；赦罪师（摄政王方）："罗德岛如今已经迎回了那个让人不快的人"
  - **《孤星》（哥伦比亚·特里蒙）**：见**石棺**（"你现在所拥有的记忆的起点"——缪尔赛思语；晕眩感与切城苏醒时如出一辙）；与凯尔希/锡人深入能量井地堡；与"保存者"弗里斯顿的**"辩论"**（思维共振——幻见**普瑞赛斯**（"只是她的思维共振""扮演'博士'的人是我，而你才是'我'"）、塔露拉、阿米娅、特蕾西娅）；"我就是我自己""我始终如一"（特蕾西娅幻影："你是一个全新的人。但不必沮丧，你也是最接近本性的那个你……'始终如一'，这句话将是你的生命中最重要的注脚"）；目睹弗里斯顿把"最后的血"交给克丽斯腾、见证万星园突破星荚（双月露真容）
- 与其他角色关系：
