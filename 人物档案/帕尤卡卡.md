# 帕尤卡卡（Payukaka）

- 阵营：？｜种族：黎博利｜身份：自称"探险家"（神秘游历者）
- 首次登场：活动《日暮寻路》（act18mini，2023；st06）
- 形象：随和神秘（"怕，怕极了。人哪有不怕天灾的"）；好奇（"我看到没见过的景象，就按捺不住好奇心"）；谎话多（维什戴尔："别再在我面前撒谎了，我知道你是故意被抓住的"）
- 关键信息：
  - **天灾避让（重磅）**：萨卡兹撤军队伍头顶的天灾云——**雷电都躲着他**（雇佣兵斥候："我可没见过能让天灾云里的雷电都躲着的探险家，就像、就像它们在害怕你"）；死魂灵："他身上有我讨厌的味道……（古老的萨卡兹语）'施矛狄卡'……外来的敌人。不，不是那些家伙亲自来了，是他随身带着的一个东西。奇怪，好像只是……一张纸？"——**随身携带的"符纸"令天灾/死魂灵忌惮**（身份谜团）
  - **游历路线（重磅）**：穿过萨米与乌萨斯（"我总是能遇到讲道理的人"）；叙拉古被家族成员抓去审问（多次——"不知道是第几次被不同家族的人抓起来审问了"）；**自称要去"黑流树海"**（"也是回家，朋友，回玻利瓦尔"——叙拉古家族成员语："你要去哪里来着，'黑流树海'？"）——**呼应《丛林症结》黑流树海**
  - **与萨卡兹（重磅）**：故意被萨卡兹侦察兵抓住（警告"有舰队朝你们过来"——无法确定国籍/关闭信号识别/地形掩护埋伏）；被维什戴尔放走（"要是再有萨卡兹不长眼抓你，就告诉他们放你走的人的名字——维什戴尔"）；维什戴尔："我怎么总能撞上一些跟萨卡兹没有半点关系、偏偏要来帮忙的好心人？"
  - **萨米技巧**："我在萨米学会了一招，一旦害怕，就把帽子扣在头上，蹲在那里想点开心的事"（萨米经历——邪魔/雪祀关联？）
- 经典台词："我看到没见过的景象，就按捺不住好奇心。""也是回家，朋友，回玻利瓦尔。"
- 信息来源：活动《日暮寻路》st06
