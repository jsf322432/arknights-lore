# 芳汀（Fartooth）

- 身份：罗德岛干员（萨科塔/拉特兰出身/感染者；法杖术师——"分解、毒素"源石技艺）
- 首次登场：活动《如我所见》（act13d0，故事集）
- 关键信息：
  - **萨科塔术师**：拉特兰出身/感染者（无法回拉特兰——"拉特兰的土地不接纳感染者"）；持法杖而非守护铳（"很遗憾，我没有守护铳需要检查"）
  - **《如我所见》（武器可靠性证明）**：到第三维修工坊办武器可靠性证明（工匠们外出参赛，只剩学徒安德切尔）；欲拓印工匠签名蒙混（"源石技艺还真便利"）——被博士识破（"罗德岛的博士果然很敏锐，安德切尔那家伙倒是没说错"）
  - **与安德切尔**：聊拉特兰（"你是个地地道道的拉特兰萨科塔。虽然持不了铳，光环也不正"——对安德切尔）；对弃械师傅感兴趣（"我有预感，我会和这个人合得来"——"那个到处都是弹壳的地方，我见了就头疼"）
  - 与安比尔：公证所话题（"上一个在我午睡的时候突然砸我的门的家伙，现在还在为了替我解决一些事情而四处奔走呢"）；安比尔："你说话像个反派。挺不错的嘛"
  - **转变**："发现了不少有意思的人，为此花费一些时间也不错"（决定下午再见弃械师傅/不再蒙混）
  - 与送葬人：与公证所干员"送葬人"有约（"把安比尔出没的情报带给他，他会不会卖我个人情？"——玩笑）
- 经典台词："发现了不少有意思的人，为此花费一些时间也不错。""你是个地地道道的拉特兰萨科塔。虽然持不了铳，光环也不正。"
