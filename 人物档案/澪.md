# 澪（Mio）

- 阵营：金石会（三船的助理/杀手）→独立｜种族：黎博利｜身份：三船手下的杀手（三只手三把刀）；金石会的"孤儿"
- 首次登场：活动《墟》（act44side）
- 关键信息：
  - **金石会的孤儿（重磅）**："一个衣衫褴褛还一言不发，只在别人欺负到自己头上时以命相搏的孤儿，是祸害""一个盛装见人却沉默寡言，只在公司利益受损时挥刀砍人的助理，是让人憧憬的高岭之花"；"铁斋想给我们这些社会渣滓一个家，所以他死了。三船知道我们根本不配有一个家，所以，他活到了今天"；忠于"金石会"本身（"能让为人所不容的渣滓们活下去，这才是金石会"）。
  - **能力**：三只手三把刀（黑色"鬼手"=源石技艺——"一个人，三只手，三把刀"）；"我何曾替他（三船）卖命？"
  - **《墟》**：受三船命令"处理"萌萌香（"让她直接悄无声息地消失……帮她染上个矿石病"——对萌萌香的愧疚："唯独对萌萌香，我做不到问心无愧"）；放走哲也（"在我改主意之前，走。再也别回来"）；与星熊对决（"你怕刀出鞘……你在害怕"——"我不会失控的。有般若不会，没般若，也不会"）；认输（"善后。为一个没有三船先生的金石会善后"）；向议员辞行（"我已经尽最大努力为金石会善后，现在特来向您辞行"）。
- 经典台词："铁斋想给我们这些社会渣滓一个家，所以他死了。三船知道我们根本不配有一个家，所以，他活到了今天。""我的刀与他无关。""对金石会好一点。对萌萌香好一点。"
- 信息来源：活动《墟》（全文）
- 后续：离开御机（辞别金石会/议员）；去向未明
