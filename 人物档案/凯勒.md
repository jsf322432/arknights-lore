# 凯勒 / 阿黛尔·凯勒（Keller / Adele Keller）

- 身份：**火山博物馆馆长**（汐斯塔）；火山学者；**本名也叫"阿黛尔"**（与艾雅法拉同名）
- 首次登场：活动《火山旅梦》（act27side）
- 关键信息：
  - **身世/过去**：汐斯塔人；年轻时是摇滚吉他手（"我希望有一天，我可以在汐斯塔最高的地方弹吉他……我出的第一张专辑，就准备叫《火山奏鸣曲》"）；在知更鸟咖啡店与**瑙曼夫妇**（卡提亚/玛格娜）相识（"我见识到了书本之外更广阔美丽的大地"）——随其走上火山研究之路（"和玛格娜、卡提亚他们一起，在火山上度过了十几年的时间"）
  - **"阵雨计划"（真相）**：卡提亚将部分研究交给莱塔尼亚军方换取安稳学术环境——凯勒负责对接军方；**乌纳火山意外前凯勒离队=去帮瑙曼夫妇搪塞军方**（"我没有预料到会有那样的意外"）——自责十年（"恐惧的人到底是谁呢？火山就在眼前，自己却一步也无法上前"——十年不敢再登火山）；被卡恩误会（军方书信）——真相大白（阿黛尔："您为什么会觉得，这是自己的错呢？"）
  - **《火山旅梦》**：建火山博物馆（"希望能保留下他们当年所研究的一切"）；邀请阿黛尔（艾雅法拉）协助整理父母遗物；与科斯达重逢（知更鸟咖啡店/火山咖啡）；登火山观测（克服心结）；"我多想陪他们再走一段"
  - **本名伏笔**：凯勒的名字=阿黛尔（st03：阿黛尔翻阅旧文件发现"凯勒老师的名字原来是……"——艾雅法拉与凯勒同名）
  - 理念："能让人们凝聚在一起的，除了客观的自然环境，还有共同的记忆""我希望多年后，人们提起瑙曼夫妇时，只会记得他们是纯粹而伟大的科研学者"
- 经典台词："恐惧的人到底是谁呢？火山就在眼前，自己却一步也无法上前。""我多想陪他们再走一段。""我希望多年后，人们提起瑙曼夫妇时，只会记得他们是纯粹而伟大的科研学者。""遇见他们，是我人生中最幸运的事。"
- 信息来源：活动《火山旅梦》（全文）
