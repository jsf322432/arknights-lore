# 蒂奇（Titch / "小珍珠"）

- 身份：盐漠海盗船队的副手（胡安娜的左膀右臂）；船员之女（"小珍珠"）；结局随胡安娜出海
- 首次登场：活动《出苍白海》（act39side）
- 关键信息：
  - 与胡安娜：幼时被胡安娜抱在怀里讲"出海"的故事（"爸爸说你们出海……海真的是蓝色的吗？"）；"我不在乎罗盘，我只在乎胡安娜女士"；深知胡安娜的伤疤（"她从来不在众人面前示弱……总能在她身上看到新的伤疤"）
  - 性格：果决泼辣（"我宁可死在此次的狩猎中，也不愿意一个月后活活饿死"）；务实（"人比肉重要"——放弃猎物保人）
  - 《出苍白海》：逼伊西多干活/警告他（"炼金工坊里发生的事，不论是好是坏，一件也不要向旁人提起"——很多人等着胡安娜出错拉她下台）；围剿中与帕斯卡拉相依（重伤仍护着她——"帕斯卡拉，你把我放下，自己先跑……"；"这份温暖如今好像是属于她的了"）
  - 结局：随胡安娜出海（极境告别："您真的是一位很帅气的女士……我祝您一路顺利，能够真正地在大海上航行，和风浪搏斗"）
- 经典台词："人比肉重要。""我不在乎罗盘，我只在乎胡安娜女士。""我宁可死在此次的狩猎中，也不愿意一个月后活活饿死。"
- 信息来源：活动《出苍白海》（全文）
