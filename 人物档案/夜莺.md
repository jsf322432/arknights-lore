# 夜莺（Nightingale / 丽兹 Liz）

- 身份：罗德岛干员（赦罪师出身，与闪灵、临光组成"使徒"）；"容器"真相在第十四章揭示
- 首次登场（提及）：第十三章「恶兆湍流」（此前作为罗德岛干员被多次提及）
- 关键信息：
  - **第十四章（真相）**：赦罪师首领奎萨图什塔为制造"容器"而造出的纯白意识——"把一个纯白的意识做成囚笼，好骗过'魔王'"，本欲将魔王力量转移至闪灵（奎萨辛娜）身上；丽兹是"一个本不该存在的意识，向往着本不可能拥有的自由"
  - 闪灵曾负责雕刻其灵魂（后因探索灵魂的执念留下痕迹，丽兹因此苏醒/拥有情感）；"我夺走了你真实的记忆"
  - 反抗奎萨图什塔：撕裂灵魂挣脱囚笼（"我有名字的。我叫丽兹，是你的敌人。""你说的每一句话，我都不同意"）——灵魂受损（"你的灵魂为什么不完整？！"）
  - 与闪灵/临光的约定（"我是使徒的一员……一名医生。我也会保护你们。"）
  - **第十三章**：被赦罪师带走（W 安全屋遭袭）
  - **《长夜临光》（卡西米尔）**：与闪灵陪伴临光（"你只要安心点亮你的光就好，临光……但是也不要太勉强。你的疲惫在积攒"）；与玛嘉烈夜舞（"青鸟飞向了温婉的深空……宛如拉特兰最崇高的圣像"）；"有一天，你能够真正起舞的，丽兹"——"那一天来临的时候，你还会在我们身边吗？""当然。"
- 经典台词："我有名字的。我叫丽兹，是你的敌人。""在你们身边……我仿佛……真的会飞。"
- 信息来源：第十三章、第十四章（14-11）；活动《长夜临光》（05_beg/10_end）

> 待补充：灵魂修复、与闪灵/临光的渊源全貌（《使徒》活动、后续主线）
