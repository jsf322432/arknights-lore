# 温米（小锅盖 / Vermeil）

- 身份：**卡特斯小女孩**（矿石病感染者）；阿兰娜收养的"女儿"；源石技艺（热/温度控制）
- 首次登场：活动《去咧嘴谷》（act16mini，2024）
- 形象：爱笑逞强（"温米怎么会有不开心的时候呢？"）；能干（"六星级大厨"——做饭）；渴望长大（"我又不是小孩子啦"）
- 关键信息：
  - **身世（重磅）**：老爸=卡特斯矿工（"每次离家上工，坐的就是这趟车"——**可能死于矿难**（"前两年……矿难停过一个"——温米赖在阿兰娜的运载车上等爸爸）；老爸离家前一天的生日愿望："像现在这样开开心心地长大"（"如果不开开心心地笑着的话，在人群中找到她老爸的时候，老爸就认不出她了"）；**感染矿石病**（被阿兰娜藏在车上两年——"你收养了两年，还一直藏在车上的……是个感染者？"）
  - **源石技艺（重磅）**：徒手施术控温（热菜/调节动力炉温度——"我说过多少次不许徒手施法"）——**源石技艺失控爆燃/发烧**（"潜意识的施术行为停止了，体内源石结晶的活性化进程也控制住了"——阿米娅救她）；学用法杖（阿兰娜买"充满雷姆必拓工业美的法杖"）
  - **与阿兰娜（重磅）**："兰娜姐有点像爸爸，也有点像妈妈，还有点像矿工叔叔婶婶们……谁都像，那就谁也不像了"；"她和朋友们打了个赌，而我是他们的赌注"（赌局赌注）；"要是我以前就会源石技艺的话，就可以偷偷地把椅子变得暖暖的，让爸爸的骨头不那么疼了"；**去罗德岛本舰治病**（暴行带路）；哭（"抓着我的衣服哭，我也不计较了。至少这趟旅途走到最后，你不是两手空空啊"——阿兰娜）
  - "变成感染者……难道是错事吗？""为什么我是感染者，就会把兰娜姐害成那样？"（对感染的困惑）
- 经典台词："温米怎么会有不开心的时候呢？""兰娜姐就是兰娜姐。""我还能跟着你们一起找巨兽吗？"
