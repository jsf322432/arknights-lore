# 死芒（Sidemon / 爱布拉娜·都柏林）

- 阵营：罗德岛（干员"死芒"）｜种族：德拉克｜身份：爱布拉娜·都柏林——深池领袖的"死后"形态（"我只是塔拉领袖的小小影子，只是'死芒'"）
- 首次登场：活动《淬羽尘黯》（act41side，st03——以"死芒"之名与博士对谈）
- 关键信息：
  - **真相（重磅）**：爱布拉娜并未真正死去——"死亡对我而言从来都不是沉眠。我驱策生命能做到的，驱策死亡亦然"；"加斯特里尔"号与食腐者一战后急需把分出去的死火收归己身（"征收血税"——"那是延续千年的怨恨、悲伤和愤怒，当它们聚集到我身上，又怎么可能简简单单地放我的意识和身体消散"）；被拉芙希妮"两次杀死"（枪尖/火焰）后死火聚身反使她无法消散——以"死芒"之名活着。
  - **《淬羽尘黯》（幕后）**：向威灵顿承诺"只要拉芙希妮愿意回归，我就能扭转塔拉的航向"（"用一城注定死去的人，换取一个稳如磐石的塔拉"——原计划纳斯尔纱人死光/死火收归己身；拉芙希妮创造奇迹救活全城——"这件事出乎所有人的意料"）；酒馆中以"神秘女性"身份引导作家（"歌唱家"）讲完故事（"这个故事现在已经不属于你，只属于我"——揭穿/失语）；"永别了……直到死亡让我们重逢。希望你喜欢我给你的临别赠礼"（对拉芙希妮）。
  - **与博士（罗德岛）**："被你的罗德岛所吸引，所以降临。毕竟这里总为死亡的气息所笼罩，你的身旁尤其如此，亲爱的学者""当洪潮倾覆，死如夜般随行，只要我不嘲弄你们的灾难，你就会感激我的存在""我只是塔拉领袖的小小影子，只是'死芒'"——以干员"死芒"身份加入罗德岛。
  - **性格/力量**：死火（紫火）之主（"凡俗的君王征收血税……而我征收血税，将其与红龙的火焰共同铺就路途，将生命与死亡连通"）；"死亡平等地嘲弄所有人……而我，将嘲弄死亡"。
- 经典台词："死亡对我而言从来都不是沉眠。""我们即塔拉。""永别了……直到死亡让我们重逢。""我只是塔拉领袖的小小影子，只是'死芒'。""生命短暂，而死亡要漫长得多。"
- 信息来源：活动《淬羽尘黯》（全文）；主线第十二~十四章；《照我以火》
- 后续：罗德岛干员"死芒"（与博士对谈——"我终会明白的"伏笔）；塔拉线核心伏笔（"关于红龙的复活，会诞生一个完全不同的故事"——涅梅丝担忧）
