# 砾·塞诺蜜（Gravel / 塞诺蜜）

- 身份：卡西米尔征战骑士（四阶）；被贩卖到卡西米尔的奴隶出身；罗德岛干员（"砾"）
- 首次登场：活动《长夜临光》（act13side）
- 关键信息：
  - 身世：作为奴隶被贩售到卡西米尔（"我从那时候起，就被老爷教育，要时刻准备好为他人献身"）；被骑士家族收养（"老爷"）；监正会指派为罗德岛（博士/阿米娅）在卡瓦莱利亚基的护卫
  - 性格：轻佻热情（初见"啾——"的吻礼玩笑）、话中有话（"我只是比较喜欢能掌握全局的感觉"）；对博士（"您是自由的"——博士语）产生真心认同（"我现在是发自真心地想要保护博士"）
  - 战斗：与白金（欣特莱雅）周旋保护博士；随博士以"联合会成员"身份化解无胄盟
  - **结局**：说服"老爷"放行、随罗德岛离开卡西米尔（"年轻的骑士需要历练……他们已经赢得了砾的忠诚"——罗素为其作保）；"如果我也去罗德岛兼职的话，能和您……平起平坐呢？"
  - **《玛莉娅·临光》（前史）**：塞诺蜜为"老爷"（银枪天马老骑士，戴罪之身）传话——"那些竞技骑士就是一帮为了钱财甘愿受人摆布的废物""被商业联合会腐蚀渗透的国民院无权给老爷定罪"；与罗德岛人员抵达卡西米尔（衔接）
- 经典台词："您只是把自己当做我的救世主——但您是自由的。""如果我足够优秀……那即使我过去是奴隶，也配得上与您同行吧？"
- 信息来源：活动《长夜临光》（全文）；活动《玛莉娅·临光》（st03）

- **身世（重磅）**：被拐到卡西米尔的孩子（"和你不同，我甚至没有从猎人手上逃走的机会，就这样被卖掉了。唯一幸运的是，买走我的老爷子是位大善人"——五月树家族长骑盖克斯基）；成为骑士后巡历村庄惩治猎人（贩卖勾当的势力被她肃清）；盖克斯基（"你是来向我道别的""你没有放弃去找它（故乡）。这是正确的事情"）
- **梦境（重磅）**：恐怖马丁酒吧（救逃跑的女孩——被猎人拐卖——"我不知道自己的家在哪里"）；"我时常做梦。梦到自己离开家乡，被带到了卡西米尔……时至今日，我还是无法想起自己到底来自哪里"（"贫穷，闭塞……脆弱。做父母的连保护自己的孩子也做不到"）
