# 临光（耀骑士 Nearl / 玛嘉烈·临光）

- 种族：库兰塔（马）｜出身：卡西米尔（卡西米尔骑士）
- 阵营：罗德岛（E4 小队）｜称号：耀骑士
- 首次登场：序章「黑暗时代·上」（0-9 临光）
- 性格：正直、谦逊、果决；"不断战斗是我达到目的的方式"
- 关键信息：
  - 神兵天降，先安顿平民再赶来接应（"你们的速度比我估算的慢上太多了"）
  - 用盾牌挡开浮士德的弩炮；发起骑士冲锋击溃整合运动阵线
  - 与阿米娅谈心：夸奖阿米娅靠自己解决危机，"再自信点"
  - 提到自己有一个同样失忆的朋友（与博士"会合得来"——伏笔）
  - 与 Ace 分析浮士德的异常狙击（时差/交叉火力）
  - **第一章**：天灾坠石中飞身救下博士（"我的盾牌还撑得住——跳啊，博士！"）；塔露拉一击融化其全身铠甲，重伤仍坚持带队撤退（"作为耀骑士，无论在什么时候，都该成为指引众人的光吧？"）
  - **第十四章（"使徒"线）**：自卡西米尔驰援伦蒂尼姆（"抱歉，之前风暴过于强烈，我花了点时间确定方位"）；与闪灵/夜莺并肩对抗赦罪师**奎萨图什塔**（剑枪击落其荆棘冠冕；"英雄流自己的血，为其他人开道"）；"使徒"三人组集结（"只要你们需要，玛嘉烈·临光还有她的剑枪，会随时为你们而来"）；提及与夜莺/闪灵的约定
  - **《长夜临光》（卡西米尔回归，核心前史）**：六年前因"隐瞒感染者身份"被流放——**实为爷爷西里尔·临光的"假感染"保护局**（她本人后来才察觉，"我并不是感染者"）；以独立骑士身份重返特锦赛夺冠（击败左手骑士/烛骑士/逐魇骑士平手/决赛胜血骑士）
  - **《玛莉娅·临光》（回归救场）**：得知妹妹遇险（独战腐败/凋零骑士濒死），自流放地携闪灵/夜莺赶回——"你长大了，你做得很好""辛苦了，玛莉娅"；姐妹同心击败二人；决心参加特锦赛（"我会取回应属于骑士的荣耀"）；与玛恩纳拔剑对峙（"倒在我的剑下，总好过倒在无胄盟的阴影里"）
  - **理念**："所谓骑士，即是照亮整片大地的崇高者"；"我们只是各自投身于自己的信念……为自己的理想和正义而奋斗"；拒绝联合会颁奖，**搀扶血骑士共赴冠军墙**（"授勋之地，是骑士的归属"）；"我会留在这里……让骑士们能够重新被称作骑士"
  - **《骑兵与猎人》（前史）**：给格拉尼写任务信（卡西米尔骑士陵墓/骑士宝藏传统——"请帮我确定骑士遗物的真正内容"）；后信揭穿（"斯卡蒂已擅自前往滴水村，未任命其任何任务，小心对待"）
  - 与罗德岛：暂离罗德岛（"我不能把这份责任强加在他们身上"）；结局与博士/阿米娅道别（"如果罗德岛呼唤我，那么我一定会前往您的身边"）；为红松骑士团引荐罗德岛
- 经典台词："想要对抗卡西米尔骑士——再去训练个几十年再说！""在需要保护的人身前，骑士的盾不会这么脆弱。"
- 信息来源：序章 0-9、0-10、0-11；第十四章（14-11）；活动《玛莉娅·临光》；活动《长夜临光》（全文）；活动《骑兵与猎人》（任务信）
