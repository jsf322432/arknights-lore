# 顾筌 / 顾笙（Gu Quan / Gu Sheng）

- 身份：**煌（顾烛煌）的父亲**（本名**顾笙**——1037 年生于琅珆）；太师门下的寒门学子；礼部奉礼郎（后改名顾筌）
- 首次登场：活动《春分》（act40side，回忆/身世）
- 关键信息：
  - **太师门下**："当年无数寒门学子之一"；受太师"一言之恩"（"世事诡随，谨致良知"——太师教诲）；1055 年考入学宫（教育科——改制后第一批/成绩全甲）；1062 年"与其妻女失踪"（档案封存）
  - **太师案（四十年前）**：太师案发时当众上门凭吊（"那个学宫的学生，竟敢当众上门凭吊太师"）——撞见太师被抄家——**带走太师家出生不久的女婴（=宁茵——太师遗孤）**——携妻女（妻子+自己的女儿煌）逃离百灶——被禁军抓到——禁军（心存恻隐）放走他（"有意为太师保留血脉"），带回"书生的孩子"（宁茵——交到宁述手中收养）；顾筌逃到维多利亚（煌出生）
  - **回百灶**：改名顾筌（维多利亚归侨身份）1074 年定居炎国/1077 年入职礼部（奉礼郎——十几年未升迁）；**宁府誊录郎**（在宁述眼皮底下抄信十几年——"就通过这一封封达官显贵之间的信，他一个九品的奉礼郎，找到了当年那场血案中活下来的每一个人，抽丝剥茧，最终拼凑出了真相"）；寻找遗落在百灶的女儿（宁茵）
  - **百珍宴献菜**：献"天下一白"（清炖萝卜——教育平等）+白面馒头夹红腐乳（"意在给叛臣平反，惹得真龙大怒"）——**近乎求死之举**（"实际上是已经与真相和解"）——被打入死狱（**唯一一个被打入死狱又被放出去的人**）
  - **假死与病逝**：虞澄安排"坠河假死"（"借先生人命一用——你要的清白真相，我给你"——让顾筌脱身/杜绝追查）；顾筌病重（肺病——"五脏六腑都被病灶沁透了""大夫说，我活不了多久啦"）；"我想见她们，但是不见，可以让她们活得更好""他们都放下了，我也该放下了"——临终把太师遗孤（宁茵）的下落告诉唯一的朋友**虞澄**（"他是希望我查明真相后，也能选择和解"）
  - **与煌**：在维多利亚寄桔红酥给女儿（"他总是习惯点一份桔红酥，说要寄给国外的女儿……自己做了加工，又用信纸在包装上裹了一层又一层"——余味居常客）；"他眼里总是有光的"（煌语）
- 经典台词："蒙恩逢赦，夫复何求。""我想见她们，但是不见，可以让她们活得更好。""古来世事如流水……没有涓流，何来浪潮？""世事诡随，谨致良知。"（转述太师语）
- 信息来源：活动《春分》（全文）
