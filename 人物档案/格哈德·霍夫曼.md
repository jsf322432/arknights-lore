# 格哈德·霍夫曼（Gerhard Hoffman / 学者）

- 身份：恩瓦德最具天赋的术师之一；曾服务于乌提卡家族；弗莱蒙特的学生；23 年前随双子攻入巫王塔的幸存者；巫王残党的实际执行者
- 首次登场：活动《崔林特尔梅之金》（act29side）
- 关键信息：
  - 巫王时代：王座前数千名术师之一（"那一天，我曾经跪过的台阶……变得比路德维格大学里的红叶还要鲜艳"）；**背叛巫王加入反抗**（"在赫琳玛特和伊维格娜德的带领下杀进了巫王塔"）；并肩作战的友人十不存一（"我的同学，朋友，甚至爱人都不在了"——曾想跳塔，被弗莱蒙特以金律乐章之书救回）
  - 学者生涯：研究金律乐章二十年（"当我无法回答自己的提问的时候，历史说不定可以"）——得出绝望结论："赫尔昏佐伦的成就太过耀眼……他解决了叙拉古的问题，拯救莱塔尼亚于分崩离析的边缘……而这样一位伟大的王，却被我们杀死了"
  - 《崔林特尔梅之金》：从黑键脑中"尘世之音"下手失败后，**盗用金律乐章副本上的赫尔昏佐伦术式**召唤"始源之角"（"我不想……后悔第二次"）；欺骗并敲晕黑键（"这是第二次。有人举起手里的铜管乐器，狠狠地敲在他的头上"——第一次是残党植入尘世之音时）
  - 动机：为当年劝说战友赴死而求自我原谅（"像我这样，自私又懦弱的人……我做的所有的事，不都是为了……求得自己的原谅？"）
  - 结局：身体无法承受赫尔昏佐伦术式而崩毁（"我这身体……果然不可能成为'始源之角'的容器"）；阿尔图罗为其送葬——琴声揭示**"黄金的旋律……莱塔尼亚的意志……我们所有莱塔尼亚人都被困住了！"**（"错不在我。"）；死在路德维格大学最高处（"他从未像此刻这般自由"）
- 经典台词："我走得太远了，老师。我不想……后悔第二次。""伟大的王，却被我们杀死了。""错不在我。"
- 信息来源：活动《崔林特尔梅之金》（全文）
