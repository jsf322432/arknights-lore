# 酒神 / 剧团长（Dionysus / 猩红剧团团长）

- 阵营：猩红剧团（创始人/团长）→传承给卢西恩｜种族：？（菲林形象/长生者）
- 首次登场：活动《红丝绒》（act43side，2025）
- 身份：**长生者**——"诈术师、表演家、苦行者、权谋家、煽动者、游走于历史的幽灵，一个无从被定义的长生者"；戏剧美学的信徒（"死亡是戏剧的因与果，魂与肉……万物的归宿"）
- 关键信息：
  - **历史足迹（卢西恩考证）**：拉特兰（两百多年前某枢机因"绝症真相"发动政变被铳骑格杀）；高卢加莱（副将叛城后自尽——"叛徒成了那场战役中最可悲的死者"）；伊比利亚黄金时代（灯塔/双生相印演出票根）；莱塔尼亚高塔；萨尔贡/雪原——"你无处不在"
  - **猩红剧团**：以黑暗造梦、用绝望喂养演员；训练卢西恩（"血钻"）、暮落（"沉渊"）、剧作家（"笔者"）与"白英花/刀舞/影子"等老师；"剧团长看出我的早悟，亲自教导我如何使用武器"
  - **飞页（核心手法）**："擅长将一段本不存在的喜怒嫁接进你的人生，就像一个恣意妄为的导演……添加'飞页'"——为莫伊拉植入"劳拉姐姐"记忆（录像带/虚构童年）；曾为卢西恩的人生添加飞页
  - **死亡美学**："死亡是戏剧的因与果……它培育意义，也浇灌缺陷；它巩固真实，也喂养虚假；它让垂死的血肉成为花朵，让本应消失无痕的得到铭刻！"——因**死亡是长生者永远无法到达的彼岸**（"你难道不曾如我这般，感到痛苦？"）
  - **死而复生**：曾被卢西恩刺杀（"我犹记得刀锋刺入你胸膛的温热"）——"死亡常在，而戏剧永恒""你所杀死的，只不过是我的万千存在之一"
  - **结局（传承）**：被卢西恩以权杖刺穿心脏（"死亡，或者毁灭，是你送我的最好的谢师礼"）；完成"传承"——卢西恩成为新酒神（"戏剧不会毁灭，审美永恒更迭，我因此永远立于一切的顶点""你又能给出怎样不同的答案——'酒神'"）
- 经典台词："死亡常在，而戏剧永恒。""它让先驱找到登高的台阶，让远视者敢于放手一搏，让自诩灯塔之人成为灯塔！""我完成了初见时对你的承诺——我永远不会成为你的阻碍……戏剧的阻碍。"
