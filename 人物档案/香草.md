# 香草（Vanilla）

- 阵营：黑钢国际（实习生）→罗德岛交换干员｜种族：（萨尔贡）｜身份：猎手出身/实习佣兵
- 首次登场：活动《干员秘录合集（三）》（act7d5，2020）
- 形象：认真刻苦（"今天的体能训练终于完成了"——杜宾/雷蛇帮忙调过训练表）；护食（"圆圆小刺大黑还有坚强都不能吃！"）；对矿石病感染者态度转变（"一直觉得罗德岛的大家，和我曾经见过的感染者有哪里不太一样"）
- 关键信息：
  - **身世（重磅）**：萨尔贡偏僻贫穷部落出身（"部落的四周都是黄沙，因为很难耕作，想要生存下去，就必须要外出狩猎，部族里的每一个孩子，都会被培养为优秀的猎手"）；商队路过部落（以物易物/晚上围火堆/给孩子沙枣/讲外面的事——"在很远很远的东方，有遍地鲜花的香氛都市"）；"当佣兵是没得选，不过，我并不后悔"（缺钱）
  - **黑钢国际（重磅）**：实习佣兵；矿石病爆发后黑钢内部不少佣兵被感染，委托方不愿雇佣感染者——黑钢与罗德岛合作开始（"和罗德岛的合作，大概就是从那个时候开始的"）；香草经考核（实战+笔试——"为了笔试能合格，我还在图书室通宵了整整一个礼拜"）拿到交换名额
  - **小动物（重磅）**：养源石蜗牛（圆圆/小刺/大黑——"大黑虽然体型大，但是性格是最温顺的"；"不能挤压到大黑壳上的这些尖角。否则……会爆炸"）与小型萨尔贡沙漠磐蟹（坚强）——阿米娅和凯尔希医生给了许可（特殊保温箱隔绝源石影响/自动喂食）
  - **罗德岛感悟**："罗德岛的大家，和我曾经见过的感染者有哪里不太一样，大概就是因为大家都还在努力生活，并不看轻自己吧？……有的时候我甚至会忘记大家是感染者这件事"
  - 与 A4 预备组：玫兰莎（受托照顾宠物——芙兰卡"师傅"教剑术）、史都华德（受托照顾宠物——谢拉格人）；与煌（联欢会提议/朵拉）；"下次A4预备队的大家再去看望那些在接受治疗的孩子们的时候，也请叫上我一起吧！……来学习折纸花"
- 经典台词："当佣兵是没得选，不过，我并不后悔。"／"救人难道是错的吗？让更多无辜的人活下去难道是错的吗？"（意近）
