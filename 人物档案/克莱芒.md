# 克莱芒（Clement / 修道院花匠）

- 身份：安布罗修修道院花匠（种"象征友谊与希望"的花）；教会"青草格子饼"的见证者
- 首次登场：活动《空想花庭》（act26side）
- 关键信息：
  - 花的守护者：修道院之花=拉特兰与伊比利亚携手合作的象征；"那个时候修道院里还到处都是成片种植的花卉……整座修道院就像是被花填满"（爱琳/杰拉尔德都喜欢）
  - 信仰的崩塌：目睹矿石病萨卡兹被送入地下房间隔离（"我们从来救不了谁，也没有谁能救我们"）；"我们不得不看到现实……考验只会让它受伤"
  - 《空想花庭》：被阿尔图罗琴声影响（回忆/绝望——"从她的琴声里，我常常能听见上面这些回忆"，但否认其操控意志）；**地下预藏大量可燃物与点火器**（"在事情发展到无可挽回的地步之前……我会终止这一切"——费德里科称其为"系列异常事件主导者"）
  - 偷听主教计划→盗走怪物血肉面包（"我本来想，至少杰拉尔德他们不用参与进来"）；费德里科击毁其点火器但拒杀（"你的行为并未直接导致任何拉特兰公民的死亡"）
  - **结局：吞下面包咳血而死**（倒在被其烧毁的断臂圣像前——"圣像的断臂落在两侧，好似一个轻柔的抱拥"）；遗言："没有人……没有人能真正获得救赎……"；双胞胎把赫曼的毯子盖在他身上
  - 与费德里科：关于"伤痕无法修复的花"的问答（"但它还在。""是吗，它真的还在吗？"）
- 经典台词："这里已经没有我想要的花了。""想救我的是拉特兰的律法……还是你自己？""友谊、信赖、期盼、未来……什么都没有了，没人能真的得救。"
- 信息来源：活动《空想花庭》（全文）
