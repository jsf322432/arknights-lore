# 锡兰（Ceylon）

- 身份：**汐斯塔市长之女**；维多利亚国立大学源石研究者；后续罗德岛干员（源石研究/医疗）
- 首次登场：活动《火蓝之心》（act3d0）
- 关键信息：
  - 母亲芭芭拉生她时去世（葬于汐斯塔海中）；父亲赫尔曼"埋头于工作"；由保镖黑（"像姐姐一样"）带大
  - 研究源石的初衷：**治好黑的矿石病**（"我偏要把它治好！总有一天，我会把它给打败，然后把黑从它手里抢回来"）
  - 火山危机：独自搜集证据（"如今情况还算稳定，我们还有时间"）；向市政厅报告被克洛宁拒绝（"这个来路不明的外来游客"）；制定"广播塔计划"（实为诱饵引开黑）
  - 与黑的和好："我是你的朋友，一直都是"（黑）；"只要是朋友的话，就应该是这样啊"
  - 结局：加入罗德岛（"我准备向罗德岛投一份简历""所以我要你跟我一起去"）；赫尔曼同意（"这座汐斯塔已经不再是她的天堂了"）
- 经典台词："我们能战胜矿石病吗？我看不到尽头。我没有把握。我不知道答案。我可以放弃吗？可以。但我不愿意。""保护汐斯塔，既是父亲的事情，是你的事情，也是我的事情！"
- 信息来源：活动《火蓝之心》（全文）；活动《火山旅梦》（全文）

## 活动《火山旅梦》补全（身世重磅）

- **罗德岛驻汐斯塔办事处医生**（"我这次回来，就是想用自己的知识为汐斯塔做点什么。在这里建立罗德岛办事处，都是靠我自己的努力"）；与赫尔曼关系不佳（"你回到汐斯塔有两个月，也没有来看过我"——赫尔曼语）
- **母亲芭芭拉·道尔科斯（身世）**：维多利亚人/生态环境学者——怀着锡兰时每天往矿场跑（教工人避险知识/想推行感染者保护法案——"老了不必担心，病了不必绝望，这就是我想象中的汐斯塔"）；"她是在以她的方式保护这座城市，也在保护你"（赫尔曼语）；**锡兰=道尔科斯姓**（母亲姓氏）——"锡兰·道尔科斯"
- **黑曜石晶洞礼物**：工人们当年想送给芭芭拉（祝贺锡兰出生）的黑曜石晶洞——未送出（佩利佩保管）；背着矿灯的小黑羊（矿工化身）找到锡兰（伏在她胸口听"咚咚"心跳——母亲腹中锡兰的心跳）——"是告别吧……也是重逢！"
- **与赫尔曼和解**："作为赫尔曼·道尔科斯的女儿，我还是要说——爸爸，辛苦了"；赫尔曼讲述芭芭拉（"我忙碌于那些有关哥伦比亚和维多利亚的繁重外交工作，却从来不敢让人知道自己的妻子恰好来自维多利亚"）
- **感染者收治中心计划**：应对哥伦比亚法律施压（感染者须缴医保否则入拓荒队）——锡兰提议拓荒区方案/借罗德岛资源建**感染者治疗中心**（"为了黑，也为了更多无辜的人。我可不只是需要你照顾的人，我也会用我的方式来保护汐斯塔"）；结局在汐斯塔筹备收治中心（招埃尼斯留下——埃尼斯选择去罗德岛）
