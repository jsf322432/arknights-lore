# 雅拉 / 玛丽安娜·布莱克（Yarra / Marianna Black）

- 阵营：莱茵生命（人事科主任，已退休）；前梅兰德基金会特工（代号"**晨星**"）；前蓝卡坞传奇影后（艺名"**玛丽安娜·布莱克**"，本名"雅拉·布克·威尔森"）｜种族：？（前影星）
- 首次登场：活动《孤星》（act25side）；活动《红丝绒》（act43side，身份补全）
- 关键信息：
  - **蓝卡坞传奇影后（重磅身份补全）**：息影几十年的"无法逾越的高山"（"玛丽安娜女士凭一部二十八天拍成的影片包揽蓝卡坞电影节各类奖项"）；《在永夜里燃烧的晨星》拍摄时**主动走向天灾与风暴对戏**（"摄影机记录下了你与风暴擦肩而过的画面……你也是主动走向前与它对戏的呢？"——米兰妮之问）；息影发布会宣布转幕后（"它会仅仅是'玛丽安娜'，留给影迷朋友的最后的礼物"）；"息影几十年，'玛丽安娜'这个名字对我来说已经有些陌生了"
  - **前影星/梅兰德"晨星"**：负责保护/监视科学家（莱特夫妇、克丽斯腾）；"这二十年来，哥伦比亚变得很快"
  - **看着克丽斯腾长大**："当我注视着克丽斯腾的时候，我看不见那个高深莫测意气风发的莱茵总辖，我看见的只有……那个倔强的怎么都不肯低下脑袋的孩子""我和她，我们或许都没能走出过二十多年前那一天"（莱特夫妇坠机日）；"我从来没有成为过母亲。但是我有一个孩子。"
  - **《孤星》中**：救下赫默（赠武器/放行）；阻止赫默追踪克丽斯腾（"作为克丽斯腾的……家人，我依然不会让你通过"）；与赫默的伦理之辩；**结局**：退休离开莱茵（"我恐怕追不上她了"）
  - **《红丝绒》中（蓝卡坞）**：帮助《杜邦夫人》破例入选"另类电影节"（"我只不过是看了那段在天灾中的表演，觉得如果它不能被观众看到，实在是太过可惜"）；与米兰妮和解相拥（"到头来，还是很难说赢过了你啊！"）；"展映会结束后，我还得跑一趟特区，去见见副总统阁下"（与哥伦比亚线衔接）
  - 蒂比的"雅拉奶奶"（爷爷是雅拉曾经最好的合作伙伴/多年好友）
- 经典台词："一个科学家对自己的实验对象产生感情，她就不再仅仅是一名科学家了，不是吗？""我从来没有成为过母亲。但是我有一个孩子。""当初，你拍摄《在永夜里燃烧的晨星》时也遭遇了天灾……那究竟如你在发布会上所说，是一个意外，还是你也是主动走向前与它对戏的呢？"（米兰妮之问——雅拉未答）
