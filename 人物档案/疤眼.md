# 疤眼（"疤眼" / 独眼巨人）

- 身份：卡兹戴尔地下悬空聚集地"**疤痕商场**"的首领（独眼巨人，戴面具）；预言者（"我能'看到'"未来）
- 首次登场：活动《巴别塔》（act33side，1030 年）
- 关键信息：
  - 疤痕商场：雇佣兵中介→城镇（"有太多人融入不了那些充满力量崇拜和血统论的王庭社会"）；奴隶交易/委托/情报生意；"我从不和输家合作"
  - 与双子（特蕾西娅/特雷西斯）六十年交情（"祖父吹嘘曾与您交手"）；为军事委员会背书（"混乱会让我们变得更强大"）
  - 预言观："预言法术的本质不过是推测和计算，当然没什么无法违逆的命运"；自称在"塑造预言"（"我想要塑造预言"）
  - **预言阿斯卡纶**（"弑君之刀剑，诛王之枪矛"）；1094 年夺城战前拦截阿斯卡纶（试图"拨动命运"），面具被击碎
  - **结局**：死于自己布置的伏兵之手（"命运没有杀死他。确实。他做到了逆转预言。然后他死在了自己亲手搭建的舞台上"）
- 经典台词："被言说的仍需辨别，被辨别的仍可更改——预言法术的本质不过是推测和计算。""看穿未来并不容易，但是看穿你接下来的动作算不上困难。"
- 信息来源：活动《巴别塔》（01/02/05/08/08_end）
