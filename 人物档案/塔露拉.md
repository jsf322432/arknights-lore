# 塔露拉（Talulah / 塔露拉·雅特利亚斯）

- 种族：德拉克（龙）｜身份：整合运动前领袖（第八章后被捕）
- 家人：父亲**爱德华·雅特利亚斯**（魏彦吾结义兄弟，20 年前死于龙门）；母亲为魏彦吾之妹（忧郁而终）；**陈（晖洁）是她的妹妹**；养父/师**科西切**（黑蛇公爵）
- 挚友：**阿丽娜**（感染者教师，死于被弃感染者之手）
- 首次登场：第一章（提及）/第四章（正式）；第八章完整前史+决战
- **完整前史（第八章）**：
  1. 科西切养女/继承人——被灌输"魏彦吾杀了你父亲"的谎言；以自染矿石病反抗；**亲手杀死科西切**（但被种下意识转移诅咒）
  2. 隐居乌萨斯小村（老夫妇收养）→ 北原组织感染者队伍 → 与霜星不打不相识 → 与爱国者合流游击队 → 收留浮士德（萨沙）/梅菲斯特（伊诺）
  3. **阿丽娜之死**（被失信感染者劫杀）——背尸穿雪原，无意识焚毁沿途一切
  4. 皇帝内卫当众揭穿其身份 → 队伍信任崩塌 → 烧村复仇（村民饿死感染者）——**"我恨你们"**——科西切诅咒发芽
- **第八章决战**：被科西切意识操纵；阿米娅与陈将其拉回——"我已经不再是你了，科西切……我可是火。我的火会把你我一同烧穿"；交出真正停城钥匙；被陈逮捕："我还不敢死去。我要活着，要活到我有资格为他们殉死。"
- **第十三章（整合运动维多利亚线）**：随 Guard/九的队伍在维多利亚活动，作为"**旗帜**"——"我是旗帜，你们必须在维多利亚挥舞的旗帜……我接受""我是罪人……把我当作你们的工具吧"；引陈之言"等到能够公平地审判感染者的那一天"——"我会等。在那之前，把我当作你们的工具吧"
- 与九的对话：感染者的移动城市不应只是"临终关怀中心"；"我们不能只是在结局等待"
- **第十七章（泽尔格勒）**：率整合运动（雷德等）潜入泽尔格勒调查感染者失踪（"我不相信乌萨斯关于这一切的说辞，所以必须要知道他们到底想对感染者做什么"）；与**图林**（北原矿工领袖）结盟（"我很喜欢'整合运动'这个名字……我们是同行者"）；提及**叶莲娜**（霜星）在北原游击时遇到的重要的人（图林旧识伏笔）
  - 攻入"燃料工厂"：救出被玻璃罐分解的感染者（"他们还有得救，先关了总闸"）、焚毁工厂（"这场属于感染者的漫长徭役，在此刻终止"）；突袭石墙、掩护民众撤离
  - **与弑君者和解**（17-15）："我必须要向你道歉……我只是想做到那些我曾经没有做到的事"；弑君者："你必须去做到你曾经没能做到的事。"——"我会的。"
  - **《生于黑夜》（切城事件前）**：接见渗透整合运动的萨卡兹佣兵（"欢迎你们。远道而来的战士"）；伊内丝察觉其异常——"**两个影子**……一座废墟，古老，强盛"（**科西切附身伏笔**，早于主线第八章）；"她在葬送整合运动，刻意的"（伊内丝评）；整合运动受摄政王/赦罪师暗中渗透（"被过度操纵的战争阴谋"）
- 经典台词："我怜悯你。你的死只证明了你的孤独。""感染者会为你辟开别样的领土。"（早年）/ "我已经不再是你了，科西切……我可是火。""我还不敢死去。""我会等（公平审判的那一天）。在那之前，把我当作你们的工具吧。"
