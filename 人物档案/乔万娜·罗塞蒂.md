# 乔万娜·罗塞蒂 / 卡特琳娜（Giovanna Rossetti / Katrina）

- 阵营：罗塞蒂家族（首领）｜种族：（鲁珀/哥伦比亚家族领袖）｜身份：《德克萨斯之死》剧本作者（笔名卡特琳娜）
- 首次登场：活动《叙拉古人》（act21side）
- 关键信息：
  - **罗塞蒂家族首领**：哥伦比亚家族回流叙拉古的领袖（带回移动城市技术——"几乎在免费为叙拉古建造新的移动城市"）；自居萨尔瓦多雷·德克萨斯的接班人（"乔万娜花了多少力气才将剩下的哥伦比亚家族重新统合起来"）；持有西西里夫人的信物项链
  - **与切利尼娜的旧友**：1080 年合影（"乔万娜与切利尼娜，摄于1080"——萨尔瓦多雷将孙女寄养萨卢佐时期）；"当年的清算，如果不是某个家族把她保下来，她绝无可能活下来"；"德克萨斯，切利尼娜·德克萨斯"（对贝洛内找回德克萨斯的执念）
  - **《叙拉古人》**：以笔名"卡特琳娜"创作《德克萨斯之死》（三幕剧：拓荒/奋斗/陨落——"第三幕尚未完成"）；与空（企鹅物流）成为朋友；在剧院与德克萨斯重逢（"我是来杀你的""好久不见，切利尼娜"）——试图让德克萨斯加入罗塞蒂（"我们可以一起重新开始"）被拒（"乔万娜，我们都太念旧了"）
  - **被瓦拉赫刺杀**（差心脏几厘米）："我始终觉得，有些事应当适可而止""我们是既得利益者……我们不能忘记，有些事是我们不能做的"；瓦拉赫夺权（"从现在起，你就是罗塞蒂的首领了"）
  - **结局**：留下《德克萨斯之死》第三幕剧本（"你是如此自由，切利尼娜。没有人能够定义你"）后离开；筹备新作《叙拉古人》；将西西里夫人的项链（可能转交）
- **《新沃尔西尼狂欢节》（回归）**：伤愈归来（"我养好了伤，也收集了不少新灵感，自然是要回来的。曾经的美好时光已经不在，但不代表我们不可以创造新的更美好的故事"）；以**卡特琳娜文化公司**赞助 Sora（空）第二轮叙拉古全境巡回演唱会（"你没有注意到本轮的赞助商里新增了'卡特琳娜文化公司'吗？""她也是我的朋友啊，你带给我的新朋友"）；与德克萨斯重逢（"这个时机是不是刚刚好？你看起来也做了新的决定""我们以后要换一种方式相处了"）；申请资料与德克萨斯的一起提交（留在新沃尔西尼）
- 经典台词："我是来杀你的""好久不见，切利尼娜。""没有人能够定义你。""我总是在思考一个盛大的落幕……让她成为这个故事中，最不像叙拉古人的叙拉古人。"
