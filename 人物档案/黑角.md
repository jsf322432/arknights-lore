# 黑角（Noir Corne）

- 阵营：罗德岛（A4 行动组组员）｜种族：（鬼族）｜形象：角盾卫/太刀使；憨厚热心；与夜刀形影不离
- 首次登场：活动《眠于树影之中》（act24side，详细展开；此前为罗德岛基础干员）
- 关键信息：
  - **A4 行动组组员**：与组长夜刀搭档（"俺俩都跟着博士干那么久了"）；前杀手（与夜刀同期脱离——"也是那天我遇见了黑角，他听了我的话，也不做杀手了"——夜刀语）；以"保护他人"为使命加入罗德岛；骂醒夜刀："过去就是过去……你所有的悔恨，所有的罪孽，就用全部的未来去弥补吧"。
  - **《眠于树影之中》**：勘察/采样主力（"空气检测、土壤采样、生物采样……十七个采样点，二十三份样品"）；读《源石虫都能读懂的泰拉生物百科》（薄绿推荐）——水蝇幼虫线索发现火龙爪痕；关心老猎人柏生义冈的状态（"俺很难不在意柏生家老爷子的状态……就和那时的……"）；被艾露猫们捉弄（臭羽兽蛋/钓鱼恶作剧）；决战中学**太刀"气刃兜割"**（随从艾露猫传授）斩断火龙尾巴；与夜刀讨论是否杀火龙（"俺觉得，既然已经不构成威胁了，它也不是故意要袭击人的……"）。
  - **战力**：盾卫（举盾挡兽潮/龙尾）+太刀（居合/气刃兜割——"以气御刃，命中敌人以练气，才能爆发出更强的威力"）；与夜刀的默契（"踏在盾牌上的刹那……我的身躯高高跃起"）。
- 经典台词："俺在努力。""俺记着的。""过去就是过去……你所有的悔恨，所有的罪孽，就用全部的未来去弥补吧。"（对夜刀）"俺觉得，既然已经不构成威胁了，它也不是故意要袭击人的……"
