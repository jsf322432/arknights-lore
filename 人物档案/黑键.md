# 黑键（Black Key / 弗朗茨·乌提卡）

- 身份：**乌提卡伯爵**（巫王末裔）；罗德岛干员（矿石病感染者）；大提琴手（"黑键"）；"尘世之音"宿体
- 首次登场：活动《沃伦姆德的薄暮》（act11d0，提及乌提卡伯爵）；活动《崔林特尔梅之金》（act29side，主线登场）
- 关键信息：
  - 血脉：巫王赫尔昏佐伦的唯一末裔（"你未有子嗣，我不过是你的末裔，你我共有乌提卡这一姓氏"）；母亲是巫王残留血脉（"死前将你托付给了她的同伴，一位巫王的旧臣"——皆死于女皇之声之手）
  - **"尘世之音"**：巫王残党（格哈德/格特鲁德等）植入他脑中的旋律（以为能召唤"始源之角"——实为误解/杂音）；十多年来头痛/幻听折磨（"那东西还在我的脑子里……这首曲子还远远没有结束"）；被弗莱蒙特取走后"问题解决，但疼痛依然如影随形"（心结）
  - 沃伦姆德/维谢海姆：因"尘世之音"被利用（格特鲁德·斯特罗洛差点炸毁音乐厅；兄弟/挚友白垩之死——"我们的相遇是被格特鲁德利用的"）；逃离莱塔尼亚入罗德岛
  - 《尘影余音》（维谢海姆）：被格特鲁德召来参加车尔尼告别音乐会（化名"黑键"）；与流浪大提琴手**白垩**组队合奏——白垩即幼年替他承担尘世之音实验的另一个孩子（"我是听了你的大提琴之后才想起来的……如果当年，我再勇敢一点，也许你就不用……对不起"）
  - 尘世之音真相：巫王抛弃的旋律断片（"尘世之音"）；与白垩的共振加剧白垩损坏尘世之音的泄漏（夕照区"假愈"之源）；格特鲁德欲以共振转移其尘世之音再杀死白垩（"乌提卡伯爵死而复生"的舆论棋）——黑键拒绝（"我还没疯到用一整个地块的感染者换自由的地步"）
  - **《光影》与白垩之死**：车尔尼倾尽生命作三重奏《光影》牵引尘世之音；白垩抢先成为容器（异变为"巫王"怪物），黑键在芙蓉与爷爷掩护下击碎其源石外壳——白垩死在他怀中（"今天，我会死去，而你——将重生！"）；黑键在战斗中感染矿石病，带走白垩的大提琴、留下自己的长笛
  - 结局：官方宣布"乌提卡伯爵死亡"（平民黑键护照）；烧掉死亡证明与匿名信（"很符合我对她的印象"——格特鲁德）；成为罗德岛干员（芙蓉送来干员手册；车尔尼："从来到罗德岛的第二天开始，我就完全见不到他了……按照莱塔尼亚的官方口径，他确实已经死了"）
  - 《崔林特尔梅之金》：被密信召回崔林特尔梅（"乌提卡领的几十万人……我还没有自私到为了所谓的自由牺牲这么多人"）；被洛里斯所救（"我又又一次浪费了别人的勇气"）；与莱辛同行（挑战→同伴）
  - **荒域直面巫王**：巫王带他重走乌提卡伯爵塔的阶梯（"阶梯存在的意义，即是让你走向高处"）；战胜内心敌人（"你的敌人是谁？""是我自己"）；巫王"摸了摸他的头"——"你战胜了你的敌人，突破了困住自己的那座高塔"；黑键 19 年来第一次忘形大笑
  - 结局：赫琳玛特赐"死亡证明"（自由）或重回乌提卡领——**选择重回乌提卡领**（"这是我的耻辱，我的囚笼。这是我的责任，我的义务。这是我的路。"）；向罗德岛提交离舰申请（芙蓉劝其亲自见博士/凯尔希）
  - 与白垩（大提琴）："我和他的一生，痛苦、喜悦、绝望……都是别人给的。如果连希望都是的话……"；荒域坠入虚无时看到白垩的笑容（"那是一个笑容。一段琴声。一抹……希望。""命运总是从我们身上夺走很多东西，幸好，我还拥有爱与恨的能力"）
- 经典台词："我试过了。我一直在试。我从未停止过反抗。""我会再次改变它，但绝不以你的手段。这是我嘲弄你的方式。""没什么意义的话，就别说。我没打算把命交给任何人。"
- 信息来源：活动《沃伦姆德的薄暮》；活动《崔林特尔梅之金》（全文）；《尘影余音》（白垩/格特鲁德前史）
