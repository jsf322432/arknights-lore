# 赫尔昏佐伦 / 巫王（Helhedron / 奥托·迪特马尔·古斯塔夫·冯·乌提卡）

- 身份：莱塔尼亚前任君主/"巫王"（23 年前被双子女皇杀死）；乌提卡家族末代君主；荒域"帕维永"之主；弗莱蒙特的挚友
- 首次登场：活动《崔林特尔梅之金》（act29side，荒域正式现身；此前为背景传说）
- 关键信息：
  - 生平：即位前乌提卡伯爵（"曾以乌提卡之名改变莱辛家族命运"——废除扈从制度）；**以一己之力改写金律乐章**（剔除叙拉古声部——"他意识到金律乐章必须更新……新生的乐章才能将剩下九个大区重新系在一起"）；战胜科西嘉一世（四皇会战——源石风暴吞噬高卢陆上舰队）；建"始源之塔"（莱塔尼亚最高建筑）；晚年疯狂（"这让我成为最险恶的梦魇，让我成为自由的叛徒，让我成为……暴君"）
  - **真相（荒域独白）**：执掌"湮灭之始和混沌之源"逼迫源石揭示本质——"它说万物始源，也是造物。它说创造之初，也有主宰。它说希望已经逝去，永恒已经消亡"（**前文明/造物者伏笔**）；"造物者残忍，造物者邪恶，造物者狡黠。祂无法消灭意志，但能够让意志脆弱……""如果连根源也是桎梏，那也必须有人连根源也一同征服……那造物者也必须先于万物灭亡。"；"真相不应只有一人知晓，事实不应只有一人见证"——这就是他成为暴君的原因
  - **帕维永（荒域行宫）**："人类千万年来无法计量的牺牲累积起来的所有……帕维永是人类意志凝结的丰碑"；混沌（实在的另一面）包围着它；他穷尽毕生之力在混沌中"吹出一个不稳定的泡泡"
  - 与弗莱蒙特：曾将命结借予他研究荒域（巫王早已归还——"我不是早就还给你了吗？""死亡不会追上你，它只是追上了我"）；被弗莱蒙特"放逐"送别（"你只是来道别吗？弗莱蒙特啊，我的挚友。这座高塔，为何仍如此矮小……"）
  - 与黑键：荒域中平静地带领末裔重走乌提卡阶梯（"阶梯存在的意义，即是让你走向高处"）；考验其"敌人是谁"（"很好，弗朗茨。你战胜了你的敌人，突破了困住自己的那座高塔"）
  - 与阿尔图罗：点破她的"唯一真实"（"你将自己变成了容器……你无比接近，混沌"）；拒绝求证（"我不会回应你的求证。而此时此刻，我允许你见证我的终局"）
  - **遗言**：被双子再杀前——"你们必须抵达我无法抵达之境，你们必须实现我未实现之愿景。就算希望逝去，就算永恒消亡。亦只是赫尔昏佐伦的绝响与终局。莱塔尼亚，必将比希望更加璀璨。莱塔尼亚，必将比永恒更加漫长！"；阿尔图罗拼凑的"巫王遗言"=**"危机近在眼前"**（"我们的始源也是终点，我们的能力即是桎梏"）
  - **尘世之音（《尘影余音》）**：巫王**抛弃的旋律断片**——"宫廷乐师们将他一时兴起，信手拈来的旋律一一记录……这些断片被命名为尘世之音"；蕴含独特力量但无法普遍应用（双子女皇明令禁止研究）；残党以此做血裔容器实验（黑键/白垩为幸存者）
- 经典台词："我不顾忌，亦不怀疑。我不惧魔鬼，亦不惧成为魔鬼。""永恒……不更不易，不移不改。但永恒不等于不朽。不朽，在于'更新'。""我永不停止，这是我与历代先贤的区别。这就是我的'不朽'。""造物者必须灭亡。虚无不会是真相，虚无绝不该是真相。我绝不容许，我绝不原谅。"
- 信息来源：活动《崔林特尔梅之金》（全文）；《沃伦姆德的薄暮》（背景）；《尘影余音》（背景）
