# "歌唱家"（The Singer / 作家）

- 阵营：深池（高层之一）→独立（酒馆作家）｜种族：（塔拉人）｜身份：深池"歌唱家"；故事的讲述者（活动叙事框架）
- 首次登场：活动《淬羽尘黯》（act41side，作家框架）
- 关键信息：
  - **深池高层**：庆功会中留在原位的深池之一（"歌唱家"）；"他专门挑了人员已经开拔……的时候告发，这样就既不用得罪'雄辩家'他们，又不能算知情不报"（小丘郡——向爱布拉娜告发"雄辩家"挟持拉芙希妮）；从黑林逃脱（"好容易从黑林里逃出来，都已经走到了旧王城的遗址"——被歌声引回遗迹熔炉）；"最后一位深池"（爱布拉娜语）。
  - **作家**：在塔拉荒村酒馆讲述纳斯尔纱故事的人（"观察、灵感、写作过程中废掉的文本，我会一股脑抛出来"）；写不出结局（"我写不出结局""我看见的、我相信的、我说出口的，彼此全都背道而驰"）；受西莫·威廉姆斯（塔拉诗人）影响（"从我第一次读到那个名叫西莫·威廉姆斯的诗人写的句子开始，我就一直是塔拉人"）；对库林有特殊感情（"这位铁匠和我根本没打过几次照面。他只是城中混乱的第一个牺牲品"）。
  - **结局（被揭穿）**：与"神秘女性"（=爱布拉娜/死芒）对谈——被揭穿身份（"你不是拉芙希妮，你是——爱布拉娜？！"）；坚信的故事破灭→**失语**（"你失语了……仅仅是因为某些坚信着的东西刚刚忽然破灭了吧"）；"再见，'歌唱家'——不，'作家'。再见，最后一位深池。"
- 经典台词："故事是火映在墙上的影子，而不是火焰本身。讲故事的人需要牢记这一点，不然只会被火焰焚身。""我写不出结局。""非要把故事给一个结局的人是你，不是我。"
- 信息来源：活动《淬羽尘黯》（全文）
- 后续：失语（留在酒馆——"作家"）；深池的终章（"最后一位深池"）
