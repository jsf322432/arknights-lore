# 明椒（Mint）

- 种族：萨卡兹｜身份：年轻雇佣兵（原哥伦比亚佣兵队）
- 首次登场：第十一章「淬火尘霾」
- 关键信息：
  - 父母皆佣兵（已死），由姥姥带大；"许多地方都不欢迎萨卡兹，我就只好也来当佣兵了"
  - 原在哥伦比亚替"见不得光的商人押送货物、猎杀野兽"；随队来到伦蒂尼姆才知要占领城市
  - 导师**格林**（爱抽烟的老雇佣兵）战死；凯瑟琳把格林藏在烟盒里的毛线指套交还给她（格林临死把烟盒给了凯瑟琳当烟钱）
  - 被队长逼着第一次杀人（处决凯瑟琳）——"我做不到！"；与雇佣兵队一同被费斯特的工人+罗德岛俘虏
  - 对战争懵懂："我们只是收钱办事……萨卡兹的王说，我们可以有个归处，可以被统治，可以找到未来。"
  - **第十二章**：因放走十一号军工厂工人（凯瑟琳等）被**曼弗雷德逮捕**并带在身边"学战争"；在飞空艇上服役，暗中为封锁区（经考伯特/日落街酒店）送物资；被伊内丝劫持问话（"我常常觉得，自己不应该在这里"）
  - 向伊内丝了解卡兹戴尔（"那里是萨卡兹的家"）——伊内丝："所有没去过卡兹戴尔的萨卡兹都以为那里大概是个可爱又甜蜜的小窝……放大一百倍，那就是卡兹戴尔"
  - **第十三章**：任萨卡兹运输小队队长（随"司机"/"矿工"/"老财"等巡修法阵）；被 Logos 征用车辆（"真正被俘的，是我们"）；"我会保护他们的安全……这是我对曼弗雷德将军的承诺"；与阿米娅并肩对抗血魔造物（"我太熟悉王庭军的那群家伙了，你们给人的感觉完全不同"）
- 经典台词："格林告诉过我，对我们雇佣兵来说，生离死别是很正常的事。""我……我才不……"（指套）"我只是看到，老面孔们一个个死掉，新的面孔很快就会顶替上来。"
- 信息来源：第十一章（11-08）、第十二章（12-06/12-07/12-13/12-17）、第十三章（13-04/13-13）
