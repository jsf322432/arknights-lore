# 图利娅（Tulia / 已故）

- 身份：**阿戈尔航道计划数据员**（前生态艺术家——培育濒危深海藻类）；海嗣化后死亡
- 首次登场：活动《生路》（act34side）
- 关键信息：
  - 前职：生态艺术创作所（火山能源站濒危植物繁育基地——被海嗣吞没后转岗）；"这些原始藻类是整片海洋里最简单，却也最顽强的生命"
  - 死亡真相：发现**信标数据异常**（"有人利用航道，信号"）→告知卡西娅（被灭口）→从城市边缘排污口坠海→**吃下异种血肉海嗣化**只为回城救海藻（"她吃下了异种的血肉"）
  - 临终：以海嗣形态抱着植物营养液回到水培试验田（"她选择留下来，或许只是因为她知道，随生态艺术创作所迁去其他城市，并不能真正救下这些逐渐在海洋里失去容身之所的生命"）
  - 结局：被西昆妲亲手处决（"她的旅程结束，她的家乡近在眼前。她选择在此间睡去"）——海嗣体液未溅到水培箱（"那些海藻只是摇曳着，安静地呼吸着"）
- 经典台词："它们与海洋同岁，是这颗星球的活化石。""我没办法直接去斩杀海嗣……但我不能看着它们就这么枯萎在这里。"
- 信息来源：活动《生路》（全文）
