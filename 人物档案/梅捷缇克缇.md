# 梅捷缇克缇 / 缇缇（Metjeteti / Titi）

- 阵营：米纳特哈玛仪（法尔贾万达巴德博物馆副馆长）｜种族：（萨尔贡人）｜身份：文物修复师（源石技艺辅助）；佩佩/阿娜特的挚友
- 首次登场：活动《太阳甩在身后》（act35side）
- 关键信息：
  - **副馆长/修复师**：用源石技艺辅助修复文物（"桌台上还残留着一些类似树脂的金色物质，那是缇缇使用源石技艺辅助修复文物的痕迹"）；从哥伦比亚博物馆（商业运营）转来米纳特哈玛仪（"米纳特哈玛仪的博物馆又不用挣钱"——"我乐得清闲"——实则怀念忙碌）；爱唱歌（古歌谣）。
  - **《太阳甩在身后》**：给佩佩通行证（"再帮你尝试一次，如果到最后，你还是一无所获，就不要再执拗下去了"）；发现云兽雕像消失/古尸从柜子里出来（"你怎么从柜子里出来了！"）；米奥吐宝石给她（第三颗宝石——"它给我吐了一块幸运的宝石哦"）；与阿娜特的争执（"我只是想让她不要放弃特展啊"）；解开构装体谜题（与阿娜特一起——"匹特拉姆"冶炼技术等）；结局继续博物馆工作（处理修复/投资者）；**米奥指定她为"饲养员"**（米奥跟随她）。
  - **性格**：乐观/随性（"无论我们展出什么，都会有人挑刺的"）；"我的通行证在昨晚和今早都留下了不该有的访问记录……胡说，我的记录明明抹得干干净净！"
- 经典台词："看你们争来夺去这些年，我也是腻味了。""我只是想让她不要放弃特展啊。""大胆去吧，讲错了也没关系，不管不顾继续说下去就好！"
- 信息来源：活动《太阳甩在身后》（全文）
- 后续：博物馆副馆长（米奥同行——兽主饲养员）
