# 扎罗（Zaro）

- 阵营：狼之主（兽主）｜种族：兽主（"从狼群中走来的兽主"）｜形象：巨狼（黑雾化身）
- 首次登场：活动《叙拉古人》（act21side）
- 关键信息：
  - **狼之主（兽主）**："不同于这片大地上的一切生物，他们从未诞生，他们只是显示他们的存在""狼之主不死不灭，兽之主不死不灭"；与同胞们站在荒野上见证狼群足迹（"扎罗，是从狼群中走来的兽主"）
  - **"獠牙"游戏**：狼之主们制定游戏规则——每头狼之主挑选一个人类培养，人类互相狩猎，拥有不曾折断的獠牙的狼之主就是头狼；**贝纳尔多·贝洛内是其獠牙**（培养六十八年——"你的父亲，是我最为满意的獠牙"）
  - **唯一与人类社会有联系的狼之主**（"他认为，人类的权力，也是一种力量。用这份力量战胜其他狼之主，亦是一种胜利"）
  - **与德克萨斯的交易**（七年前）：放她离开哥伦比亚（"荒野一向公允"）——《叙拉古人》中上门讨债（"你要跟我回叙拉古，你要协助我的獠牙"）
  - **与大帝**："大帝，我可悲的同胞"（同为兽主；大帝已融入人类社会）；"我们终究属于荒野"
  - **《叙拉古人》**：被贝纳尔多背叛（饮毒自尽——"他竟敢以自尽来葬送我的胜利"）；违反狼之主规则现身干涉凡人之事（"我要让他的血脉从此断绝于这片大地之上"）；被大帝召唤的其他狼之主压制（"他破坏了规则……你失败了，而且，败得很彻底"）后退场（"他选择向未知放下尊严"——st04 中与拉普兰德战斗三个月后选择与其同行？注：st04 幕间显示扎罗在荒野与拉普兰德战斗后"向一个人类伏下身躯，选择与她同行"）
- **《新沃尔西尼狂欢节》（续篇）**：与拉普兰德同行（拉普兰德开出租车载他——"这一轮的游戏即将结束，不要让我失望，拉普兰德""我们的斗争会持续千年万年"）；向恺撒揭穿最后獠牙（翁贝托·德蒙塔诺）的下落（"我唤你来此，是为了向你分享一个有趣的秘密——最后一位尚未现身的獠牙，到底藏在哪儿""局外人恰恰最喜欢看戏"）；"依靠贝纳尔多的影响力，在叙拉古社会里找到一个叙拉古人，就像风翻出藏在荒草堆里的小动物一样简单。我不帮他们，这一轮游戏不知道又要拖到几时才能结束！"；狼群决议（游戏分出胜负前狼之主不得插手）；结局——众狼之主认拉普兰德为头狼（"我有种预感。接下来我会度过有生以来最开心的一段时光"）；"权力，显而易见。"
- 经典台词："获胜的方式多种多样，这是我的选择。""我们终究属于荒野。""人类的权力，也是一种力量。""权力，显而易见。"
- 信息来源：活动《叙拉古人》（全文）；活动《新沃尔西尼狂欢节》（全文）
- 后续：与拉普兰德同行；狼之主"新游戏"（认拉普兰德为头狼）
