# 米夏埃尔（Michael / 赫琳玛特的专属密使）

- 身份：鲁珀少年；**莱塔尼亚女皇赫琳玛特的专属密使**（自称"女皇之声"但未获敕封——"女皇之声同时服务于两位女皇。而我只属于赫琳玛特"）；低音号手
- 首次登场：活动《崔林特尔梅之金》（act29side）
- 关键信息：
  - 出身：鲁珀坎/叙拉古毗邻地区（"我带着家族使命降生，这个词语从来就和我没有关系"）；七年前来崔林特尔梅觐见女皇（"伊维格娜德不喜欢我的演奏、我的谨慎，或者说我所代表的鲁珀坎……是赫琳玛特救了我"）
  - 职务：赫琳玛特的密使（"城里的事，你继续盯着"）；与费德里科合作（"我们目标暂时是一致的"——监视阿尔图罗/查残党）；用"女皇的旋律引路"
  - 《崔林特尔梅之金》：被赫琳玛特解除身边职务（"是时候放你离开了"）；赫琳玛特留荒域后代掌文书（"总得有人代为处理那些堆积如山的文书"）；坚信"那可能是一个不再需要高塔的时代"
  - 结局：与费德里科完成阿尔图罗移交手续（双边协议）；"费德里科先生，无论我在拉特兰还是在罗德岛，你都可以来找我"（费德里科）
  - 与赫琳玛特：低音号（"你得吹响我的号。我得告诉金律法卫，所有人都得救了"）；使命——"将一切对莱塔尼亚的威胁扼杀在起点"
- 经典台词："我们没有办法选择自己的出身，但至少应当能选择什么时候转过身去。"（赫琳玛特之语）"我宁可多想想我的玛尔塔。"（玩笑）
- 信息来源：活动《崔林特尔梅之金》（全文）
