# 凛冬（Зима / Sonya / 索尼娅）

- 身份：**乌萨斯学生自治团首领**（"冬将军"）；罗德岛干员（先锋）；本名索尼娅
- 首次登场：故事集《乌萨斯的孩子们》（act10d5）
- 关键信息：
  - 切城封锁期：公立高中学生（"公立高中里没人是她的对手"）；保护被欺凌者（"我只是看不惯这些人仗着自己人多有力气就欺负别人而已"）；收留安娜（真理）一行人，成立**乌萨斯学生自治团**（首领）
  - **第二场大火**：夜袭贵族据点（想"从根本上消除安娜的烦恼"）——打翻烛台点燃（"我点燃了第二场大火"）→粮食点尽毁→校内彻底混乱——**负罪感**（"我不仅没有打消安娜的烦恼，还让她的愿望落空"）
  - 噩梦自我审判（"你有罪""我没有"）；父母死于切尔诺伯格（"我的爸爸妈妈都死在切尔诺伯格了"）——不回乌萨斯
  - 与娜塔莉娅（早露）和解（"我觉得你做了你能做的事"）；与真理的隔阂与默契（"凛冬，我依然愿意相信你。但我却不知道该怎么和你说话"）
  - 罗德岛：前线干员（临光带新人小队——"外露的暴力是一种保护壳"）；"总有一天我也要当队长对你发号施令"
