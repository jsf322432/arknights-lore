# 迷迭香（Rosmontis）

- 阵营：罗德岛（**精英干员**，歼灭战专员）｜种族：菲林（猫）｜14 岁
- 首次登场：第七章「苦难摇篮」（7-1 生物处理室；6-2 回忆已提及）
- 能力：无形巨力（精神塑造的"无法被观察的形体"，可抓握/挤压/切割）；远程操控武器（"EX-42"等）
- 关键信息：
  - **诞生于研究所的感染者**：实验体，法术与精神状态相连——曾"一点一点碾碎整个研究所"；被秘密转交罗德岛（对外宣称"迷迭香并不存在"）
  - **记忆问题**：靠便携终端记录记忆（"六年前到去年的记忆我都记在这里"）；会忘记（Scout 之死等），但情感残留
  - 与 Ace/Scout 亲如家人（"我想看看 Ace 和 Scout 一直在说的你是什么样子"）；为确认他们的死而参战
  - 战斗残酷但克制（"我已经很久没捏死过人了"；凯尔希：其战术旨在解除战斗力，很少击杀）
  - 与阿米娅互相支撑（"不要怕我""我不害怕迷迭香"）
- 经典台词："你好，霜星……拜拜。""我绝对不会忘记任何一个人的死。""我不要你们留在我的记忆里。""你对我来说什么都不是，只是一名罪犯。法律和监狱都做不到的事，我来。我宣判你的死刑。"
- 信息来源：第六章（提及）；第七章 7-1~7-17；活动《孤星》（全文）

## 活动《孤星》补全（重大进展）

- **本名纳西莎（Narcissus）**：洛肯·威廉姆斯之女/实验体（"洛肯水箱"——国防部资助的人体实验：为纳西莎与"哥哥们"植入施术单元/源石技艺改造）；"哥哥们"死于实验（"我死去的兄弟在手术台上哭泣……从来都没有什么花园。有的只有残酷的囚禁、切割、摆弄我们生命的樊笼"）；纳西莎觉醒后**毁掉实验室**；梅兰德夺走她转交罗德岛（罗德岛档案"迷迭香"——"她唯一的名字是迷迭香"）
- **记忆恢复**：收到洛肯的信（"纳西莎"称呼/抚养院/花/土豆汤的回忆——"你曾经对我很好很好，但你突然变得很坏很坏"）；靠终端记录记忆的习惯源于创伤（"我把所有不想忘记的事情都记在了终端上"）
- **暴走与挽回**：在洛肯面前回忆涌来→精神失控摧毁实验室外墙（"不正确的，我都会毁掉""怪物。武器。毁灭者。"——对自己的认知）；**伊芙利特以"朋友之约"挽回**（"那些好的回忆不该被一起毁掉……可以停下了"）
- **宣判洛肯**：拒绝成为洛肯的工具（"你想借我的手来毁掉你自己，我不愿意。我不是你的武器"）；"我恨你，但阿米娅和博士都说，报复并不能让那些消失了的我爱的人回到我身边"；**"我宣判你的死刑"**（洛肯在万星园实验中死去）
- 与罗德岛的羁绊（"阿米娅和凯尔希医生帮我清理过那些情绪了"；想念 Logos/煌/Sharp/Raidian）
