# 卡夫卡（Kafka）

- 阵营：赫默的朋友（自由职业者/情报通）→ 罗德岛干员｜种族：黎博利（推测）
- 首次登场：活动《孤岛风云》（act15d0，2021）
- 形象：个子矮（"不要叫我小姑娘，我只是个子矮"）；爱玩牌/浑水摸鱼；"场面越混乱我越喜欢"
- 关键信息：
  - **与赫默的友谊**：不打不相识（赫默撞见她用不光彩手段做事，差点断了她那笔生意）；赫默常给她介绍工作（希望她"像她那样正经做事"）；"像赫默这样的只有这一个，我很珍惜她的"
  - **《孤岛风云》**：受托潜入曼斯菲尔德（三个原因：帮赫默/好奇这座监狱/赫默这次很坚定）；作为囚犯进入 B 区（打牌混熟/"给你捎来你老妈的话"）；借打扫 C 区接触安东尼摊牌（"我是受人委托来帮你越狱的"）；策划越狱核心（装晕/偷巴顿钥匙卡/启动塔下沉断电/"越狱这么好玩的事情，我当然要兴奋了"）；与罗宾互为"演技派"
  - 结局：随队越狱成功；与米娜在监狱外汇合
- 经典台词："还不如从一开始就承认自己是坏人啦。"／"做着坏事的人即使有着好的想法，又怎么能被叫做好人呢？"
- 信息来源：活动《孤岛风云》全文 18 段
