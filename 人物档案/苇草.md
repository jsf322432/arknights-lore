# 苇草（Weedy / 拉芙希妮）

- 阵营：深池（"领袖"之一/影子）→罗德岛（干员）｜种族：德拉克（红龙）｜身份：爱布拉娜之妹；小丘郡紫火术师
- 首次登场：第九章「风暴瞭望」（重伤现身）；活动《照我以火》（act22side，全面展开）
- 关键信息：
  - **身世**：德拉克姐妹（与爱布拉娜同父同母）；父母（盖尔王后裔/塔拉德拉克）被阿斯兰刺客暗杀于节日雪夜；姐妹俩被沃里克伯爵（"颂古者"）收留培养（教塔拉历史与仇恨——"他教我们，毁去无辜者的生活，激化塔拉人与维多利亚人的矛盾……他还谋害了落魄的政敌，就像那些维多利亚人，害死我们的父母一样"）；爱布拉娜杀师（毒酒）后带她流浪——"既然你不知道自己的欲望在何处，那就先成为我吧。往后，你与我便都是'领袖'"；"那火焰注视着我，我成为了她的影子"。
  - **小丘郡（第九章）**：深池"领袖"（被推到台前的影子）；紫火术师（"让整条街道变成了灰烬"）；脏弹轰炸中重伤（"我想以死永远摆脱我的身份，所以源石炮弹落下时我没有躲开"）；**Outcast 违背命令救下她**（后 Outcast 为救她/同伴而死——"你让Outcast为救你而死"）；随罗德岛撤离，成为干员。
  - **《照我以火》（重磅）**：独自离开罗德岛追踪深池相关之事（"深池里，有人改变了我的命运……我想试试还能不能从那里扳回来什么"）；搭救塔拉流民（维恩/塞尔蒙/莫兰等——护送穿越石高原野）；被陈认出德拉克（"我不会认错"）；向风笛坦白身份（"我是。……罗德岛救起我之后，我试图为自己的命运扳回什么，所以我踏上这趟旅程，试图抚平一些深池的暴力留下的伤痕"）——风笛失望离去；被菲舍尔（开斯特情报员）/"校官"（威灵顿赤铁近卫队）追猎（重伤）；塔拉王城遗址直面姐姐的幻影（"我不是你的影子。我只是，人们理想中'领袖'的影子""姐姐，我为什么要战胜你呢？"）；**新生之火**（"这终于是我自己的火焰了"——治愈/净化之力；送葬被操纵的亡魂——塞尔蒙的哥哥）；结局"到那一天，我会去见她"。
  - **能力**：德拉克火焰（红龙之焰——"昔日红龙替他的子民流血，一滴血便烧毁整片原野"）；可熄灭/净化爱布拉娜的死亡之火（"她的火光，如此耀眼……你会战胜我吗，我亲爱的妹妹？"——爱布拉娜语）。
  - **性格**：说话声音小（"你说话声音实在太小了"）；习惯说"不"（风笛："你呀，在说到自己的事的时候，才最喜欢说'不'……就好像要费劲摆脱什么似的"）；"我只是不喜欢打劫他人的做法"。
- 经典台词："我不需要寻求死亡，也可以挣脱原本的命运。""（我是。）在小丘郡的时候，我想以死永远摆脱我的身份。""我只是，人们理想中'领袖'的影子。""这终于是我自己的火焰了。""塔拉人应该，在夜晚有一簇温暖的火，在唱起歌谣时杯中有酒。""我们要在寒夜里……拥有一簇温暖的火。"
- 信息来源：第九章（9-11~9-16）；活动《照我以火》（全文）；活动《淬羽尘黯》（全文）
- 后续：塔拉领袖（唯一的德拉克后裔——"拉芙希妮·都柏林"）；与姐姐爱布拉娜（死芒）的"舞"落幕

## 活动《淬羽尘黯》补全（塔拉领袖——重磅）

- **全名**：**拉芙希妮·都柏林**（Loughshinny Dublin）。
- **回纳斯尔纱**：见证塔拉光复后的纳斯尔纱；发现居民被死火（紫火）侵染（"紫色的死火"——腰间的源石灯=紫）；拒绝姐姐"杀死我"（"我不会再成为你的影子，红龙之间也不该像被污蔑的那样，病态地自相残杀"）；发现姐姐的虚弱（"那个等不起的人，此刻就站在你面前呢"——死火散布拖垮爱布拉娜）；"我宁愿将活人身上的紫火看作一场瘟疫……我希望那解药能让你也一并痊愈，爱布拉娜"。
- **还火仪式（"红龙复生"）**：杀死爱布拉娜（棺椁中只有枪/无尸体——空棺）；紫火化为明黄（还火成功——"从幽深的紫，化为明亮的黄"）；"我为了消解你们焚身的烈焰而死，而你们为我哀悼的泪雨浇灭了火焰，让我从死亡的深渊中归来"——**"红龙复生"=自导自演的奇迹**（与爱布拉娜/涅梅丝在堡垒阳台计算好的残局解法）；向居民演讲（"我们铭记，因为我们要给生者以生活的尊严，予逝者以终将重逢的许诺""我们要在寒夜里……拥有一簇温暖的火"）；无限期推迟加冕仪式（对开斯特示好——"塔拉王国"）。
- **塔拉唯一的德拉克**："我，拉芙希妮·都柏林，塔拉唯一的德拉克后裔"（爱布拉娜已"死"）；布莉吉携其介绍信赴罗德岛；涅梅丝担心爱布拉娜复活的故事（"关于红龙的复活，会诞生一个完全不同的故事"）。

## 活动《日暮寻路》补全（伦蒂尼姆围城/命令威灵顿）

- **独自穿战场（重磅）**：银石崖一战后，苇草带塔拉流民（莫兰等）行军至伦蒂尼姆外围；独自穿过战场（救治伤兵——不分萨卡兹/维多利亚/塔拉）赴"加斯特里尔"号；对垂死塔拉士兵（橡林郡——"火已经燃起来了"）："火已经燃起来了，它会吞噬许多东西，但它从不该刻意把生命作为薪柴""士兵，你的战争已经结束了"（守灵人传说——归乡塔拉战士在守灵人送还的火中安眠）
