# 艾莉诺·马奇伯爵（Eleanor，March Countess / "小公爵"）

- 阵营：诺曼底公爵（代表/马奇郡封地）｜种族：（维多利亚贵族）｜形象：年轻精明的女伯爵（紫色名片印金色千屈菜）
- 首次登场：活动《维娜·维多利亚》（act37side）
- 关键信息：
  - **诺曼底公爵的代表**："小公爵"；"我找诺曼底公爵阁下要来马奇郡作为封地可不是为了什么伯爵的名号，只是图些生意上的方便而已"；"不要把我与诺曼底公爵阁下混为一谈。他是位值得尊敬的人，但处置伦蒂尼姆这种小事还犯不上麻烦公爵阁下"。
  - **《维娜·维多利亚》**：与哥伦比亚军方长期合作（医药企业引荐——"没有堵不上的缺口，只要价钱合适"）；警告维娜"别和罗德岛走得太近"（"一旦你做出了那个决定，就别和罗德岛这些人走得太近"）；掐断维娜的广播演讲（"太急躁了。有些话，你可以在我们面前说，但不该公开对那些平民说。为他们好，也是为你好"）；向维娜透露威灵顿公爵的历史（26 年前缄默旁观国王被绞死→塔拉暗涌）；组织公爵们到伦蒂尼姆（皇家科学院）小聚；"有时候，不必觉得自己做得还不够好。这座城市的变化，已经远超我的想象"。
  - **战时**：其部队（诺曼底公爵麾下掷弹团第八营——隶属马奇伯爵）支援典范军（"中尉，保护好亚历山德莉娜殿下""等眼下这些糟心事全都了结后，我会亲自拜访你的"）；劝维娜"想想那些仍然被你护着的人，真正需要的是什么"。
- 经典台词："我们未来的亲密合作，可以从这起一个好头。""伦蒂尼姆对你来说，太小了。""太急躁了。有些话……不该公开对那些平民说。""有时候，不必觉得自己做得还不够好。"
- 信息来源：活动《维娜·维多利亚》（全文）
- 后续：诺曼底公爵系（维多利亚战后格局的重要棋子）；与维娜的"合作"博弈中
