# 吕刻伊昂（Lukaiyon）

- **身份**：赞索斯的徒弟（渡口帮工）；**前祭司学院学生**（题罗斯神殿——辩论冠军/"善辩的石头"称号——赫卡德墨所取）；**感染者**
- **经历（重磅，活动《雅赛努斯复仇记》act48side》）**：因矿石病主动辍学（"感染之后，我不可能再成为祭司——那是与众英雄沟通，为米诺斯人指引方向的神圣工作"）；被赞索斯收留（"他救了我的命，教我水文知识和战斗的技艺"）；替老师取药（隐瞒赞索斯的病情——"病重的是赞索斯老师"）；撞船放火掩护老师盗琴（"既然知道您的计划……那我自然要跟您一起承担责任"）；入狱（与伊萨科斯父亲辩论）；越狱（赫卡德墨劫狱——"我会让你成为米诺斯的英雄"）；与赫卡德墨的"最后辩论"（辩题"感染者究竟能不能成为英雄"——"矿石病可怕的并不是身体上受到的折磨，而是它给所有的梦想和抱负都打上了不容涂改的截止日期"）；结局随赫卡德墨游历（"跟更多的人交谈，做更多的事"）
