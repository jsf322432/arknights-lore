# 三船光平 / 金兵卫（Mitsufune Kōhei / Kinbei）

- 阵营：金石会（实权者）→独立｜种族：斐迪亚｜身份：金石集团总裁/金石台电视台实控人；"金兵卫"（发迹前名字）
- 首次登场：活动《墟》（act44side）
- 关键信息：
  - **金石会实权者**：架空铁斋（"我现在不过是个被架空的老头"——铁斋语）；控制金石会全部产业（源石晶体企业/电视台/演艺事务所）；"漂亮"哲学（"想在御机活得好，最重要的是……'漂亮'""如果第一幕出现了一把铳……最迟到第三幕，这把铳一定要被一个拉特兰人握在手中""让每一把铳都在最后扣响"）。
  - **怪谈的制造者（重磅）**：20 年前议员候选人死后，岛须（凶宅第一受害者）拿真相要挟→被三船所杀；把星熊和"沉默的佐原"杂糅炮制凶宅怪谈（"结果一炮而红"）；凶宅成了"处理碍事之人的场所"（佐野口=三船杀——断刀证物/伪造）；"不存在的电梯"=金石会赌场；福井家食堂=强拆；招财猫摆件=发信装置。
  - **20 年前的选择**："我鬼迷了心窍，才在那一夜闭口不言"（让星熊背议员候选人案）；"我留了下来，我来面对你和铁斋留下的巨大的烂摊子"——自认的付出（"我选的这条路，是让我彻彻底底看清铁斋究竟有多无能……的路"）；断指=机械（"断指再植，甚至最近流行的仿生义肢"——铁斋说对了——演戏/立威）。
  - **《墟》**：伪造铁斋的信骗星熊回来（想要般若/继位仪式）；逼死铁斋（拍卖会/两亿买电视/按手印/刀刺——"让哲也亲眼见证你如何逼死他父亲的"）；背靠议员（锻冶町开发=议员的任务——议员想要小钢珠机）；舆论操控（寻人启事直播——"一张由每个看过电视的人的眼睛组成的大网"）；最终被星熊击败（河边决战——"终究还是……你赢了"）；被救（"你大概还能活，活很久"——星熊留手）。
  - **恨的根源**：铁斋的"任侠"（"任侠是一个人的事。一群任侠，要么散伙了事，要么就只是一帮社会渣滓在自欺欺人""铁斋总喜欢吹嘘他自己……希望他们能像家人一样爱彼此"）；"我宁可那天晚上你狂性大发，把我也砍死，也算干净！"
  - **结局**：倒在锻冶町河滩（失血——"我还有多长时间会死？"）；"这座城市现在的样子，就这么让你讨厌？""我现在只是个黑道。被逼到死角，困兽犹斗的黑道……我宁愿死得干净利索，死得……漂亮。"
- 经典台词："漂亮。""任侠是一个人的事。""我只是想……把事情做得漂亮。""我宁可那天晚上你狂性大发，把我也砍死，也算干净！""终究还是……你赢了。"
- 信息来源：活动《墟》（全文）
- 后续：被捕/受审（星熊未下重手——"被捕受审是理所当然"——文月语）；金石会被澪善后
