# 潘格尼尼（Pagnini / 黎博利制铳师）

- 身份：法柏尔区铳械工坊老板（**黎博利**为萨科塔造守护铳——"铳械工坊之王"）；帕特里奇昂的旧友；在灾异中为救老友牺牲
- 首次登场：活动《众生行迹》（act42side）
- 关键信息：
  - 生平：唯一成功复刻"恐怖的大口径转管遗产铳"的制铳师（"那种默认使用者能承受远超常规铳械五倍后坐力的设计，真是天才又疯癫"）；曾是铳骑专属制铳师（与帕特里奇昂/吉雅是挚友）——吉雅被驱逐后辞职开小工坊
  - 与帕特里奇昂的怨："我们曾一起宿醉，一起玩铳……但直到吉雅的背影消失在荒野尽头，你就那么从我旁边转身回拉特兰的时候，我才意识到——我们从来没有真正交流过"
  - 《众生行迹》：工坊被关停（签接收文书）；拒绝"分享光环"（"我可不想要你头顶那发光的玩意"）；把铳砸在铳骑甲胄上；顶替梵里妮被捕（"我指使她来的"）
  - 觉醒与牺牲：混入朝圣队伍（"当然是为了能找机会弄死你"）→为救帕特里奇昂挡下奥罗拉的子弹（"能洞穿铳骑盔甲的子弹"）；遗言："离别就像是化了的冰淇淋和报废的铳……哪怕没法阻止，你也可以在那时候送上祝福，哪怕只是一句再见""现在，好歹也算……没这个遗憾了"
- 经典台词："很多厨子都不吃自己做的菜，我只是没法使用自己造的武器罢了。""你可是铳骑啊！拉特兰最优秀的铳骑！""哪怕没法阻止，你也可以在那时候送上祝福，哪怕只是一句再见。"
- 信息来源：活动《众生行迹》（全文）
