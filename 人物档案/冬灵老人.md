# 冬灵老人（最后的冬灵族长 / 已故）

- 身份：**最后一名正统冬灵部族族长**（卡普里尼；"这片土地最初的定居者"）；塞弗林的追猎对象
- 首次登场：活动《沃伦姆德的薄暮》（act11d0）
- 关键信息：
  - 冬灵人=沃伦姆德最早的住民（被殖民/血脉已与镇民融合）；"冬灵就是沃伦姆德这颗月亮"
  - 复仇史：刺杀贵族/商旅（"一开始，我们都觉得，这是正当的复仇"）；"我们打不败莱塔尼亚……我们开始放弃"；逃入沃伦姆德地下（塞弗林未赶尽杀绝）
  - 揭示毕德曼未死（"发号施令的人的确是他"）；"冬灵人不是这场纷争的起因……他们自己毁了自己"
  - 结局：在铃兰面前"唱着歌寿终正寝"（"前面的路往哪里？那就是往山里去的路……晚安"）；塞弗林回忆"他好像在后悔……自顾自地感到了解脱"
- 经典台词："冬灵，冬灵就是沃伦姆德这颗月亮啊……他们，自己毁了自己。""不要急着去复仇、去战斗，先听我说……小姑娘。"
- 信息来源：活动《沃伦姆德的薄暮》（全文）
