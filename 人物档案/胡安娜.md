# 胡安娜（Juana / 盐漠海盗船队首领）

- 身份：盐漠"苍白海"海盗船队首领（阿戈尔人/百余岁）；科鲁兹船长的爱人；"重返海洋"计划的发起者；结局把首领之位交给哈维尔后率愿出海者启程
- 首次登场：活动《出苍白海》（act39side）
- 关键信息：
  - 生平：大静谧前的海员（"若你像我一样曾驾驶着船只在海浪中翻腾……你也只能用一生去怀念"）；随科鲁兹的船队在盐漠立足；**科鲁兹以自己为诱饵困住海嗣**（临终将船长职务交给她，"嘱咐我一定要带着大家回到海洋"）
  - 首领之道："要领导船队，我不仅需要他们敬爱我，还需要他们害怕我"（放任海嗣传言）；用舵轮/亲自猎鳞立威（"只要我没死，它就还是我的猎物"）
  - 《出苍白海》：认出伊西多的奥卢斯金币（"我认识金币原来的主人，奥卢斯，他是那一派中最有才的炼金术师"）；饲喂洞窟中的海嗣（"会离开的，不论付出什么代价，我们都会离开盐漠"——科鲁兹）；托伊西多学剑并结束海嗣（科鲁兹）的生命（"我爱他，正如我深爱过去那些远航的时日"）
  - 与哈维尔：养大的孩子（"不论你长多大，在我心里都还是个孩子"）；新老首领决斗中不杀他（"恭喜你，小哈。这场新老首领之间的决斗，你赢了……走回去，去找你的船员们"）；把首领之位交给他
  - 结局：率愿出海者登上征服宣告号（掌舵"久违了，老朋友"）；桅杆上跳起最后一支舞（夕阳下——"阳光为她的裙摆镀上一层金边"）
  - 与雅隆的旧怨：曾帮雅隆驱赶海嗣/省出口粮（"可他们呢！等审判庭一来，又毫不留情将我们赶进盐漠深处……如果不是他们见死不救，科鲁兹又怎会沦落到那个境地"）
- 经典台词："失败并不足以让人畏惧，纵然成功的几率只有万分之一，我也会孤注一掷，倾尽所有去赌一个机会。""告诉我，我们的人生到底是赌博，还是实验？""再会了，爱人。""愿你的灵魂从盐漠中释放……我们重逢时，一定会在那无垠的海上。"
- 信息来源：活动《出苍白海》（全文）
