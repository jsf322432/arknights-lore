# 奥卢斯（Olus / 萨卡兹教士·"主教阁下"）

- 身份：萨卡兹教士/主教（赫曼称其"主教阁下"；疑似**深海教会**关联者）；曾求学于安布罗修修道院（尚属伊比利亚时期）；**"向海而生"炼金流派的大炼金术师**（棘刺/伊西多的老师；审判庭通缉要犯）
- 首次登场：活动《空想花庭》（act26side）；《出苍白海》（act39side，背景补全）
- 关键信息：
  - 求学经历："在这座了不起的建筑尚在伊比利亚时，我曾有幸在此学习"——对修道院怀有感情；有一名伊比利亚学生（"那是我教导过的最出色的学生之一。可惜在他离开伊比利亚之后，我们再未相见过"——伏笔）
  - 理念：质问"净土"与"互相理解"（"人和人究竟有什么不同？阻隔我们的究竟是体魄上的差异，还是别的什么？……是否真的存在所谓的互相理解？"）；劝斯特凡诺考虑成为"我新的同胞"（邀其"入教"）
  - **炼金流派（《出苍白海》补全）**："向海而生"——金币（盐/水图样/海平线，"只能由老师传给学生"）；"海洋与陆地本是一体，融合不过是抹消彼此间的隔阂""终有一日，所有人都会向所有人敞开身心"（海嗣融合理念——杀死学生伊西多的同窗并令其异变）；大静谧后该派门徒被囚禁/产物被摧毁；奥卢斯被审判庭通缉（安纳斯塔西奥："你和通缉要犯奥卢斯是什么关系？……为什么你会一眼认出一件被封存多年的炼金孽物，提及一支已被抹去的炼金流派？"）
  - 《空想花庭》：保护"扭曲的怪物"赫曼（深海教会异变者——"请不要阻拦这个可怜的魂灵"）；与蕾缪安对峙（"您如何定义净土？""就算生活只是看不到尽头的忍饥挨饿？"）；拒绝放行
  - 结局：携赫曼启程（"搁浅于旷野的乐园已逝，我们也该启程了"）；评价拉特兰"现任教宗是个温和派"——双胞胎将由合适人家收养；"再次……欢迎你的加入，赫曼"
- 经典台词："我常常思考，人和人究竟有什么不同？""海洋与陆地本是一体，融合不过是抹消彼此间的隔阂。""终有一日，所有人都会向所有人敞开身心。"
- 信息来源：活动《空想花庭》（全文）；活动《出苍白海》（背景——棘刺之师）
