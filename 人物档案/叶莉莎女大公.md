# 叶莉莎女大公（Grand Duchess Elisa / 叶莉萨维塔·拉齐萨拉）

- 身份：乌萨斯**布列洁诺伊女大公**（叶莉萨维塔·康斯坦丁诺夫娜·拉齐萨拉）；布列斯克（"远北明珠"）治理者
- 首次登场：第十六章「反常光谱」
- 关键信息：
  - "仁慈"名声：辖区内十几年无死刑（"她对感染者矿工给过皇帝陛下允诺的关照"）；亲民（"真诚的善意是不依赖于礼数而存在的"）
  - 实则冷酷：下令两周内出"奥卡"人体实验成果（受害者多为非自愿矿工）；封锁矿区、屏蔽通讯；烧毁议会信件、**默许集团军"清洗"矿工**（"乌萨斯绝不能软弱，如果她即将变得软弱，那我们便要剜去让她软弱的部分"）
  - 与第四集团军（叶甫根尼元帅）的博弈：被要求保持沉默（"第四集团军协助布列斯克剿灭了发生在远北地区的叛乱"）；"我在意的只有他们（人民）"——言行矛盾
  - 批准罗德岛进入矿区（经阿洛伊泽斡旋）；"我希望我的确是仁慈的"
- 经典台词："一个失去了能源命脉的国家能有什么下场？沦为仰人鼻息的牲畜，或是在那之前，夺来足够让自己维生的能源。""这是乌萨斯的渴求。""我希望我的确是仁慈的，可是真的很少有人会感谢他人的仁慈。"
- 信息来源：第十六章（16-04/16-15/16-17）
