# 羽毛笔（Quill / 拉菲艾拉）

- **身份**：罗德岛干员（玻利瓦尔）——本名**拉菲艾拉**；**埃内斯托（龙舌兰）的妹妹**；镰刀
- **经历（干员密录 story_crow_1_1）重磅**：**多索雷斯（回来看爸爸——潘乔上校（被捕入狱——玻利瓦尔军人）；潘乔残部（塔吉克/巴罗叔叔——想营救上校——被坎黛拉盯上——"渗透、袭击、爆破，最好能在坎黛拉脸上开道口子"）；羽毛笔阻止**（说服爸爸拒绝营救——"你不能让那些尊敬你、爱戴你的人白白为你送死"；用镰刀放倒士兵——"格杀勿论"前自救）；**坎黛拉（市长）**（"你很勇敢，孩子……你是被狂风卷起的羽毛……如果你足够坚韧，也会看见只能在风暴之中窥见的景色"）；紫丁香（妈妈的花——潘乔与妻子的回忆——"是紫丁香"）；结局：买紫丁香（"送给我的家人"）
- **经典台词**："如果他们不打算离开，那么，我也不应该离开。就这么简单。"
