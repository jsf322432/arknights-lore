# 干员秘录合集（三）精读摘要

> 干员密录 obt/memory 第 3 批：38 个角色、45 段（ctable→ghost 字母序）。每篇密录为该干员的个人故事（身世/羁绊/成长）。

## 本批逐篇要点

### 晓歌 / 克劳迪娅 / 刻刀 / 达格达 / 深海色
- **晓歌（story_ctable_1_1，重磅）**：罗德岛干员（前雇佣兵/杀手——"目标收割者"）；**最后的目标**（废墟中求她救丈夫的女人受惊吓产子——"那就是'生命'"）；自己也被炸伤感染矿石病，被罗德岛救回；任务中打伤想杀强盗的村民而内疚、用不吃饭惩罚自己；受伤羽兽飞进宿舍（豆苗教她照顾——"它已经选中了你"）；给小病人弹琴；结局：把过去写进报告（"我会更清楚自己以后应该怎么做"）。
- **克劳迪娅（story_ctrail_1_1，重磅）**：哥伦比亚飞行爱好者/自制飞行器（梦想=羽兽迁徙伴飞）；**飞行测试撞上"天灾云"感染矿石病**；母亲的陪伴（科学工作者）；孵化羽兽蛋（印随行为）；"我并不害怕飞行……我是怕死"；结局：申请罗德岛治疗项目（"借这个机会调查大地上不同区域的羽兽迁徙情况"）+带小羽兽学习飞行。
- **刻刀（story_cutter_1_1，重磅）**：前雇佣兵（"从记事起就一直跟着师父"）；**护送任务全是诱饵**（雇佣兵B感染源石结晶绝望——"我们他妈的从一开始就是诱饵"）；罗德岛厨房事故（切土豆切砧板/烧锅——被列入"刻刀禁止入内"）；铸铁当教官教她烹饪（"要带着希望……做成自己期待的样子"）；学会"沙虫罐头烩饭"。
- **达格达（story_dagda_1_1，重磅）**：塔楼骑士伊莎贝尔·孟塔古（导师芬恩——"空王座"嘱托）；**被导师们拼死送出**（"他们是要我替他们好好看看维多利亚的未来"）；与格拉斯哥帮磨合（因陀罗打架/摩根送衣服耳钉）；把"塔楼之书"交给推进之王（"我并非在守护维多利亚的王，我只是在守护我的朋友"）。
- **深海色（story_deepcl_1_1/2_1，重磅）**：画家/前海嗣（"使者"引导成为"同胞"——但"在距离海洋只有一步之遥的地方掉头折返"）；教士追猎（"标记"）；蓝色吞噬（源石技艺陷阱）；段2：神秘包裹（画）引导回旧画室（"当绘画成为生命，生活便堕落为毒药"）；"助手"（海嗣触手生物）；前辈画家溺死（"她溺死了，我还活着，我要表达"）；海底作画（"我不会，也不想听从大群的呼唤。我将仅剩的自我全留给绘画"）——深海教会线。

- **塞雷娅（story_demkni_1_1，重磅）**：莱茵生命新总辖上任第一天（秘书海伦视角）；静滞所调查向梅兰德开放权限/冻结问题项目经费；拳击面试斯凯·杰格（"未来之星"/克丽斯腾粉丝/偷听特里蒙理工——收进工程科）；多萝西来告别（"克丽斯腾并不伟大……但她打开了一扇大门"）；斐尔迪南（"他要回莱茵，先站上我的拳击台"）。
