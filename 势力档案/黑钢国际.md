# 黑钢国际（Blacksteel International）

- **定位**：泰拉佣兵公司（总部**巴伦基地**；"植根哥伦比亚"）；与罗德岛长期合作（借调干员）
- **信息来源**：主线第二~四章（芙兰卡/雷蛇/杰西卡借调罗德岛）；活动《不义之财》（act28side，重磅）；活动《维娜·维多利亚》（埃利西奥=赤心医疗/国防部背景提及）
- **组织架构**：
  - **老板"桥夹"克里夫（本名鲁伯特）**：90 多岁萨科塔；哥伦比亚独立战争军官出身；**"既然无法终结战争，我也只能退而求其次，试着把它的开关攥在手心里"**——创立黑钢的动机；"战争一直都在，它只是偶尔停下，然后继续爆发"
  - **B.P.R.S.（雷蛇小队）**：队长雷蛇（瓦伊凡）；成员芙兰卡/杰西卡/罗拉（首席技术员）等；负责高风险外勤
  - **情报组**：蒂拉（克里夫心腹，护送/追踪）；资深干员/情报小组
  - **装备与应用技术部门**：杰西卡七年前入职部门（装备测试员出身）
- **《不义之财》大事记**：受托拖拽达维镇回航路（州政府委托）→配合银行驱逐负债居民（"回收不良资产"）→银行越权下令开火（克里夫警告"没有谁能越过我去指挥我的人"）→金库劫案（四人组劫走准备金；克里夫撤走银行安保暗中放行）→克里夫帮行长补漏换取签署文件（反制银行）；在玻利瓦尔与哥伦比亚东部边境设立训练中心
- **组织风格（克里夫语）**："大家都是体面干净的人，招人恨的脏活做不了，只能佣兵来做坏人。"；"我们已经被一个比玻利瓦尔强大得多的家伙攥得太紧也太久了"（对哥伦比亚政府的依附与反制）
- **与罗德岛关联**：芙兰卡/雷蛇/杰西卡/陨星等干员长期借调罗德岛；杰西卡结局（拓荒地服刑期间）仍保留黑钢员工身份
