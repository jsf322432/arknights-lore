# 玻利瓦尔（Bolívar）

- **定位**：泰拉大国之一（战事频发的南陆大国）；"名义上"由**玻利瓦尔联合政府**统治；莱塔尼亚/哥伦比亚势力渗透
- **信息来源**：活动《多索雷斯假日》（act12side）；活动《水晶箭行动》（act32side）；活动《太阳甩在身后》（萨尔贡线提及玻利瓦尔关联）；**活动《丛林症结》（act21mini，2026——玻利瓦尔近代史/大迁徙核心）**
- **历史（重磅·《丛林症结》补全）**：伊比利亚殖民地（发现源石矿脉/三百多年前伊比利亚舰队——佩德洛见证）→莱塔尼亚附属地→两百年前附属国（**辛嘉斯王朝**）→巫王时期莱塔尼亚借玻利瓦尔掀哥伦比亚内乱→内乱失败反被哥伦比亚入侵（**联合政府**建立）→三方割据（联合政府/辛嘉斯王朝/"真正玻利瓦尔人"反抗军）→**和平协议（汉科将军被杜宾刺杀）→内战→"大总统"统一（收复辛嘉斯工业区/解放种植园）→多索雷斯动乱（1101.5）→"大迁徙"（百万人南迁）→特科马事件**→多索雷斯（埃内斯托·萨拉斯接管/坎黛拉退场）
- **国家结构**：
  - **玻利瓦尔联合政府**（首都拉乌尼达）：派驻各城市的代表（如多索雷斯的马特奥上尉）；对地方的控制力有限（多索雷斯实际由市长坎黛拉掌控）；种植园体系（"液体化肥"黑流/强制劳动/"坏香蕉"式人口运输）
  - **多索雷斯（"双日城"）**：度假城市（阳光沙滩/赌场/酒吧）；市长**坎黛拉·桑切斯**（前市长之女）；**大总统遇刺后由埃内斯托·萨拉斯（龙舌兰）广播接管**，坎黛拉退场（死讯存疑/假死留白）；哥伦比亚切断物资后经历"大迁徙"
  - **"真正玻利瓦尔人"**：潘乔等军官（《多索雷斯假日》夺城阴谋；潘乔入狱，其子埃内斯托=罗德岛干员"龙舌兰"）；**汉科将军（协议时代领袖，被杜宾刺杀）/马丁上校（出走）/何塞上校（屠杀士兵）/杜宾上校（刺杀汉科后入罗德岛）/"大总统"（1101 年遇刺）**；"勇敢、勤勉和自由"
- **《水晶箭行动》政局**：联合政府代表马特奥为"娱乐城开发计划"强夺街头艺术社区地皮；坎黛拉平衡三方；雷内尔（卡西米尔商人）被商业联合会遣返
- **《丛林症结》重磅（1101 年）**：
  - **黑流/猎犬病（核心）**："液体化肥"（黑流）增产且致病（症状=猎犬病：失忆/空壳/衰竭；只在玻利瓦尔土地生效）；源头=**黑流树海中启动的"某个装置"**（十几年前，哥伦比亚军方/国防部实验；洛伦茨之父 16 年前主持"第一次实验"——特里蒙闪光）；无药可医（特效药仅暂缓）；**人体实验**（防控镇/特科马；"每个病患都是珍贵的数据来源"）
  - **黑流树海**：玻利瓦尔北部的移动黑色森林/沼泽区（特科马附近）；本质=**"被称作兽主的特殊个体的内部"**（洛伦茨语）；哥伦比亚国防部秘密实验区；**米格鲁的意识保存在此（化为橙黄小生物）**；特科马改建为探索前哨站（黑流树海肉鸽「沉沦者的黑流树海」前置）
  - **大迁徙**：多索雷斯动乱后，小麦克森播放"哥伦比亚公民被害"录像→联合议会批准国防部特别行动（三支高速战舰编队）→切断多索雷斯等三座移动城市物资→近百万人南迁（"大迁徙"）；罗德岛（米格鲁/克洛丝，响应龙舌兰求援）护送撤离队伍
  - **特科马事件**：联合政府故意放出病人/猎犬引玻利瓦尔人来救人再屠杀（嫁祸）；米格鲁牺牲（触发武器制动）
- **街头艺术社区（多索雷斯）**：艺术家聚居地（涂鸦/音乐/摄影；感染者众多）；舞厅火灾（社区伤疤）；精神领袖迪亚兹·冈萨雷斯（老消防员）；艺术节传统
- **与罗德岛**：罗德岛在多索雷斯设办事处（《多索雷斯假日》）；罗德岛干员龙舌兰（埃内斯托）/空爆出身关联；坎黛拉与罗德岛"有点交情"；**龙舌兰向罗德岛发出玻利瓦尔救援请求（《丛林症结》）**；杜宾教官=前玻利瓦尔军队上校
