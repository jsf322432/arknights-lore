# 深池（Dublinn / "鬼魂部队"）

- 性质：维多利亚的武装组织（对外称塔拉人反抗军"鬼魂部队"）；实为利用塔拉人旗号的政治势力
- 目标：以火焰"净化"维多利亚（"烧出一条通向自由和平未来的通路"）；真正的野心指向维多利亚王位（"维多利亚的冠冕"）
- 核心人物：
  - **拉芙希妮**（名义领袖，红龙）——被推到台前的影子；第九章重伤被罗德岛救走
  - **爱布拉娜**（幕后主导，拉芙希妮之姐，第十二章正式登场）——"贪婪的红龙"；德拉克；亲自出马
  - **阿赫茉妮**（谋臣）、**蔓德拉**（石系术师）
  - **"校官"**（赤铁近卫队队长，第十二章）——率深池部队潜入诺伯特区
  - 六干部：会计/囚犯/纵火家/毒药学者/强盗/雄辩家（第九章被 Outcast 全灭）
- 手段：煽动塔拉人仇恨、贵族集会渗透、脏弹事件后接管城市、广播宣言收买人心
- **第十二章（爱布拉娜亲临）**：紫火（不可扑灭、令死者化为"行尸走肉"）焚杀诺伯特区难民；对死魂灵/飞空艇感兴趣（"我对你们的存在很感兴趣，死魂灵"）；与变形者集群对峙（"我的火焰总会为我灼烧一切"）；"校官"秘密潜入地块抢夺飞空艇技术
- 与塔拉人的关系：自称"为塔拉人复仇"，实为利用（阿赫茉妮："你跟我都和塔拉一磅关系都没有"）——但《照我以火》揭示爱布拉娜本人的塔拉/德拉克出身与真实诉求（"我们只是为了从维多利亚人那里换回我们的命运"）；深池内部分歧（"校官"强硬派 vs 阿赫茉妮的私情）
- **《照我以火》（1098 年，塔拉线开篇）**：
  - **双"领袖"与"影子"**：拉芙希妮（"影子"）逃离深池/独自追踪（"我只是，人们理想中'领袖'的影子"）；"校官"（赤铁近卫队）奉威灵顿之命追杀（"如果你不再甘于影子的身份"）；爱布拉娜等妹妹自愿回归（"既然她终于醒来……那她很快就会回到我身边"）
  - **与威灵顿结盟（源头）**：威灵顿公爵=塔拉人后裔（"德拉克麾下传奇将领之名"）；七年前向沃里克伯爵宴会派使者（"这艘战舰的巡游正是从那时开始"）；"加斯特里尔"号七年巡游后停靠橡林郡（爱布拉娜家乡）；**爱布拉娜"加斯特里尔"号演讲**——"这艘战舰的下一次停靠，将会在伦蒂尼姆的港口""火已经燃起来了。它将烧尽这片大地上陈旧的秩序"（衔接主线 10-14 章进军伦蒂尼姆）
  - **死亡之火/紫火**：操纵死者（"她只是准许他们从灰烬中爬起，在死后得以向烧毁他们家园的人复仇"）；拉芙希妮的新生之火可熄灭/净化
  - **蔓德拉之死（补完）**：死于伦蒂尼姆/下水道旁（"雄辩家"利用其分裂深池——"本该和那六个叛徒一同死在小丘郡"）；"间谍"（伦蒂尼姆城内情报线）已死
  - 起源：沃里克伯爵（"颂古者"）寻找并培养德拉克（姐妹俩的老师）——深池的塔拉民族主义源头（爱布拉娜杀师夺权）
- **《淬羽尘黯》（2025，塔拉线终局）**：
  - **纳斯尔纱**：塔拉光复后首府（"红龙的巢穴"）；居民被死火（紫火）侵染（源石灯=紫——"红龙的祝福"实为死火）；爱布拉娜"杀死我"的舞（"在最后一个小节之前，用你的枪贯穿我的心脏"）；还火仪式——拉芙希妮"杀死"爱布拉娜/紫火化明黄/"红龙复生"（自导自演的奇迹——空棺/余火/威灵顿观望）；拉芙希妮=塔拉唯一的德拉克后裔（"拉芙希妮·都柏林"）；无限期推迟加冕仪式（塔拉王国）
  - **深池高层覆灭**：爱布拉娜以盖尔王珍宝为饵诱高层（官僚/酷吏/拷问者/监察官）入黑雾（"走向黑暗的来处……那残忍地张开大口的黑林"）；"歌唱家"（最后一位深池）逃脱/失语
  - **爱布拉娜未死（重磅）**：以"**死芒**"之名加入罗德岛（"我只是塔拉领袖的小小影子，只是'死芒'"；死火聚身无法消散——"加斯特里尔"号一战后急需收回死火）；向威灵顿承诺"扭转塔拉的航向"（"用一城注定死去的人，换取一个稳如磐石的塔拉"——被拉芙希妮的奇迹打破）
  - **"放逐王"拉布雷德**：六百多年前喷吐死火的德拉克（归来被弟弟艾里尔杀害/死火蔓延/祭司还火/守灵人=祭司后裔）；被爱布拉娜唤醒；死火传承（拉布雷德→爱布拉娜→拉芙希妮新生之火）
- 信息来源：第九章、第十二章（12-12/12-14/12-15）、第十四章；活动《照我以火》（全文）；活动《维娜·维多利亚》（提及）；活动《淬羽尘黯》（全文）
