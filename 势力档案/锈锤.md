# 锈锤（Rusthammer / 锈锤组织）

- **定位**：泰拉荒地反抗组织（无政府/反文明）；"荒地的征服者"
- **信息来源**：活动《灯火序曲》（act7mini，st01——重磅）；活动《绿意火花》（坎诺特——锈锤成员）；活动《如我所见·主线》（act8mini st01——坎诺特搭救博士）；主线提及
- **理念（重磅）**："所谓的'国家'和'文明'——从根本上就透着邪恶，那些巨大的移动城市，那些丑陋的钢铁造物，那些以恶意铸造的金属枷锁与监牢，就是他们邪恶的罪证""他们抢走了一切……他们用力量让你们恐惧，他们用文明让你们软弱……他们以此来奴役本应自由的你们""这片大地理应属于每一个人，每个人都该像你我一样，凭借自己的双手在荒原中拥有一席之地""**我们从不战斗！我们摧毁！我们砸碎牢笼，我们摧毁枷锁**"
- **加入方式（重磅）**："想要加入他们，就去寻找撕裂岩石的锈锤"（山顶岩石上倒插的铁锤——"这是一种象征。想要活在荒地之上，你就得像这把锤子一样。你不需要尖锐，但是需要坚忍"）；给铲子/镐子/捕兽夹——**在峡谷存活一个月**（"证明你们属于荒地，证明你们不是离开了栅栏就活不下去的畜兽"）；"如果你拥抱荒野，隔断文明的毒血，我们一视同仁"（不在乎感染者/身份/种族）
- **行事（重磅）**：袭击乌萨斯哨卡（上百人冲击营地/金属敲击如战鼓/"疯狂"冲锋）；**洗劫感染者矿场**（放走矿工/烧军用补给/杀军官/撕碎旗帜——"锈锤洗去了乌萨斯的痕迹"）；歼灭越境劫掠的乌萨斯正规军小队（"他们不是普通的暴徒"）
- **成员**：加勒斯/依拉（乌萨斯逃兵——st01 加入）；布恩（感染者）；坎诺特（铁桶头商人——R20 绿意火花："我向很多人，很多组织提供过帮助，锈锤、整合运动、萨米的独眼巨人们……"）
- **关联**：坎诺特（锈锤商人——"疯狂是这个世界即将面对的真相"世界观）；与整合运动重建（悬浮载具原型机改造——绿意火花）；荒地（乌萨斯/卡西米尔边境的无人地带）
- **搭救博士（活动《如我所见·主线》重磅）**：坎诺特以"**古德英纳夫先生**"之名在哥伦比亚**加斯帕荒原**搭救博士/阿米娅（提卡伦多遇袭/"坏家伙"号坠毁后）；博士识破坎诺特暗处有**锈锤/恶魔帮保护**（"我以为我的朋友们藏得很好"）——锈锤成员在哥伦比亚荒地的活动能力
- 信息来源（补）：活动《灯火序曲》（act7mini st01）；活动《如我所见·主线》（act8mini st01）
