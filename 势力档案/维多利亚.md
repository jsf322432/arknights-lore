# 维多利亚（Victoria）

- 性质：泰拉强国之一（曾为经济中心）；首都**伦蒂尼姆**（"永不陷落的堡垒"）
- 局势（第九章起）：王位悬空（阿斯兰王室失势）、各大公爵割据城外、**萨卡兹摄政王特雷西斯**入主伦蒂尼姆、深池/塔拉人反抗、自救军地下活动
- 王位相关：**推进之王（维娜）**=阿斯兰王室继承人（全名亚历山德莉娜·维娜·维多利亚；父王 26 年前被绞杀，流亡多年）；初代阿斯兰王与德拉克盖尔王曾有休战条约
- **王权象征（第十一~十四章）**：**诸王之息**——源出萨尔贡万王之王秘宝（可抑制源石结晶扩散，探险者自黄沙带出），阿斯兰帕夏**路加沙姆什**于 737 年携入维多利亚，斩红龙、成王权象征（"劈开天灾"传说）；**剑座**=开斯特家百年研究的产物（可激发国剑力量；荣光号上）；**第十四章推进之王插剑入座、劈开天灾**
- **蒸汽骑士（第十一章真相）**：维多利亚王牌兵种；4 年前全体被调回伦蒂尼姆，在诸王长眠之所中了萨卡兹的埋伏——**背叛他们的是整个维多利亚**；唯一幸存者（疑似最后册封的查尔斯·林奇爵士）第十四章在荣光号从源石中夺回诸王之息抛给维娜
- 关键势力：
  - 萨卡兹军（特雷西斯/曼弗雷德/诸王庭）——详见 `萨卡兹军事委员会.md`
  - 深池（塔拉人旗号；**爱布拉娜**与**威灵顿公爵**结盟）——详见 `深池.md`
  - **伦蒂尼姆市民自救军**（克洛维希娅[滞留城内]/费斯特/洛洛/凯瑟琳）
  - **典范军（第十三章新生，第十四章正式崛起）**：推进之王建立的军队；与风笛/号角（风暴突击队）会合；获开斯特公爵承认为"独立英雄部队"；高多汀公爵以"议会直属"名义拉拢未果
  - **格拉斯哥帮**（贝尔德[战死]/卡铎尔/戴菲恩·温德米尔）
  - **各大公爵（第十四章总攻）**：**威灵顿**（铁公爵，与爱布拉娜结盟、故意后撤弃同僚）、**开斯特**（留守荣光号、发动反攻、邀典范军独立作战）、**温德米尔**（第十三章战死，戴菲恩继位）、**高多汀**（议会成员肖恩·高多汀）、亚伯科恩/阿什沃思（被威灵顿弃）
- 重要地点：碎片大厦（"阿喃那"道标）、银石崖（公爵联军前线）、荣光号（开斯特旗舰/剑座）、吉布森镇、布伦特伍德、诺伯特区、诸王长眠之所
- 历史：塔拉人百年压迫；四皇会战（高卢战败，林贡斯被威灵顿毁灭）；蒸汽骑士覆灭；26 年前狮王被绞杀；4 年前萨卡兹掌控伦蒂尼姆；**第十二章战争全面爆发；第十三章温德米尔公爵战死；第十四章诸王之息劈开天灾、公爵联军反攻**
- **战后（活动《维娜·维多利亚》，萨卡兹撤军两个月后）**：
  - **新议会与维娜议长**：维娜·维多利亚在公爵们支持下出任伦蒂尼姆**临时议长**（"新沃尔西尼不存在家族"式试验的另一面——"只要他们还需要'维多利亚'这个名字来点缀自己的门面"）；临时法庭→"伦蒂尼姆城市法庭"更名中；警察系统重组/宵禁解除承诺；**典范军番号永久保留**（解散安置/成员加入城防军）
  - **战后权力格局**：开斯特/高多汀/诺曼底（"小公爵"艾莉诺·马奇伯爵为代表）仍欲操控；**威灵顿公爵缺席**（26 年前缄默旁观国王被绞死→对维多利亚失望→塔拉暗涌；"加斯特里尔"号引擎两月未熄火）
  - **"铣痕"组织**：地下佣兵（头目=阿勒黛·坎伯兰——倒卖劣质药/护送留城萨卡兹出城）；被议会通缉清剿
  - **重建线**：工人（凯瑟琳/费斯特/工业振兴协会）重启工厂与科技研发；整合运动（珀茜瓦尔留守）灰色贸易；药物短缺/感染者激增（**源石技艺异变新症状**——埃利西奥观察）
- 信息来源：第九章~第十四章；活动《维娜·维多利亚》（全文）
