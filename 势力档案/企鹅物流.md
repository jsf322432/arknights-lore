# 企鹅物流（Penguin Logistics）

- 性质：龙门物流/情报组织（对外为快递物流公司）；总部龙门
- 核心成员：**能天使**（萨科塔，话痨，情报/路线）、**德克萨斯**（寡言，强战力/叙拉古德克萨斯家族末裔）、**可颂**（送货/保镖）、**空**（偶像歌手，后加入）、**大帝**（老板/兽主）、莫斯提马（信使，拉特兰线）、拜松（临时成员）
- 宗旨："只要能抵达目的地，什么路都可以走"；"风雨无阻"
- 与罗德岛关系：合作提供情报、护送、路线支援
- 特点：熟悉龙门地下与高层地形；行事自由随性；"企鹅物流的企业文化是——从不怕群架"
- **《叙拉古人》补全（重磅）**：
  - **大帝=兽主**（狼之主扎罗称"可悲的同胞"——"我们终究属于荒野"）；企鹅物流是"他在遇到德克萨斯后，两个人商量着建立的"；德克萨斯是叙拉古德克萨斯家族末裔（萨尔瓦多雷之孙女）
  - **德克萨斯留叙拉古**：完成与贝洛内/扎罗的约定后，决定留下助莱昂图索/拉维妮娅改变叙拉古（"这片土地还没有那么无可救药。所以，我不逃了"）；"我打算延长一下我的假期"
  - **《叙拉古人》事件**：能天使/可颂/空追到沃尔西尼寻找德克萨斯；空借"白日剧团"演员身份接近贝洛内；大帝亲赴叙拉古召唤狼之主压制扎罗（"用你们的规矩打败你，能更让我解气"）
